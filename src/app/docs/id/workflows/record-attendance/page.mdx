# Catat kehadiran

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu mencatat entri kehadiran baru (check-in/out atau catatan manual) untuk karyawan.

## Prasyarat

- Anda masuk sebagai HR atau Admin (atau sebagai karyawan jika aplikasi mengizinkan entri kehadiran mandiri).
- Anda punya izin untuk menambah catatan kehadiran.

## Langkah

1. Buka [Daftar Kehadiran](/docs/manual/pages/attendance-tracker).
2. Klik **Catatan Kehadiran Baru** (atau **+ Tambah Kehadiran**).
3. Di halaman [Tambah Kehadiran](/docs/manual/pages/attendance-tracker-add), pilih karyawan (jika wajib), tanggal, waktu check-in/out atau kolom wajib lainnya. Isi catatan jika perlu.
4. Klik **Simpan** (atau **Kirim**). Perbaiki error validasi jika ditampilkan.
5. Catatan baru muncul di [Daftar Kehadiran](/docs/manual/pages/attendance-tracker). Mungkin perlu persetujuan tergantung pengaturan perusahaan.

## Hasil yang diharapkan

Catatan kehadiran baru dibuat dan muncul di daftar. Mungkin tampil sebagai tertunda sampai disetujui.

## Kesalahan umum

- **Tidak melihat Tambah Kehadiran** — Mungkin dibatasi oleh peran. Tanyakan ke admin.
- **Error validasi** — Pastikan tanggal dan waktu valid (mis. check-out setelah check-in). Isi semua kolom wajib.
