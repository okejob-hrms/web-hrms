# Ajukan lembur di mobile

## Kapan menggunakan

Anda bekerja atau akan bekerja jam tambahan dan perlu mengirim pengajuan lembur.

## Prasyarat

- Sudah masuk di aplikasi mobile.

## Langkah

1. Dari [Mobile: Home](/docs/manual/mobile/pages/mobile-dashboard), ketuk **Overtime Request**, atau gunakan pintasan kehadiran di [Mobile: Profile](/docs/manual/mobile/pages/mobile-profile).
2. Di [Mobile: Overtime Request](/docs/manual/mobile/pages/mobile-overtime-request), isi tanggal, jam, dan alasan.
3. Kirim form.

## Hasil yang diharapkan

Pengajuan lembur tersimpan dan terlihat di riwayat kehadiran atau lembur Anda.

## Kesalahan umum

- **Error validasi** — Kolom wajib harus diisi; periksa tanggal tidak di masa lalu jika dibatasi.
- **Tidak menemukan layar** — Gunakan pintasan Home atau Profile → Attendance and Overtime.
