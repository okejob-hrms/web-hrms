# Edit atau batalkan pengajuan cuti

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu mengubah atau membatalkan pengajuan cuti yang ada yang masih bisa diedit (mis. tertunda).

## Prasyarat

- Anda masuk dan punya izin untuk mengedit pengajuan cuti (milik Anda atau sebagai HR/Admin).
- Pengajuan cuti ada dan dalam status yang mengizinkan edit (mis. Tertunda).

## Langkah

1. Buka [Daftar Pengajuan Cuti](/docs/manual/pages/leave-request) (atau [Cuti ESS](/docs/manual/pages/ess-leave) untuk karyawan).
2. Temukan pengajuan cuti. Buka menu baris dan pilih **Edit** (atau setara). Anda akan diarahkan ke halaman [Edit Pengajuan Cuti](/docs/manual/pages/leave-request-edit) (URL berisi ID pengajuan).
3. Ubah kolom sesuai kebutuhan (mis. tanggal, alasan). Untuk membatalkan, gunakan **Batalkan** atau aksi batalkan/tarik jika aplikasi menyediakan.
4. Klik **Perbarui Pengajuan Cuti** (atau **Simpan**) untuk menyimpan perubahan. Jika Anda membatalkan pengajuan, konfirmasi seperti diminta.

## Hasil yang diharapkan

Pengajuan cuti diperbarui atau dibatalkan. Daftar mencerminkan status baru atau pengajuan dihapus dari daftar tertunda.

## Kesalahan umum

- **Edit tidak tersedia** — Pengajuan mungkin sudah disetujui atau ditolak. Hanya pengajuan tertunda (atau serupa) yang biasanya bisa diedit. Jika perlu mengubah pengajuan yang disetujui, tanyakan ke admin.
- **Halaman tidak ditemukan** — Buka Edit dari daftar agar URL berisi ID pengajuan yang valid. Jangan ketik ID secara manual.
