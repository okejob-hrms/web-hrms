# Ajukan cuti di mobile

## Kapan menggunakan

Anda memerlukan waktu libur dan ingin mengirim pengajuan cuti dari ponsel.

## Prasyarat

- Sudah masuk sebagai karyawan.
- Tipe cuti dikonfigurasi oleh perusahaan Anda.

## Langkah

1. Buka tab **Leave Request** ([Mobile: Leave Request](/docs/manual/mobile/pages/mobile-leave-request)) atau ketuk **New Leave Request** di Home.
2. Di [Mobile: New Leave Request](/docs/manual/mobile/pages/mobile-leave-request-form), pilih tipe cuti, tanggal, dan alasan.
3. Kirim form.
4. Lacak status di daftar cuti; buka baris untuk [Mobile: Leave Detail](/docs/manual/mobile/pages/mobile-leave-detail).

## Hasil yang diharapkan

Pengajuan cuti baru muncul di daftar Anda dengan status tertunda atau terkirim.

## Kesalahan umum

- **Daftar cuti kosong setelah kirim** — Tarik untuk refresh atau buka kembali tab; periksa error validasi di form.
- **Tidak dapat memilih tanggal** — Beberapa tipe cuti membatasi tanggal; tanyakan ke HR jika opsi tidak muncul.
