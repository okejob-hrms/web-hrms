# Lihat daftar dan detail payrun

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu melihat daftar payrun (periode payroll) atau membuka payrun tertentu untuk melihat detailnya.

## Prasyarat

- Anda masuk sebagai HR atau Admin (atau peran dengan akses payroll).
- Anda punya izin untuk melihat payrun.

## Langkah

1. Buka [Daftar Payrun](/docs/manual/pages/payroll-list) (di bawah Payroll).
2. Gunakan pencarian atau filter tanggal jika perlu mencari payrun tertentu. Tabel menampilkan Nama Payrun, Total Slip Gaji, Total Gaji, Status Slip Gaji, Status Generasi, Pembaruan Terakhir.
3. Untuk melihat satu payrun secara detail, buka dari menu baris (mis. **Lihat** atau **Detail**). Anda akan diarahkan ke halaman [Detail Payrun](/docs/manual/pages/payroll-detail) (URL berisi ID payrun).
4. Di halaman detail Anda bisa melihat informasi payrun. Untuk mengedit atau memproses payrun, gunakan tautan atau tombol ke [Edit Payrun](/docs/manual/pages/payroll-edit) (alur proses payrun).

## Hasil yang diharapkan

Anda melihat daftar payrun dan bisa membuka payrun untuk melihat detailnya (dan dari sana lanjut memproses jika perlu).

## Kesalahan umum

- **Tidak melihat Daftar Payrun** — Peran Anda mungkin tidak punya akses payroll. Tanyakan ke admin.
- **Halaman detail tidak ditemukan** — Buka payrun dari daftar agar URL berisi ID payrun yang valid.
