# Lihat profil karyawan

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu melihat profil dan detail satu karyawan.

## Prasyarat

- Anda masuk (HR, Admin, atau pengguna dengan akses ke data karyawan).
- Anda punya izin untuk melihat detail karyawan.

## Langkah

1. Buka [Daftar Karyawan](/docs/manual/pages/employee-management).
2. Cari atau gulir untuk menemukan karyawan.
3. Buka menu baris dan pilih **Lihat** (atau opsi yang membuka profil), atau klik nama karyawan jika berupa tautan. Anda akan diarahkan ke halaman [Detail Karyawan](/docs/manual/pages/employee-management-detail) (URL berisi ID karyawan).
4. Di halaman detail Anda bisa melihat informasi karyawan. Dari sini Anda juga bisa **Edit** jika punya izin.

## Hasil yang diharapkan

Anda melihat profil karyawan dengan informasi yang dikonfigurasi untuk peran Anda (mis. kontak, posisi, departemen, saldo cuti).

## Kesalahan umum

- **Halaman tidak ditemukan** — ID di URL mungkin tidak valid. Buka karyawan dari daftar, jangan ketik URL.
- **Informasi hilang** — Beberapa kolom mungkin disembunyikan oleh peran atau belum diisi. Jika butuh data lebih, tanyakan ke admin atau minta karyawan memperbarui profil jika diizinkan.
