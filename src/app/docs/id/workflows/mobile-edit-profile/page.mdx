# Edit profil di mobile

## Kapan menggunakan

Anda perlu memperbarui detail pribadi yang diizinkan untuk layanan mandiri di mobile.

## Prasyarat

- Sudah masuk; kolom yang diizinkan perusahaan Anda untuk diedit karyawan.

## Langkah

1. Buka **Profile** ([Mobile: Profile](/docs/manual/mobile/pages/mobile-profile)).
2. Ketuk **My Profile** ([Mobile: Profile Detail](/docs/manual/mobile/pages/mobile-profile-detail)).
3. Ketuk **Edit** ([Mobile: Edit Profile](/docs/manual/mobile/pages/mobile-profile-edit)).
4. Ubah kolom yang diizinkan dan simpan.

## Hasil yang diharapkan

Detail profil menampilkan informasi yang diperbarui.

## Kesalahan umum

- **Edit tidak tersedia** — Beberapa kolom hanya untuk HR di web; tanyakan kepada admin Anda.
- **Simpan gagal** — Periksa kolom wajib dan koneksi jaringan.
