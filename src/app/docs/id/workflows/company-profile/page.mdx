# Edit profil perusahaan

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu mengubah informasi perusahaan atau detail bank payroll.

## Prasyarat

- Anda masuk sebagai Admin. Anda punya izin untuk mengedit profil perusahaan.

## Langkah

1. Buka halaman [Profil Perusahaan](/docs/manual/pages/company-profile) di bawah Pengaturan, Perusahaan.
2. Klik Edit Informasi Perusahaan. Anda di halaman [Edit Profil Perusahaan](/docs/manual/pages/company-profile-edit).
3. Ubah kolom sesuai kebutuhan. Simpan.
4. Anda kembali ke halaman Profil Perusahaan. Informasi yang diperbarui ditampilkan.

## Hasil yang diharapkan

Profil perusahaan dan detail payroll diperbarui.

## Kesalahan umum

- **Tidak bisa mengedit** — Peran Anda mungkin tidak punya izin. Tanyakan ke admin.
- **Error validasi** — Pastikan kolom wajib terisi dan format valid.
