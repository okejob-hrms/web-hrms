# Lengkapi penilaian diri di mobile

## Kapan menggunakan

Perusahaan Anda membuka periode penilaian diri dan Anda harus mengirim skor dari ponsel.

## Prasyarat

- Periode penilaian aktif dikonfigurasi di HRMS.

## Langkah

1. Buka **Performance** ([Mobile: Performance](/docs/manual/mobile/pages/mobile-performance)).
2. Ketuk **Self Assessment** ([Mobile: Self Assessment](/docs/manual/mobile/pages/mobile-self-assessment)).
3. Buka baris penilaian → [Mobile: Assessment Form](/docs/manual/mobile/pages/mobile-assessment-form).
4. Isi skor dan komentar, lalu kirim.

## Hasil yang diharapkan

Penilaian diri Anda menampilkan status terkirim untuk periode tersebut.

## Kesalahan umum

- **Tidak ada penilaian terdaftar** — Periode mungkin belum dibuka; tanyakan ke HR.
- **Tidak dapat mengirim** — Lengkapi semua kolom dan bagian wajib.
