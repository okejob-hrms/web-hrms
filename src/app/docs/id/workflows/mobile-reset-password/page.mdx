# Atur ulang kata sandi di mobile

## Kapan menggunakan

Anda lupa kata sandi aplikasi mobile dan memerlukan tautan reset melalui email.

## Prasyarat

- Anda mengetahui alamat email yang terdaftar di HRMS.

## Langkah

1. Di [Mobile: Login](/docs/manual/mobile/pages/mobile-login), ketuk **Reset Password**.
2. Di [Mobile: Reset Password](/docs/manual/mobile/pages/mobile-reset-password), masukkan email Anda dan kirim.
3. Buka [Mobile: Check Email](/docs/manual/mobile/pages/mobile-reset-password-check-email) dan ikuti tautan di kotak masuk Anda.
4. Atur kata sandi baru di [Mobile: Create Password](/docs/manual/mobile/pages/mobile-create-password) jika diminta.
5. Konfirmasi [Mobile: Password Reset Success](/docs/manual/mobile/pages/mobile-reset-password-success), lalu masuk dengan [Masuk ke aplikasi mobile](/docs/workflows/mobile-sign-in).

## Hasil yang diharapkan

Anda dapat masuk dengan kata sandi baru di aplikasi mobile.

## Kesalahan umum

- **Email tidak diterima** — Periksa spam; pastikan email sesuai catatan HR; tanyakan kepada admin Anda.
- **Tautan kedaluwarsa** — Minta reset lagi dari layar login.
