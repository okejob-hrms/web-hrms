# Selesaikan penilaian supervisor

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda supervisor dan perlu menyelesaikan penilaian untuk karyawan (setelah mereka mengirim penilaian diri atau ketika periode mengharuskan).

## Prasyarat

- Anda masuk sebagai supervisor atau HR/Admin.
- Anda punya izin untuk menyelesaikan penilaian supervisor.
- Karyawan telah menyelesaikan (atau periode mengizinkan) penilaian diri, jika itu wajib.

## Langkah

1. Buka [Daftar Penilaian Supervisor](/docs/manual/pages/supervisor-assessment) (di bawah Kinerja).
2. Temukan penilaian yang perlu diselesaikan. Buka (mis. dari menu baris atau dengan mengklik baris). Anda akan diarahkan ke halaman [Detail Penilaian Supervisor](/docs/manual/pages/supervisor-assessment-detail) (URL berisi ID penilaian).
3. Di halaman detail, isi form penilaian supervisor (pertanyaan, rating, komentar sesuai template). Gunakan template form yang dikonfigurasi di [Template Penilaian Supervisor](/docs/manual/pages/form-template-supervisor) (Pengaturan).
4. Simpan atau kirim penilaian. Status diperbarui dan karyawan (atau HR) bisa melihat hasil sesuai proses perusahaan.

## Hasil yang diharapkan

Penilaian supervisor selesai dan dikirim. Tercatat dan bisa digunakan untuk tinjauan kinerja.

## Kesalahan umum

- **Tidak bisa membuka penilaian** — Peran Anda mungkin tidak punya akses, atau penilaian mungkin tidak dalam status yang mengizinkan input supervisor. Tanyakan ke admin.
- **Pertanyaan hilang** — Form berdasarkan template di Pengaturan. Jika form terlihat tidak lengkap, minta admin memeriksa [Template Penilaian Supervisor](/docs/manual/pages/form-template-supervisor).
