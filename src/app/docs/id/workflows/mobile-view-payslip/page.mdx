# Lihat slip gaji di mobile

## Kapan menggunakan

Anda ingin melihat slip gaji di ponsel.

## Prasyarat

- Data slip gaji dipublikasikan untuk catatan karyawan Anda.

## Langkah

1. Buka tab **Profile** ([Mobile: Profile](/docs/manual/mobile/pages/mobile-profile)).
2. Ketuk **My Payslip** ([Mobile: Payslip](/docs/manual/mobile/pages/mobile-payslip)).
3. Pilih periode. Jika perusahaan Anda mewajibkan persetujuan, lengkapi [Mobile: Payslip View Request](/docs/manual/mobile/pages/mobile-payslip-view-request).
4. Buka [Mobile: Payslip View](/docs/manual/mobile/pages/mobile-payslip-view) untuk membaca detail.

## Hasil yang diharapkan

Anda dapat membaca jumlah slip gaji untuk periode yang dipilih. Setelah HR menyetujui permintaan lihat, akses berlaku selama **3 hari**. Setelah itu Anda harus mengajukan ulang.

## Kesalahan umum

- **Daftar slip gaji kosong** — HR mungkin belum mempublikasikan data gaji; tanyakan kepada admin Anda.
- **Akses kedaluwarsa** — Akses lihat berlaku 3 hari sejak disetujui. Ajukan ulang akses dari My Payslip.
- **Permintaan cetak** — Gunakan [Mobile: Payslip Print Request](/docs/manual/mobile/pages/mobile-payslip-print-request) jika Anda memerlukan salinan fisik.
