# Edit karyawan

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu mengubah informasi karyawan (mis. nama, posisi, departemen, detail kontak).

## Prasyarat

- Anda masuk sebagai HR atau Admin.
- Anda punya izin untuk mengedit karyawan.
- Anda tahu karyawan mana yang akan diedit (mis. dari [Daftar Karyawan](/docs/manual/pages/employee-management)).

## Langkah

1. Buka [Daftar Karyawan](/docs/manual/pages/employee-management) dan cari karyawan, atau buka halaman [Detail Karyawan](/docs/manual/pages/employee-management-detail) mereka.
2. Dari daftar, buka menu baris dan pilih **Edit**, atau di halaman detail klik **Edit**. Anda akan diarahkan ke halaman [Edit Karyawan](/docs/manual/pages/employee-management-edit) (URL berisi ID karyawan).
3. Ubah kolom sesuai kebutuhan (mis. nama, posisi, departemen).
4. Klik **Simpan** (atau **Perbarui**). Perbaiki error validasi jika ditampilkan.
5. Setelah berhasil, Anda biasanya kembali ke halaman detail atau daftar.

## Hasil yang diharapkan

Informasi karyawan diperbarui dan perubahan terlihat di halaman detail dan daftar.

## Kesalahan umum

- **Tidak menemukan Edit** — Gunakan menu baris di daftar karyawan atau tombol Edit di halaman detail karyawan. Jika tidak melihat keduanya, tanyakan ke admin.
- **Perubahan tidak tersimpan** — Periksa pesan validasi; pastikan kolom wajib masih valid dan simpan lagi.
