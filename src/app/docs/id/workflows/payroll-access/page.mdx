# Permintaan akses payroll

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu meminta akses untuk melihat atau mencetak slip gaji (mis. karyawan meminta akses slip gaji mereka atau HR memproses permintaan).

## Prasyarat

- Anda masuk. Karyawan bisa meminta akses slip gaji sendiri; HR/Admin mungkin punya alur terpisah untuk menyetujui atau memproses permintaan.
- Anda punya izin untuk menggunakan fitur permintaan payroll.

## Langkah

1. Buka halaman [Permintaan Akses](/docs/manual/pages/payroll-request) (di bawah Payroll).
2. Ikuti langkah di layar untuk meminta akses atau melihat/mencetak slip gaji (mis. pilih periode gaji, kirim permintaan). Jika aplikasi menampilkan daftar permintaan, Anda bisa membuat baru atau membuka yang ada.
3. Kirim permintaan. Jika perusahaan membutuhkan persetujuan, permintaan mungkin tampil sebagai Tertunda sampai admin menyetujui. Setelah disetujui, Anda bisa melihat atau mencetak slip gaji sesuai yang diizinkan.

## Hasil yang diharapkan

Permintaan Anda dikirim. Anda bisa melihat atau mencetak slip gaji yang diminta setelah proses selesai (dan Anda punya akses).

## Kesalahan umum

- **Tidak melihat Permintaan Akses** — Peran Anda mungkin tidak punya akses. Tanyakan ke admin cara meminta slip gaji.
- **Tidak ada slip gaji untuk periode** — Payrun untuk periode tersebut mungkin belum selesai. Periksa dengan HR atau coba lagi setelah payrun diproses.
