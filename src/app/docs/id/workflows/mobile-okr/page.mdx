# Tinjau OKR di mobile

## Kapan menggunakan

Anda perlu melihat atau memperbarui objective dan key result di ponsel.

## Prasyarat

- Data OKR ada untuk karyawan dan periode Anda.

## Langkah

1. Buka **Performance** → OKR ([Mobile: OKR List](/docs/manual/mobile/pages/mobile-okr-list)).
2. Ketuk sebuah objective ([Mobile: OKR Detail](/docs/manual/mobile/pages/mobile-okr)).
3. Buka key result ([Mobile: OKR Key Result](/docs/manual/mobile/pages/mobile-okr-key-result)) untuk memperbarui progres jika diizinkan.

## Hasil yang diharapkan

Anda dapat membaca progres OKR dan menyimpan pembaruan di mana pengeditan diaktifkan.

## Kesalahan umum

- **Daftar OKR kosong** — HR harus menetapkan OKR untuk periode tersebut.
- **Kolom hanya baca** — Beberapa periode mengunci pengeditan setelah batas waktu.
