# Masuk ke aplikasi mobile

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda membuka **ESS CPS** di ponsel dan perlu masuk dengan email kerja dan kata sandi.

## Prasyarat

- Aplikasi mobile terpasang dan dapat terhubung ke API perusahaan Anda.
- Anda memiliki akun karyawan (email dan kata sandi dari HR).

## Langkah

1. Buka aplikasi ESS CPS. Jika belum masuk, Anda melihat [Mobile: Login](/docs/manual/mobile/pages/mobile-login).
2. Masukkan **email** Anda di kolom Email.
3. Masukkan **kata sandi** Anda di kolom Password.
4. Ketuk **Sign In**.
5. Jika ini login pertama, lengkapi [Mobile: Create Password](/docs/manual/mobile/pages/mobile-create-password) saat diminta. Jika tidak, Anda diarahkan ke [Mobile: Home](/docs/manual/mobile/pages/mobile-dashboard).

## Hasil yang diharapkan

Anda sudah masuk dan tab **Home** menampilkan nama, cabang, dan tindakan clock-in. Navigasi bawah menampilkan lima tab.

## Kesalahan umum

- **Email atau kata sandi wajib diisi** — Ketuk setiap kolom sebelum mengetik; pastikan kedua kolom terisi.
- **Kredensial tidak valid** — Konfirmasi email dan kata sandi dengan HR; gunakan [Atur ulang kata sandi di mobile](/docs/workflows/mobile-reset-password) jika perlu.
- **Anda membuka Web ESS** — Gunakan aplikasi mobile yang terpasang untuk alur kerja di ponsel; Web ESS ada di browser pada `/ess`.
