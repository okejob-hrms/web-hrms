# Konfigurasi pengaturan kehadiran

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu melihat atau mengubah aturan kehadiran seperti waktu check-in/out dan ambang terlambat.

## Prasyarat

- Anda masuk sebagai Admin. Anda punya izin untuk mengedit pengaturan kehadiran.

## Langkah

1. Buka halaman [Pengaturan Kehadiran](/docs/manual/pages/attendance-config) di bawah Pengaturan, Waktu dan Kehadiran.
2. Tinjau pengaturan saat ini. Untuk mengubah, klik Edit. Anda di halaman [Edit Pengaturan Kehadiran](/docs/manual/pages/attendance-config-edit).
3. Perbarui kolom. Simpan.
4. Kembali ke halaman Pengaturan Kehadiran. Aturan baru berlaku.

## Hasil yang diharapkan

Aturan kehadiran diperbarui. Sistem menggunakan pengaturan baru untuk validasi dan pelaporan kehadiran.

## Kesalahan umum

- **Tidak bisa mengedit** — Peran Anda mungkin tidak punya izin. Tanyakan ke admin.
- **Simpan dinonaktifkan** — Isi semua kolom wajib dan periksa pesan validasi.
