# Konfigurasi tipe cuti

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu menambah tipe cuti baru atau mengubah tipe cuti yang ada dan aturannya.

## Prasyarat

- Anda masuk sebagai Admin. Anda punya izin untuk mengelola pengaturan cuti.

## Langkah

1. Buka halaman [Pengaturan Cuti](/docs/manual/pages/leave-management) di bawah Pengaturan. Gunakan tab Tipe Cuti.
2. Untuk menambah tipe cuti: Klik Tipe Cuti Baru. Anda di halaman [Tambah Tipe Cuti](/docs/manual/pages/leave-management-add). Isi Nama Cuti, Deskripsi, hak Jenis Kelamin, dan Pengaturan Kuota. Simpan.
3. Untuk mengedit tipe cuti: Buka menu baris dan pilih Edit. Ubah kolom dan simpan.
4. Tipe cuti baru atau yang diperbarui muncul di daftar dan bisa digunakan saat mengajukan cuti.

## Hasil yang diharapkan

Tipe cuti ditambah atau diperbarui. Karyawan dan HR bisa memilih tipe ini saat mengajukan cuti.

## Kesalahan umum

- **Tidak bisa menambah atau mengedit** — Peran Anda mungkin tidak punya izin. Tanyakan ke admin.
- **Halaman edit tidak ditemukan** — Gunakan Edit dari menu baris di daftar Pengaturan Cuti agar URL punya ID tipe cuti yang valid.
