# Konfigurasi komponen gaji

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu mengatur atau mengubah gaji pokok, tunjangan, atau potongan (mis. berdasarkan posisi/level jabatan, potongan wajib).

## Prasyarat

- Anda masuk sebagai Admin (atau peran dengan izin pengelolaan gaji).
- Anda punya izin untuk mengelola pengaturan gaji pokok, tunjangan, atau potongan.

## Langkah

1. Buka Pengaturan, Pengelolaan Gaji. Ada tiga area:
   - [Gaji Pokok](/docs/manual/pages/salary-base) — Atur gaji pokok berdasarkan posisi dan level jabatan. Klik **Tambah Gaji Pokok** untuk menambah entri; gunakan menu baris untuk edit atau hapus.
   - [Tunjangan](/docs/manual/pages/salary-allowance) — Atur tunjangan berdasarkan tipe dan level jabatan. Klik **Atur Tunjangan** untuk menambah; gunakan menu baris untuk edit atau hapus.
   - [Potongan](/docs/manual/pages/salary-deduction) — Atur potongan (mis. wajib, kebijakan perusahaan). Klik **Atur Potongan Gaji** untuk menambah; gunakan menu baris untuk edit atau hapus.
2. Untuk setiap komponen, isi kolom wajib (mis. posisi, level, jumlah atau persentase, tanggal berlaku). Simpan.
3. Perubahan berlaku untuk perhitungan payroll periode dan karyawan yang relevan.

## Hasil yang diharapkan

Gaji pokok, tunjangan, atau potongan ditambah atau diperbarui. Payroll dan payrun menggunakan konfigurasi baru.

## Kesalahan umum

- **Tidak melihat Pengelolaan Gaji** — Peran Anda mungkin tidak punya izin. Tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Periksa kolom wajib dan tanggal berlaku. Jika tidak melihat tombol, tanyakan ke admin.
