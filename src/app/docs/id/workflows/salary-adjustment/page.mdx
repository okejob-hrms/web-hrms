# Proses penyesuaian gaji

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu memproses atau menyesuaikan gaji untuk karyawan offboarding (gaji akhir, jumlah proporsional).

## Prasyarat

- Anda masuk sebagai HR atau Admin.
- Anda punya izin untuk memproses penyesuaian gaji offboarding.
- Kasus offboarding ada. Buka dari [Detail Offboarding](/docs/manual/pages/offboarding-detail).

## Langkah

1. Buka kasus offboarding dari [Daftar Offboarding](/docs/manual/pages/offboarding) atau [Detail Offboarding](/docs/manual/pages/offboarding-detail).
2. Buka langkah penyesuaian gaji, atau buka [Penyesuaian Gaji Offboarding](/docs/manual/pages/offboarding-salary-adjustment). URL berisi ID offboarding.
3. Tinjau atau masukkan detail penyesuaian gaji. Ikuti langkah di layar.
4. Simpan atau kirim penyesuaian. Konfirmasi jika aplikasi meminta konfirmasi.

## Hasil yang diharapkan

Penyesuaian gaji untuk karyawan offboarding tercatat dan bisa digunakan untuk pemrosesan gaji akhir.

## Kesalahan umum

- **Halaman tidak ditemukan** — Buka penyesuaian dari detail atau daftar offboarding agar URL punya ID offboarding yang valid.
- **Tidak bisa menyimpan** — Periksa kolom wajib dan pesan validasi. Jika tidak punya izin, tanyakan ke admin.
