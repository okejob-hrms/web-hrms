# Mulai offboarding

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu memulai proses offboarding untuk karyawan yang keluar.

## Prasyarat

- Anda masuk sebagai HR atau Admin.
- Anda punya izin untuk memulai offboarding.
- Karyawan ada di sistem dan offboarding sesuai (mis. pengunduran diri, akhir kontrak).

## Langkah

1. Buka [Daftar Offboarding](/docs/manual/pages/offboarding).
2. Klik tombol untuk memulai offboarding baru (mis. **Mulai Offboarding** atau **Tambah**). Jika alur dimulai dari tempat lain (mis. detail karyawan), ikuti jalur tersebut.
3. Pilih karyawan dan isi detail yang wajib (mis. tipe offboarding, tanggal). Kirim.
4. Catatan offboarding baru muncul di daftar. Buka untuk ke [Detail Offboarding](/docs/manual/pages/offboarding-detail) (URL berisi ID offboarding).
5. Selesaikan langkah offboarding seperti yang ditampilkan (mis. serah terima, dokumen). Gunakan [Penyesuaian Gaji Offboarding](/docs/manual/pages/offboarding-salary-adjustment) ketika Anda perlu menyesuaikan gaji akhir.

## Hasil yang diharapkan

Kasus offboarding dibuat dan Anda bisa melacak dan menyelesaikannya dari halaman daftar dan detail.

## Kesalahan umum

- **Tidak bisa memulai offboarding** — Peran Anda mungkin tidak punya izin. Tanyakan ke admin.
- **Karyawan tidak ditemukan** — Pastikan karyawan ada di [Daftar Karyawan](/docs/manual/pages/employee-management) dan Anda memilih orang yang benar.
