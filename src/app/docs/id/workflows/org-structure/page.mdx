# Kelola struktur organisasi

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu melihat bagan organisasi atau mengubah jalur pelaporan (siapa melapor ke siapa).

## Prasyarat

- Anda masuk sebagai HR atau Admin.
- Anda punya izin untuk melihat atau mengedit struktur organisasi.

## Langkah

1. Buka halaman [Struktur Organisasi](/docs/manual/pages/org-structure) (di bawah Karyawan atau Organisasi).
2. Untuk **melihat** struktur, gunakan grafik atau daftar yang ditampilkan. Anda bisa memperluas atau memfilter jika aplikasi mendukung.
3. Untuk **mengubah** jalur pelaporan, klik **Edit** (atau buka [Edit Struktur Organisasi](/docs/manual/pages/org-structure-edit)). Pindahkan atau tetapkan karyawan ke manajer yang berbeda sesuai kebutuhan, lalu simpan.

## Hasil yang diharapkan

Anda bisa melihat bagan organisasi dan, jika punya izin, memperbarui hubungan pelaporan. Perubahan tercermin di struktur.

## Kesalahan umum

- **Tidak bisa mengedit** — Opsi Edit mungkin dibatasi. Jika Anda perlu mengubah struktur, tanyakan ke admin.
- **Perubahan tidak tercermin** — Simpan edit dan segarkan; jika masih salah, buka lagi layar edit dan pastikan manajer yang benar dipilih.
