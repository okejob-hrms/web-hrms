# Lengkapi serah terima offboarding di mobile

## Kapan menggunakan

Anda dalam proses offboarding aktif dan harus menyelesaikan langkah serah terima di mobile.

## Prasyarat

- Catatan offboarding aktif untuk akun Anda.

## Langkah

1. Buka offboarding dari Home atau entri ESS ([Mobile: Offboarding](/docs/manual/mobile/pages/mobile-offboarding)).
2. Lengkapi [Mobile: Exit Form](/docs/manual/mobile/pages/mobile-exit-form) dan jadwalkan jika diperlukan ([Mobile: Exit Interview Schedule](/docs/manual/mobile/pages/mobile-exit-schedule)).
3. Kirim [Mobile: Work Handover](/docs/manual/mobile/pages/mobile-work-handover), [Mobile: Document Handover](/docs/manual/mobile/pages/mobile-document-handover), dan [Mobile: Responsibility Handover](/docs/manual/mobile/pages/mobile-responsibility-handover) sesuai penugasan.

## Hasil yang diharapkan

Langkah serah terima menampilkan status selesai di checklist offboarding.

## Kesalahan umum

- **Tidak ada kartu offboarding** — Offboarding mungkin belum dimulai; HR memulai proses di web.
- **Tidak dapat menetapkan serah terima** — Verifikasi Anda adalah karyawan yang bertanggung jawab untuk setiap langkah.
