# Ajukan lembur

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu mengirim pengajuan lembur (sebagai karyawan atau sebagai HR/Admin atas nama orang lain).

## Prasyarat

- Anda masuk. Karyawan mungkin menggunakan [Lembur ESS](/docs/manual/pages/ess-overtime) atau bagian lembur; HR/Admin menggunakan area kehadiran.
- Anda punya izin untuk mengajukan lembur.
- Anda tahu tanggal, jam, dan alasan (dan kolom wajib lainnya).

## Langkah

1. Buka halaman [Lembur](/docs/manual/pages/overtime) (dari menu di bawah Kehadiran atau dari ESS).
2. Klik tombol untuk menambah pengajuan lembur baru (mis. **Tambah Lembur** atau **Pengajuan Baru**).
3. Isi kolom wajib (mis. tanggal, jam, alasan). Pilih karyawan jika Anda mengirim atas nama orang lain.
4. Kirim pengajuan. Muncul di daftar lembur dengan status Tertunda (atau serupa) sampai persetujuan menindak.

## Hasil yang diharapkan

Pengajuan lembur dikirim dan muncul di daftar. Menunggu persetujuan sesuai aturan perusahaan.

## Kesalahan umum

- **Tidak bisa mengirim** — Pastikan kolom wajib terisi dan jam dalam batas yang diatur di [Pengaturan Lembur](/docs/manual/pages/overtime-config) (jika berlaku). Tanyakan ke admin jika tidak melihat tombol tambah.
- **Pengajuan ditolak** — Tinjau alasan penolakan. Pastikan pengajuan sesuai kebijakan perusahaan (mis. jam maks per hari/minggu). Anda bisa mengirim pengajuan baru jika diizinkan.
