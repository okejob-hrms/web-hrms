# Buat atau perbarui OKR

## Kapan menggunakan

Gunakan alur kerja ini ketika Anda perlu membuat siklus OKR baru atau memperbarui yang ada.

## Prasyarat

- Anda masuk. Anda punya izin untuk membuat atau mengedit OKR.

## Langkah

1. Buka [Daftar OKR](/docs/manual/pages/okr).
2. Untuk membuat: Klik tombol untuk menambah OKR baru. Isi nama siklus, periode, dan objective atau key result. Simpan.
3. Untuk memperbarui: Buka OKR yang ada dari daftar. Anda akan diarahkan ke halaman [Detail OKR](/docs/manual/pages/okr-detail). Edit objective atau key result. Simpan.

## Hasil yang diharapkan

Siklus OKR baru dibuat atau yang ada diperbarui. Halaman daftar dan detail menampilkan data terbaru.

## Kesalahan umum

- **Tidak bisa menambah atau mengedit** — Peran Anda mungkin tidak punya izin OKR. Tanyakan ke admin.
- **Halaman detail tidak ditemukan** — Buka OKR dari daftar agar URL berisi ID OKR yang valid.
