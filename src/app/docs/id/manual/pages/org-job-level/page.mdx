# Level Jabatan

## Tujuan

Lihat dan kelola level jabatan (mis. Direktur, Manager, Junior Staff) dan level numeriknya. Anda dapat menambah level baru dan menggunakan tindakan baris untuk mengedit masing-masing.

## Tangkapan layar

![Level Jabatan](/manual/pages/org-job-level.png)

## Di halaman ini

1. **Level Jabatan Baru** — Buka formulir untuk membuat level jabatan baru.
2. **Tabel level jabatan** — Daftar nama level jabatan, nomor level, dan pembaruan terakhir.
3. **Tindakan baris** — Menu pada setiap baris untuk mengedit atau mengelola level tersebut.
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Level Jabatan Baru | Membuka formulir untuk menambah level jabatan. | Jika Anda tidak melihat ini, tanyakan kepada admin. |
| 2 | Tabel level jabatan | Menampilkan semua level jabatan dan nilai levelnya. | |
| 3 | Tindakan baris | Edit atau tindakan lain per level. | |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Tambah level jabatan** — Klik **+ Level Jabatan Baru**, masukkan nama dan level, dan simpan.
- **Edit level** — Buka tindakan baris pada baris tersebut dan pilih edit.
- **Lihat hierarki** — Gunakan tabel untuk melihat level (mis. 1 = Junior, 5 = Direktur).

## Pemecahan masalah

- **Daftar kosong** — Level jabatan mungkin belum diatur, atau akses mungkin dibatasi. Tanyakan kepada admin.
- **Tidak dapat menambah atau edit** — Tindakan ini mungkin dibatasi. Jika Anda tidak melihatnya, tanyakan kepada admin.
