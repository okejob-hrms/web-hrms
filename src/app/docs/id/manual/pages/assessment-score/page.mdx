# Ambang Batas Skor Penilaian

## Tujuan

Melihat dan mengelola ambang batas skor penilaian: label (mis. A, B) dan rentang skor. Gunakan **Tambah Skor** untuk menambah; gunakan aksi baris untuk edit atau hapus.

## Screenshot

![Ambang Batas Skor Penilaian](/manual/pages/assessment-score.png)

## Di halaman ini

1. **Tambah Skor** — Buka form untuk menambah ambang batas skor.
2. **Tabel skor** — Label Skor, Rentang Skor.
3. **Aksi baris** — Menu pada setiap baris (mis. Edit, Hapus).
4. **Paginasi** — Sebelumnya / Berikutnya dan nomor halaman.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Tambah Skor | Membuka form tambah. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel skor | Daftar label dan rentang (mis. 0–20, 21–40). | |
| 3 | Aksi baris | Edit atau hapus ambang batas tersebut. | |
| 4 | Paginasi | Pindah antar halaman. | |

## Tugas umum

- **Tambah ambang batas** — Klik **Tambah Skor**, masukkan label dan rentang skor, lalu simpan.
- **Edit ambang batas** — Buka aksi baris dan pilih Edit.
- **Cek rentang** — Pastikan rentang tidak tumpang tindih dan mencakup skala penuh yang digunakan dalam penilaian.

## Pemecahan masalah

- **Daftar kosong** — Tambah ambang batas skor atau periksa akses. Jika tidak melihat daftar, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Mungkin dibatasi. Jika tidak terlihat, tanyakan ke admin.
