# Edit Tipe Cuti

## Tujuan

Mengubah tipe cuti yang ada. Anda membuka halaman ini dengan memilih **Edit** dari menu baris di daftar Pengaturan Cuti; URL berisi ID tipe cuti. Simpan untuk menerapkan; Batal untuk membatalkan.

## Screenshot

![Edit Tipe Cuti](/manual/pages/leave-management-edit.png)

## Di halaman ini

1. **Form cuti** — Kolom yang sama dengan Tambah (Nama Cuti, Deskripsi, Jenis Kelamin, Pengaturan Kuota).
2. **Batal** — Kembali tanpa menyimpan.
3. **Simpan** — Simpan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Form cuti | Edit nama, hak, kuota. | |
| 2 | Batal | Batalkan perubahan. | |
| 3 | Simpan | Menerapkan perubahan. | |

## Tugas umum

- **Ubah kuota** — Perbarui Kuota (hari) atau opsi, lalu **Simpan**.
- **Ubah siapa yang berhak** — Perbarui Jenis Kelamin dan **Simpan**.

## Pemecahan masalah

- **Halaman tidak ditemukan (404)** — Buka Edit dari menu baris di Pengaturan Cuti untuk tipe cuti yang valid; jangan gunakan ID acak di URL.
- **Tidak bisa mengakses** — Jika tidak melihat Edit di menu baris, tanyakan ke admin.
