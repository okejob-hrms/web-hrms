# Edit Struktur Organisasi

## Tujuan

Ubah siapa melapor ke siapa. Anda melihat daftar karyawan yang dikelompokkan menurut posisi dan bagan yang dapat diedit; seret atau tetapkan orang untuk memperbarui struktur.

## Tangkapan layar

![Edit Struktur Organisasi](/manual/pages/org-structure-edit.png)

## Di halaman ini

1. **Kembali** — Kembali ke halaman struktur organisasi hanya-lihat.
2. **Pencarian Daftar Karyawan** — Cari karyawan berdasarkan nama atau posisi untuk ditetapkan ke bagan.
3. **Grup posisi** — Daftar karyawan menurut posisi (mis. Team Leader, Manager); perluas untuk melihat nama.
4. **Nama karyawan** — Klik untuk menambah atau memindahkan orang di bagan.
5. **Bagan organisasi** — Bagan yang dapat diedit tempat Anda menetapkan atau memindahkan node.
6. **Kontrol zoom** — Zoom in atau out pada bagan.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Kembali | Kembali ke Struktur Organisasi (lihat). | |
| 2 | Pencarian Daftar Karyawan | Cari berdasarkan nama atau posisi. | |
| 3 | Grup posisi | Daftar yang dapat diperluas menurut jabatan. | |
| 4 | Nama karyawan | Klik untuk menetapkan atau memindahkan di bagan. | |
| 5 | Bagan organisasi | Struktur pelaporan yang dapat diedit. | |
| 6 | Kontrol zoom | Sesuaikan zoom bagan. | |

## Tugas umum

- **Tetapkan seseorang ke bagan** — Temukan mereka di daftar (gunakan pencarian atau grup posisi), lalu klik atau seret ke bagan.
- **Ubah jalur pelaporan** — Pindahkan orang di bagan atau tetapkan ulang dari daftar.
- **Selesai** — Gunakan **Kembali** untuk menyimpan dan kembali ke tampilan.

## Pemecahan masalah

- **Tidak dapat melihat halaman edit** — Ini mungkin dibatasi. Jika Anda tidak melihatnya, tanyakan kepada admin.
- **Perubahan tidak tersimpan** — Pastikan Anda kembali melalui **Kembali**; jika masih gagal, segarkan dan coba lagi atau tanyakan kepada admin.
