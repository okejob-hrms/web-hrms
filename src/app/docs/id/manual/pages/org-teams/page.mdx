# Tim

## Tujuan

Lihat dan kelola tim (mis. HR, Keuangan, IT). Anda dapat menambah tim baru dan menggunakan tindakan baris untuk mengedit atau mengelola masing-masing.

## Tangkapan layar

![Tim](/manual/pages/org-teams.png)

## Di halaman ini

1. **Tim Baru** — Buka formulir untuk membuat tim baru.
2. **Tabel tim** — Daftar nama tim, deskripsi, dan pembaruan terakhir.
3. **Tindakan baris** — Menu pada setiap baris untuk mengedit atau mengelola tim tersebut.
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Tim Baru | Membuka formulir untuk menambah tim. | Jika Anda tidak melihat ini, tanyakan kepada admin. |
| 2 | Tabel tim | Menampilkan semua tim. | |
| 3 | Tindakan baris | Edit atau tindakan lain per tim. | |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Tambah tim** — Klik **+ Tim Baru**, masukkan nama dan deskripsi, dan simpan.
- **Edit tim** — Buka tindakan baris pada baris tersebut dan pilih edit.
- **Lihat semua tim** — Gunakan tabel dan paginasi untuk menelusuri.

## Pemecahan masalah

- **Daftar kosong** — Tim mungkin belum diatur, atau akses mungkin dibatasi. Tanyakan kepada admin.
- **Tidak dapat menambah atau edit** — Tindakan ini mungkin dibatasi. Jika Anda tidak melihatnya, tanyakan kepada admin.
