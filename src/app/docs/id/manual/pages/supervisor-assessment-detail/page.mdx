# Detail Penilaian Supervisor

## Tujuan

Melihat satu penilaian supervisor: detail karyawan, posisi dan level target, penilai yang ditetapkan, dan jadwal wawancara. Edit jadwal, selesaikan penilaian, atau batalkan. URL berisi ID penilaian.

## Screenshot

![Detail Penilaian Supervisor](/manual/pages/supervisor-assessment-detail.png)

## Di halaman ini

1. **Detail Karyawan** — Nama, ID, Email, Posisi Saat Ini, Departemen, Level Jabatan, Laporan Langsung, Tanggal Mulai, Posisi Target, Level Jabatan Target, Penilai yang Ditetapkan.
2. **Tab Jadwal Penilaian** — Lihat atau edit jadwal wawancara.
3. **Tab Penilaian Kinerja** — Lihat konten penilaian kinerja.
4. **Jadwal Wawancara** — Tanggal, Waktu, Peserta, Catatan.
5. **Edit Jadwal Wawancara** — Ubah tanggal, waktu, atau peserta.
6. **Selesaikan Proses Penilaian** — Tandai penilaian sebagai selesai.
7. **Batalkan Penilaian Supervisor** — Batalkan penilaian ini.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Detail Karyawan | Menampilkan info karyawan dan target. | URL berisi ID penilaian. |
| 2 | Tab Jadwal Penilaian | Menampilkan bagian jadwal. | |
| 3 | Tab Penilaian Kinerja | Menampilkan bagian kinerja. | |
| 4 | Jadwal Wawancara | Menampilkan tanggal, waktu, peserta, catatan. | |
| 5 | Edit Jadwal Wawancara | Membuka edit jadwal. | Jika tidak terlihat, tanyakan ke admin. |
| 6 | Selesaikan Proses Penilaian | Menyelesaikan proses. | |
| 7 | Batalkan Penilaian Supervisor | Membatalkan penilaian. | Gunakan dengan hati-hati. |

## Tugas umum

- **Edit jadwal** — Klik **Edit Jadwal Wawancara**, ubah tanggal/waktu/peserta, simpan.
- **Selesaikan penilaian** — Setelah selesai, klik **Selesaikan Proses Penilaian**.
- **Batalkan** — Klik **Batalkan Penilaian Supervisor** jika penilaian tidak boleh dilanjutkan.

## Pemecahan masalah

- **Halaman tidak ditemukan** — ID di URL harus valid. Buka dari daftar terlebih dahulu. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa edit atau selesaikan** — Aksi ini mungkin dibatasi oleh peran. Jika tidak melihat tombol, tanyakan ke admin.
