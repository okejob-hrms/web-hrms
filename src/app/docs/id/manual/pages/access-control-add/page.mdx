# Tambah Akses

## Tujuan

Membuat peran baru: masukkan nama dan deskripsi, atur izin berdasarkan fungsionalitas, lalu simpan. Anda dapat menetapkan peran ke karyawan dari sini atau nanti.

## Screenshot

![Tambah Akses](/manual/pages/access-control-add.png)

## Di halaman ini

1. **Informasi Peran** — Nama dan Deskripsi.
2. **Tetapkan Peran/Izin** — Terapkan atau salin template peran/izin.
3. **Tetapkan Karyawan** — Buka dialog untuk menetapkan peran ini ke karyawan.
4. **Tabel izin** — Fungsionalitas dan kotak centang aksi (Lihat, Buat, Edit, dll.).
5. **Batal** — Kembali tanpa menyimpan.
6. **Simpan** — Buat peran.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Informasi Peran | Masukkan nama dan deskripsi peran. | |
| 2 | Tetapkan Peran/Izin | Terapkan template atau atur izin massal. | Jika tidak terlihat, tanyakan ke admin. |
| 3 | Tetapkan Karyawan | Tetapkan peran ini ke karyawan. | |
| 4 | Tabel izin | Atur izin per fungsionalitas. | |
| 5 | Batal | Keluar tanpa menyimpan. | |
| 6 | Simpan | Membuat peran baru. | |

## Tugas umum

- **Buat peran** — Isi Informasi Peran, atur izin di tabel, lalu klik **Simpan**.
- **Gunakan template** — Klik **Tetapkan Peran/Izin** untuk menyalin dari peran atau template lain, lalu sesuaikan dan **Simpan**.

## Pemecahan masalah

- **Tidak bisa menyimpan** — Pastikan Nama terisi. Jika tidak melihat **Simpan** atau **Tetapkan Peran/Izin**, tanyakan ke admin.
- **Izin tidak diterapkan** — Pastikan kotak centang diatur sesuai kebutuhan sebelum **Simpan**.
