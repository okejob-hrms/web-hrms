# Daftar Penilaian Diri

## Tujuan

Melihat dan mengelola periode penilaian diri. Anda dapat membuat penilaian baru, membuka periode untuk melihat progres per karyawan, atau menggunakan menu baris untuk aksi lainnya.

## Screenshot

![Daftar Penilaian Diri](/manual/pages/self-assessment.png)

## Di halaman ini

1. **Penilaian Baru** — Buka form untuk membuat periode penilaian baru.
2. **Tabel penilaian** — Baris menampilkan Periode Penilaian, Status, Tanggal Mulai, Tanggal Akhir, Dibuat Pada, Dikirim (mis. 0/2 Karyawan), Progres, Dibuat Oleh.
3. **Menu baris** — Buka aksi untuk periode tersebut (mis. lihat detail periode).
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Penilaian Baru | Ke form Tambah Penilaian Diri. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel penilaian | Daftar periode; klik baris atau menu untuk membuka. | |
| 3 | Menu baris | Membuka detail periode atau aksi lain. | URL berisi ID periode. |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Buat penilaian** — Klik **+ Penilaian Baru**, atur periode dan opsi, lalu simpan.
- **Lihat periode** — Buka menu baris dan pilih aksi untuk membuka detail periode (URL berisi ID periode).
- **Cek progres** — Gunakan kolom Dikirim dan Progres untuk melihat penyelesaian.

## Pemecahan masalah

- **Daftar kosong** — Belum ada periode penilaian. Buat dengan **+ Penilaian Baru**. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa membuat atau membuka** — Mungkin dibatasi oleh peran. Jika tidak melihat tombol atau menu, tanyakan ke admin.
