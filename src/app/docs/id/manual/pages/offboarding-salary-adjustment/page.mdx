# Penyesuaian Gaji Offboarding

> **Ditandai:** Bagian ini adalah dokumentasi draf. Fitur offboarding belum sepenuhnya diperbaiki. Screenshot dan langkah akan diperbarui setelah fitur selesai.

## Tujuan

Menyesuaikan gaji karyawan dalam proses offboarding. Anda sampai di halaman ini dari detail offboarding; URL adalah `.../off-boarding/{id}/salary-adjustment` dengan `{id}` adalah ID catatan offboarding.

## Screenshot

![Penyesuaian Gaji Offboarding](/manual/pages/offboarding-salary-adjustment.png)

## Di halaman ini

1. **Breadcrumb / Kembali** — Navigasi kembali ke detail offboarding atau daftar.
2. **Form penyesuaian gaji** — Kolom untuk memasukkan atau mengubah nilai terkait gaji untuk offboarding.
3. **Kirim atau Simpan** — Terapkan penyesuaian gaji.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Breadcrumb / Kembali | Kembali ke detail atau daftar. | |
| 2 | Form penyesuaian gaji | Masukkan data penyesuaian gaji. | |
| 3 | Kirim atau Simpan | Menyimpan penyesuaian. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Buka penyesuaian gaji** — Dari halaman detail offboarding, gunakan tautan atau tombol untuk ke penyesuaian gaji untuk catatan tersebut.
- **Terapkan penyesuaian** — Isi form dan klik Kirim atau Simpan.
- **Kembali** — Gunakan breadcrumb atau kontrol kembali untuk kembali tanpa menyimpan.

## Pemecahan masalah

- **Halaman menampilkan error** — Catatan offboarding mungkin hilang atau tidak valid. Kembali ke daftar offboarding dan buka catatan yang valid terlebih dahulu.
- **Tidak bisa menyimpan** — Periksa kolom wajib dan izin. Jika tidak punya akses, tanyakan ke admin.
