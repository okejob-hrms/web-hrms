# Detail Kompetensi

## Tujuan

Melihat kode, nama, deskripsi, dan level kompetensi. Gunakan **Edit** untuk mengubah kompetensi; gunakan **+ Tambah Level** untuk menambah level (dimensi, nama level, deskripsi).

## Screenshot

![Detail Kompetensi](/manual/pages/competencies-detail.png)

## Di halaman ini

1. **Edit** — Buka edit untuk kompetensi ini.
2. **Kode, Nama, Deskripsi Kompetensi** — Tampilan di atas.
3. **Tambah Level** — Tambah baris level ke tabel Level.
4. **Tabel Level** — Dimensi, Level, Nama Level, Deskripsi (dan aksi baris).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Edit | Membuka edit untuk kompetensi ini. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Kode, Nama, Deskripsi Kompetensi | Menampilkan detail kompetensi. | |
| 3 | Tambah Level | Menambah level. | |
| 4 | Tabel Level | Daftar level; edit/hapus per baris. | |

## Tugas umum

- **Lihat kompetensi** — Buka dari daftar Kompetensi; URL berisi ID kompetensi (mis. .../1).
- **Tambah level** — Klik **+ Tambah Level**, isi dimensi dan nama/deskripsi level, lalu simpan.
- **Ubah kompetensi** — Klik **Edit**, perbarui kode/nama/deskripsi, lalu simpan.

## Pemecahan masalah

- **Menampilkan "-" atau tidak ada data** — ID di URL mungkin tidak ada; buka detail dari daftar untuk kompetensi yang valid.
- **Tidak bisa edit atau tambah level** — Jika tidak melihat opsi tersebut, tanyakan ke admin.
