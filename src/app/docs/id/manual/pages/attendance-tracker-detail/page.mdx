# Detail Kehadiran

## Tujuan

Melihat dan mengedit catatan kehadiran yang ada. Halaman menampilkan kolom yang sama dengan Tambah Kehadiran; gunakan **Perbarui** untuk menyimpan perubahan. URL berisi ID karyawan dan ID catatan kehadiran (mis. .../attendance-tracker/9/1).

## Screenshot

![Detail Kehadiran](/manual/pages/attendance-tracker-detail.png)

## Di halaman ini

1. **Kembali** — Kembali ke halaman sebelumnya.
2. **Breadcrumb** — Menampilkan Attendance Tracker dan ID catatan.
3. **Nama Karyawan** — Karyawan terpilih (dapat diedit).
4. **Tanggal** — Tanggal kehadiran.
5. **Shift** — Tipe shift.
6. **Waktu Clock-In** — Waktu clock-in.
7. **Waktu Clock-Out** — Waktu clock-out.
8. **Pilih Lokasi** — Lokasi.
9. **Catatan** — Catatan opsional.
10. **Batal** — Batalkan perubahan dan kembali.
11. **Perbarui** — Simpan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Kembali | Kembali ke daftar atau halaman sebelumnya. | |

| 7 | Waktu Clock-Out | Edit waktu clock-out. | |

## Tugas umum

- **Edit catatan** — Dari daftar, buka aksi baris dan pilih **Edit Catatan Kehadiran**. Ubah kolom dan klik **Perbarui**.
- **Kembali tanpa menyimpan** — Klik **Batal** atau **Kembali**.

## Pemecahan masalah

- **Halaman tidak dimuat** — Catatan mungkin tidak ada atau ID tidak valid. Kembali ke daftar dan buka catatan lain.
- **Tidak bisa memperbarui** — Periksa izin. Jika tidak melihat Perbarui atau gagal, tanyakan ke admin.
