# Daftar Template Form

## Tujuan

Melihat dan mengelola template form (mis. Exit Interview, Penilaian Kompetensi). Gunakan **+ Form Baru** untuk menambah; gunakan aksi baris untuk membuka detail atau edit.

## Screenshot

![Daftar Template Form](/manual/pages/form-template.png)

## Di halaman ini

1. **Form Baru** — Buka layar Tambah Form.
2. **Tabel form** — Nama Form, Penggunaan Form, Pembaruan Terakhir.
3. **Aksi baris** — Menu pada setiap baris (mis. Lihat, Edit).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Form Baru | Ke Tambah Template Form. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel form | Daftar template. | |
| 3 | Aksi baris | Buka detail atau edit untuk form tersebut. | |

## Tugas umum

- **Tambah form** — Klik **+ Form Baru**, atur nama dan penggunaan, tambah pertanyaan, lalu **Simpan**.
- **Lihat form** — Buka aksi baris dan pilih opsi yang membuka detail form (URL berisi ID form).
- **Edit form** — Buka aksi baris dan pilih Edit (mis. .../edit/1 untuk ID form 1).

## Pemecahan masalah

- **Daftar kosong** — Tambah form atau periksa akses. Jika tidak melihat daftar, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Mungkin dibatasi. Jika tidak terlihat, tanyakan ke admin.
