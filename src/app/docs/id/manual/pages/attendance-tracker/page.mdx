# Daftar Kehadiran

## Tujuan

Melihat ringkasan kehadiran dan daftar catatan kehadiran. Anda dapat mencari berdasarkan karyawan, menambah catatan baru, atau membuka menu baris untuk melihat detail, menyetujui, menolak, atau mengedit catatan.

## Screenshot

![Daftar Kehadiran](/manual/pages/attendance-tracker.png)

## Di halaman ini

1. **Bagian ringkasan** — Kartu untuk Terlambat Masuk, Masuk Lebih Awal, Pulang Lebih Awal, Tepat Waktu, Lembur, Tidak Hadir, Hari Libur.
2. **Cari berdasarkan Nama atau Email Karyawan** — Ketik untuk menemukan catatan kehadiran.
3. **Catatan Kehadiran Baru** — Buka form Tambah Kehadiran.
4. **Tabel kehadiran** — Baris menampilkan Nama, Tanggal, Check-In & Out, Shift, Catatan, Status.
5. **Aksi baris** — Menu pada setiap baris (Detail Kehadiran, Setujui, Tolak, Edit, Hapus).
6. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Bagian ringkasan | Menampilkan jumlah untuk setiap tipe kehadiran. | |
| 2 | Cari berdasarkan Nama atau Email Karyawan | Memfilter daftar saat Anda mengetik. | |
| 3 | Catatan Kehadiran Baru | Ke form Tambah Kehadiran. | Jika tidak terlihat, tanyakan ke admin. |
| 4 | Tabel kehadiran | Daftar catatan; gunakan menu baris untuk aksi. | |
| 5 | Aksi baris | Lihat detail, setujui, tolak, edit, atau hapus. | |
| 6 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Lihat ringkasan** — Gunakan kartu ringkasan untuk melihat terlambat, tepat waktu, tidak hadir, dll.
- **Tambah catatan** — Klik **+ Catatan Kehadiran Baru**, isi form, dan simpan.
- **Edit catatan** — Buka aksi baris dan pilih **Edit Catatan Kehadiran**. URL berisi ID karyawan dan ID kehadiran (mis. .../attendance-tracker/9/1).

## Pemecahan masalah

- **Daftar kosong** — Periksa pencarian; hapus atau ubah filter. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Mungkin dibatasi oleh peran. Jika tidak terlihat, tanyakan ke admin.
