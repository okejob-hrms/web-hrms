# Tambah Karyawan

## Tujuan

Gunakan halaman ini untuk menambah karyawan baru. Anda memasukkan detail pribadi, ketenagakerjaan, gaji, bank, dan lampiran. Kolom wajib ditandai dengan asterisk (*).

## Tangkapan layar

![Tambah Karyawan](/manual/pages/employee-management-add.png)

## Di halaman ini

1. **Bagian Informasi Pribadi** — Foto (opsional), Nama, Email, Telepon, Gender, Tempat Lahir, Tanggal Lahir, Status Pernikahan, Golongan Darah, Tinggi, Berat, Nomor ID, NPWP, BPJS, alamat, Hobi, Prestasi, Media Sosial.
2. **Bagian Informasi Ketenagakerjaan** — Perusahaan, Posisi, Departemen, Level Jabatan, Atasan Langsung Utama, Atasan Langsung Tambahan, Tim, Tanggal Mulai Kerja, Tanggal Akhir Kerja, Status.
3. **Bagian Informasi Gaji** — Tunjangan (opsional), Gaji Pokok, Gaji (Bersih). Anda mungkin perlu memilih Level Jabatan terlebih dahulu untuk melihat opsi tunjangan.
4. **Bagian Informasi Bank** — Bank, Nomor Rekening, Nama Rekening.
5. **Bagian Lampiran** — Unggah dokumen wajib (mis. CV, Ijazah, KTP, KK, NPWP, BPJS, Buku Rekening Bank, SIM) dan Opsi Lainnya.
6. **Batal** — Keluar tanpa menyimpan.
7. **Tambah Karyawan** — Simpan karyawan baru.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Informasi Pribadi | Masukkan nama, kontak, dan detail pribadi. | Kolom bertanda * wajib. |
| 2 | Informasi Ketenagakerjaan | Masukkan perusahaan, posisi, departemen, level jabatan, atasan, tim, tanggal, status. | |
| 3 | Informasi Gaji | Masukkan gaji pokok dan gaji bersih. | Pilih Level Jabatan untuk melihat saran tunjangan. |
| 4 | Informasi Bank | Masukkan bank dan detail rekening. | |
| 5 | Lampiran | Unggah file wajib dan opsional. | Setiap tipe dapat wajib (*). |
| 6 | Batal | Batalkan dan kembali. | |
| 7 | Tambah Karyawan | Kirim dan buat karyawan. | |

## Tugas umum

- **Tambah karyawan baru** — Isi semua kolom wajib di setiap bagian, unggah lampiran wajib, lalu klik **Tambah Karyawan**.
- **Keluar tanpa menyimpan** — Klik **Batal**.
- **Tambah tunjangan manual** — Jika Level Jabatan tidak menampilkan tunjangan, gunakan **Tambah Tunjangan Manual** di bagian Gaji.

## Pemecahan masalah

- **Tambah Karyawan dinonaktifkan** — Pastikan semua kolom wajib terisi dan lampiran wajib diunggah.
- **Tidak dapat memilih Posisi atau Departemen** — Pastikan Perusahaan (atau data induk) diatur terlebih dahulu. Jika opsi kosong, tanyakan kepada admin.
- **Unggah gagal** — Periksa ukuran dan tipe file. Coba lagi atau gunakan file lain.
