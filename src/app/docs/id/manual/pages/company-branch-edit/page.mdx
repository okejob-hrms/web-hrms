# Edit Cabang

## Tujuan

Mengedit cabang perusahaan: ubah informasi perusahaan, lokasi, dan detail payroll. URL berisi ID cabang.

## Screenshot

![Edit Cabang](/manual/pages/company-branch-edit.png)

## Di halaman ini

1. **Informasi Perusahaan** — Logo, Nama, Badan Hukum, Industri, Email, Telepon, BRN, Situs Web, Alamat, Pilih Lokasi, Radius Maksimum, Utama.
2. **Informasi Payroll** — Nama Rekening Bank, Nomor, Pemegang, Mata Uang.
3. **Batal** — Kembali tanpa menyimpan.
4. **Simpan** — Simpan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Informasi Perusahaan | Edit detail cabang. | URL berisi ID cabang. |
| 2 | Informasi Payroll | Edit detail bank. | |
| 3 | Batal | Keluar tanpa menyimpan. | |
| 4 | Simpan | Menyimpan perubahan. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Perbarui cabang** — Ubah kolom, lalu **Simpan**.
- **Atur utama** — Gunakan toggle **Utama**, lalu **Simpan**.

## Pemecahan masalah

- **Halaman tidak ditemukan** — ID cabang di URL harus ada. Jika tidak punya akses, tanyakan ke admin.
