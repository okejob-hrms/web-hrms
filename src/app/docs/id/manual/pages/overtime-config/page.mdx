# Pengaturan Lembur

## Tujuan

Melihat aturan lembur: pembagi jam kerja, tarif bertingkat, batas harian/mingguan, dan tarif libur. Gunakan **Edit Pengaturan Lembur** untuk mengubahnya.

## Screenshot

![Pengaturan Lembur](/manual/pages/overtime-config.png)

## Di halaman ini

1. **Rumus & Koefisien Tarif** — Pembagi Jam Kerja (mis. 173 Jam/Bulan).
2. **Tabel Aturan Bertingkat** — Jam Waktu dan Tarif (mis. 0–3 Jam, 4 Jam).
3. **Batas & Ambang** — Lembur Harian/Mingguan Maks, Tolak Otomatis, Proporsi per Menit.
4. **Lembur Libur & Hari Khusus** — Tarif akhir pekan dan libur nasional; tabel Pengecualian Khusus.
5. **Edit Pengaturan Lembur** — Membuka form edit.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Rumus & Koefisien Tarif | Menampilkan pembagi untuk tarif per jam. | |
| 2 | Tabel Aturan Bertingkat | Menampilkan tarif lembur per rentang jam. | |
| 3 | Batas & Ambang | Menampilkan jam maks dan opsi. | |
| 4 | Lembur Libur & Hari Khusus | Menampilkan tarif akhir pekan/libur dan pengecualian. | |
| 5 | Edit Pengaturan Lembur | Membuka layar edit. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Cek tarif** — Tinjau Rumus, Aturan Bertingkat, dan bagian Libur.
- **Ubah aturan** — Klik **Edit Pengaturan Lembur**, perbarui kolom, lalu **Simpan**.

## Pemecahan masalah

- **Tidak bisa mengedit** — Mungkin dibatasi. Jika tidak melihat tombol Edit, tanyakan ke admin.
- **Nilai tidak cocok dengan payroll** — Pastikan pengaturan yang berlaku dan perubahan telah disimpan.
