# Struktur Organisasi

## Tujuan

Lihat bagan organisasi perusahaan. Anda dapat memfilter berdasarkan karyawan, mengunduh bagan, atau beralih ke mode edit untuk mengubah jalur pelaporan.

## Tangkapan layar

![Struktur Organisasi](/manual/pages/org-structure.png)

## Di halaman ini

1. **Filter berdasarkan karyawan** — Persempit bagan untuk menampilkan orang tertentu dan koneksinya.
2. **Unduh** — Simpan bagan sebagai gambar atau file.
3. **Edit Struktur** — Buka halaman edit untuk mengubah siapa melapor ke siapa.
4. **Bagan organisasi** — Bagan yang menampilkan peran dan hubungan pelaporan.
5. **Tindakan node (Telepon, Mail, Profil)** — Tindakan cepat pada node setiap orang.
6. **Kontrol zoom** — Zoom in atau out pada bagan.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Filter berdasarkan karyawan | Memfilter bagan untuk fokus pada satu karyawan. | |
| 2 | Unduh | Mengunduh bagan struktur. | |
| 3 | Edit Struktur | Ke tampilan edit. | Jika Anda tidak melihat ini, tanyakan kepada admin. |
| 4 | Bagan organisasi | Menampilkan peran dan struktur pelaporan. | |
| 5 | Tindakan node | Pintasan Telepon, Mail, Profil pada setiap node. | |
| 6 | Kontrol zoom | Sesuaikan level zoom bagan. | |

## Tugas umum

- **Lihat jalur pelaporan** — Gunakan bagan; zoom atau filter jika perlu.
- **Unduh bagan** — Klik **Unduh**.
- **Ubah struktur** — Klik **Edit Struktur**, lalu tetapkan atau pindahkan orang di bagan.

## Pemecahan masalah

- **Bagan kosong** — Periksa filter; kosongkan "Filter berdasarkan karyawan" atau segarkan. Jika Anda tidak memiliki akses, tanyakan kepada admin.
- **Tidak dapat edit** — Edit Struktur mungkin dibatasi. Jika Anda tidak melihatnya, tanyakan kepada admin.
