# Organisasi ESS

## Tujuan

Halaman ini menampilkan struktur organisasi Anda (bagan organisasi). Anda dapat melihat posisi Anda dan tim Anda di perusahaan. Gunakan kontrol zoom untuk memperbesar atau memperkecil bagan.

## Tangkapan layar

![Organisasi ESS](/manual/pages/ess-organization.png)

## Di halaman ini

1. **Area struktur organisasi** — Tempat bagan organisasi ditampilkan (pohon atau bagan).
2. **Zoom 100%** — Menampilkan level zoom saat ini.
3. **Zoom out** — Mengurangi zoom (melihat lebih banyak bagan).
4. **Zoom in** — Meningkatkan zoom (melihat detail).

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Area struktur organisasi | Menampilkan bagan organisasi. | Dapat kosong jika data belum diatur. |
| 2 | Zoom 100% | Menampilkan zoom saat ini. | Hanya baca. |
| 3 | Zoom out | Memperkecil. | Lihat lebih banyak struktur. |
| 4 | Zoom in | Memperbesar. | Lihat nama dan peran dengan jelas. |

## Tugas umum

- **Lihat bagan organisasi** — Buka halaman; bagan dimuat di area utama.
- **Zoom in atau out** — Gunakan tombol minus dan plus untuk menyesuaikan zoom.
- **Temukan posisi Anda** — Cari nama atau tim Anda di bagan (jika ditampilkan).

## Pemecahan masalah

- **Area bagan kosong** — Data organisasi mungkin belum diatur. Tanyakan kepada admin.
- **Tombol zoom tidak berfungsi** — Coba segarkan halaman. Jika masih gagal, coba browser lain.
- **Tidak menemukan tim saya** — Tampilan mungkin terbatas; gunakan zoom out atau tanyakan kepada admin bagaimana bagan dikonfigurasi.
