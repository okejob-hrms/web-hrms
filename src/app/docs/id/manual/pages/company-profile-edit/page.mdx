# Edit Profil Perusahaan

## Tujuan

Mengedit informasi perusahaan dan detail payroll (bank): nama, badan hukum, kontak, alamat, dan rekening bank. Ubah logo dengan **Pilih Gambar**.

## Screenshot

![Edit Profil Perusahaan](/manual/pages/company-profile-edit.png)

## Di halaman ini

1. **Logo Perusahaan** — **Pilih Gambar** untuk mengubah logo.
2. **Kolom Informasi Perusahaan** — Nama Perusahaan, Badan Hukum, Industri, Email, Telepon, Nomor Registrasi Bisnis, Situs Web, Alamat.
3. **Kolom Informasi Payroll** — Nama Rekening Bank, Nomor, Pemegang, Mata Uang.
4. **Batal** — Kembali tanpa menyimpan.
5. **Simpan** — Simpan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Logo Perusahaan | Ubah gambar logo. | |
| 2 | Kolom Informasi Perusahaan | Edit detail perusahaan. | |
| 3 | Kolom Informasi Payroll | Edit detail bank. | |
| 4 | Batal | Keluar tanpa menyimpan. | |
| 5 | Simpan | Menyimpan perubahan. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Perbarui detail perusahaan** — Edit kolom, lalu klik **Simpan**.
- **Perbarui detail bank** — Edit Informasi Payroll, lalu **Simpan**.

## Pemecahan masalah

- **Tidak bisa menyimpan** — Anda mungkin butuh izin. Jika tidak melihat **Simpan**, tanyakan ke admin.
