# Tambah Kehadiran

## Tujuan

Mencatat entri kehadiran baru untuk karyawan. Pilih karyawan, tanggal, shift, waktu clock-in dan clock-out, lokasi, dan catatan opsional.

## Screenshot

![Tambah Kehadiran](/manual/pages/attendance-tracker-add.png)

## Di halaman ini

1. **Kembali** — Kembali ke Daftar Kehadiran.
2. **Nama Karyawan** — Pilih karyawan.
3. **Tanggal** — Pilih tanggal kehadiran.
4. **Shift** — Pilih shift.
5. **Waktu Clock-In** — Masukkan waktu clock-in.
6. **Waktu Clock-Out** — Masukkan waktu clock-out.
7. **Pilih Lokasi** — Pilih atau atur lokasi.
8. **Catatan** — Catatan opsional.
9. **Batal** — Kembali tanpa menyimpan.
10. **Simpan** — Simpan catatan baru.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Kembali | Kembali ke Daftar Kehadiran. | |
| 2 | Nama Karyawan | Pilih karyawan dari daftar. | |
| 3 | Tanggal | Pilih tanggal untuk catatan. | |
| 4 | Shift | Pilih tipe shift. | |
| 5 | Waktu Clock-In | Masukkan waktu clock-in. | |
| 6 | Waktu Clock-Out | Masukkan waktu clock-out. | |
| 7 | Pilih Lokasi | Atur atau pilih lokasi. | |
| 8 | Catatan | Catatan opsional. | |
| 9 | Batal | Batalkan dan kembali. | |
| 10 | Simpan | Menyimpan catatan kehadiran baru. | |

## Tugas umum

- **Catat kehadiran** — Pilih karyawan dan tanggal, masukkan waktu dan lokasi, tambah catatan jika perlu, lalu klik **Simpan**.
- **Batal** — Klik **Batal** atau **Kembali** untuk kembali tanpa menyimpan.

## Pemecahan masalah

- **Tidak bisa menyimpan** — Periksa kolom wajib (karyawan, tanggal, waktu). Jika tidak punya izin, tanyakan ke admin.
