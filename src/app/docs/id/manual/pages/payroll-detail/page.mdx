# Detail Payrun

## Tujuan

Melihat satu payrun: periode pembayaran, status slip gaji, total pengeluaran perusahaan, dan daftar gaji kotor karyawan. Dari sini Anda dapat mengedit payrun, melihat riwayat, atau meregenerasi.

## Screenshot

![Detail Payrun](/manual/pages/payroll-detail.png)

## Di halaman ini

1. **Edit Payrun** — Buka form edit untuk payrun ini.
2. **Riwayat Payrun** — Lihat riwayat payrun ini.
3. **Regenerasi Payrun** — Regenerasi payrun.
4. **Periode Pembayaran** — Menampilkan periode payrun.
5. **Status Slip Gaji** — Menampilkan status draf atau final.
6. **Total Pengeluaran Perusahaan** — Ringkasan total pengeluaran untuk payrun ini.
7. **Daftar Gaji Kotor Karyawan** — Bagian dengan jumlah karyawan.
8. **Cari berdasarkan Nama, ID, atau Departemen Karyawan** — Filter daftar karyawan.
9. **Tabel slip gaji karyawan** — Baris menampilkan Nama, Jam Kerja, Tunjangan, Lembur, Penghasilan Tambahan, Potongan Penalti, Gaji Kotor, Gaji Bersih.
10. **Paginasi** — Pindah antar halaman karyawan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |

| 1 | Edit Payrun | Ke halaman edit untuk payrun ini. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Riwayat Payrun | Membuka tampilan riwayat. | |
| 3 | Regenerasi Payrun | Meregenerasi payrun. | Gunakan dengan hati-hati. |
| 4 | Periode Pembayaran | Menampilkan periode payrun ini. | |
| 5 | Status Slip Gaji | Menampilkan draf atau final. | |
| 6 | Total Pengeluaran Perusahaan | Menampilkan total pengeluaran. | |

## Tugas umum

- **Lihat ringkasan payrun** — Periksa Periode Pembayaran, Status Slip Gaji, dan Total Pengeluaran Perusahaan.
- **Edit payrun** — Klik **Edit Payrun** untuk mengubah detail (URL berisi ID payrun).
- **Cari karyawan** — Gunakan kotak pencarian untuk memfilter Daftar Gaji Kotor Karyawan.

## Pemecahan masalah

- **Pengeluaran atau daftar kosong** — Data mungkin masih dimuat, atau payrun belum punya slip gaji. Jika mengharapkan data, tanyakan ke admin.
- **Tidak bisa edit atau regenerasi** — Aksi ini mungkin dibatasi oleh peran. Jika tidak melihat tombol, tanyakan ke admin.
