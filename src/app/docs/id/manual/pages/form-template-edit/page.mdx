# Edit Template Form

## Tujuan

Mengubah template form yang ada: nama, penggunaan, dan pertanyaan (tambah, edit, urutkan, atau hapus). URL berisi ID form (mis. .../edit/1). **Perbarui** untuk menyimpan; **Batal** untuk membatalkan.

## Screenshot

![Edit Template Form](/manual/pages/form-template-edit.png)

## Di halaman ini

1. **Nama Form, Penggunaan Form** — Tampilan di atas.
2. **Pertanyaan** — Setiap blok: Teks pertanyaan, Deskripsi, Tipe Jawaban, opsi (mis. Checkbox, Range, Paragraf).
3. **Tambah Pertanyaan** — Tambah pertanyaan lain.
4. **Batal** — Kembali tanpa menyimpan.
5. **Perbarui** — Simpan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Nama Form, Penggunaan Form | Menampilkan nama dan penggunaan saat ini. | |
| 2 | Pertanyaan | Edit teks, tipe, opsi; hapus dengan ikon sampah. | |
| 3 | Tambah Pertanyaan | Menambah blok pertanyaan baru. | |
| 4 | Batal | Batalkan perubahan. | |
| 5 | Perbarui | Menyimpan template. | |

## Tugas umum

- **Ubah pertanyaan** — Edit teks pertanyaan, tipe jawaban, atau opsi, lalu **Perbarui**.
- **Tambah pertanyaan** — Klik **Tambah Pertanyaan**, isi blok, lalu **Perbarui**.
- **Hapus pertanyaan** — Gunakan ikon sampah pada pertanyaan tersebut, lalu **Perbarui**.

## Pemecahan masalah

- **Halaman tidak ditemukan** — Buka Edit dari daftar Template Form untuk form yang valid (URL menggunakan ID form tersebut).
- **Tidak bisa mengakses** — Jika tidak melihat Edit, tanyakan ke admin.
