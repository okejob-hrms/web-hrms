# Edit Pengaturan Kehadiran

## Tujuan

Mengubah aturan kehadiran seperti waktu check-in/out dan ambang terlambat. Simpan untuk menerapkan; batal untuk keluar tanpa menyimpan.

## Screenshot

![Edit Pengaturan Kehadiran](/manual/pages/attendance-config-edit.png)

## Di halaman ini

1. **Form pengaturan** — Kolom untuk aturan kehadiran (mis. waktu, ambang).
2. **Simpan atau Kirim** — Menyimpan perubahan Anda.
3. **Batal atau Kembali** — Kembali tanpa menyimpan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Form pengaturan | Masukkan atau ubah aturan kehadiran. | Isi kolom wajib. |
| 2 | Simpan atau Kirim | Menerapkan perubahan. | |
| 3 | Batal atau Kembali | Keluar tanpa menyimpan. | |

## Tugas umum

- **Perbarui aturan check-in/out** — Edit kolom yang relevan dan klik **Simpan**.
- **Batalkan perubahan** — Klik **Batal** atau **Kembali**.

## Pemecahan masalah

- **Simpan dinonaktifkan** — Pastikan kolom wajib terisi dan valid.
- **Tidak bisa mengakses halaman ini** — Jika tidak terlihat, tanyakan ke admin.
