# Pengaturan Kehadiran

## Tujuan

Melihat dan mengelola aturan kehadiran (mis. waktu check-in/out, ambang terlambat). Gunakan **Edit** untuk mengubah pengaturan.

## Screenshot

![Pengaturan Kehadiran](/manual/pages/attendance-config.png)

## Di halaman ini

1. **Edit Pengaturan Kehadiran** — Buka form edit untuk mengubah aturan.
2. **Tampilan pengaturan** — Menampilkan aturan atau pengaturan kehadiran saat ini.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Edit Pengaturan Kehadiran | Membuka layar edit. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tampilan pengaturan | Menampilkan pengaturan kehadiran saat ini. | |

## Tugas umum

- **Lihat aturan** — Periksa tampilan pengaturan untuk aturan check-in/out dan terlambat saat ini.
- **Ubah aturan** — Klik **Edit**, perbarui kolom, lalu simpan.

## Pemecahan masalah

- **Tidak bisa mengedit** — Layar ini mungkin dibatasi. Jika tidak melihat tombol Edit, tanyakan ke admin.
- **Perubahan tidak diterapkan** — Simpan form dan segarkan; pastikan Anda punya izin untuk memperbarui pengaturan.
