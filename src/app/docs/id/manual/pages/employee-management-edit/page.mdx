# Edit Karyawan

## Tujuan

Gunakan halaman ini untuk memperbarui data karyawan yang ada. URL berisi ID karyawan (mis. `/employee/employee-management/edit/12`). Anda dapat mengubah informasi pribadi, ketenagakerjaan, gaji, bank, dan lampiran, atau mengarsipkan karyawan.

## Tangkapan layar

![Edit Karyawan](/manual/pages/employee-management-edit.png)

## Di halaman ini

1. **Formulir Informasi Pribadi** — Foto, Nama, Email, Telepon, Gender, Tempat Lahir, Tanggal Lahir, Status Pernikahan, Golongan Darah, Tinggi, Berat, Nomor ID, NPWP, BPJS, alamat, Hobi, Prestasi, Media Sosial.
2. **Formulir Informasi Ketenagakerjaan** — Perusahaan, Posisi, Departemen, Level Jabatan, Atasan Langsung Utama, Atasan Langsung Tambahan, Tim, Tanggal Mulai Kerja, Tanggal Akhir Kerja, Status.
3. **Informasi Gaji** — Tunjangan, Gaji Pokok, Gaji (Bersih).
4. **Informasi Bank** — Bank, Nomor Rekening, Nama Rekening.
5. **Lampiran** — Lihat atau ubah file yang diunggah (CV, Ijazah, KTP, dll.); gunakan **Unggah File** atau **Ubah File**.
6. **Batal** — Keluar tanpa menyimpan perubahan.
7. **Perbarui** — Simpan perubahan.
8. **Arsipkan Karyawan** — Arsipkan karyawan ini (biasanya menonaktifkan atau menghapus dari daftar aktif).

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Informasi Pribadi | Edit nama, kontak, dan detail pribadi. | |
| 2 | Informasi Ketenagakerjaan | Edit perusahaan, posisi, departemen, level jabatan, atasan, tim, tanggal, status. | |
| 3 | Informasi Gaji | Edit gaji pokok, gaji bersih, tunjangan. | |
| 4 | Informasi Bank | Edit bank dan detail rekening. | |
| 5 | Lampiran | Unggah, ubah, atau hapus dokumen. | |
| 6 | Batal | Batalkan perubahan dan kembali. | |
| 7 | Perbarui | Simpan semua perubahan. | |

## Tugas umum

- **Perbarui data karyawan** — Ubah kolom yang Anda butuhkan, lalu klik **Perbarui**.
- **Ubah dokumen** — Di Lampiran, klik **Ubah File** untuk dokumen tersebut dan pilih file baru.
- **Batalkan perubahan** — Klik **Batal** untuk keluar tanpa menyimpan.
- **Arsipkan karyawan** — Klik **Arsipkan Karyawan** dan konfirmasi jika diminta. Jika Anda tidak melihatnya, tanyakan kepada admin.

## Pemecahan masalah

- **Perbarui tidak bereaksi** — Periksa error validasi (mis. kolom wajib). Perbaiki dan coba lagi.
- **Arsipkan Karyawan tidak terlihat** — Ini mungkin dibatasi oleh peran. Jika Anda tidak melihatnya, tanyakan kepada admin.
- **Halaman tidak ditemukan** — ID karyawan di URL mungkin tidak valid. Kembali ke Daftar Karyawan dan buka karyawan lagi.
