# Gaji Pokok

## Tujuan

Melihat dan mengelola gaji pokok berdasarkan posisi jabatan dan level jabatan. Gunakan Tambah Gaji Pokok untuk membuat entri; gunakan aksi baris untuk edit atau hapus.

## Screenshot

![Gaji Pokok](/manual/pages/salary-base.png)

## Di halaman ini

1. Tambah Gaji Pokok — Buka form untuk menambah entri gaji pokok.
2. Tabel gaji pokok — Posisi Jabatan, Level Jabatan, Jumlah Gaji Pokok, Tanggal Berlaku, Pembaruan Terakhir.
3. Aksi baris — Menu pada setiap baris untuk Edit atau Hapus.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Tambah Gaji Pokok | Membuka form tambah. | |
| 2 | Tabel gaji pokok | Daftar posisi, level, jumlah, tanggal. | |
| 3 | Aksi baris | Edit atau hapus entri tersebut. | |

## Tugas umum

- Tambah gaji pokok: Klik Tambah Gaji Pokok, pilih posisi dan level, masukkan jumlah dan tanggal berlaku, lalu simpan.
- Edit entri: Buka aksi baris dan pilih Edit.
- Cek tanggal berlaku: Gunakan kolom Tanggal Berlaku dan Pembaruan Terakhir.

## Pemecahan masalah

- Daftar kosong: Tambah entri atau periksa filter. Jika tidak punya akses, tanyakan ke admin.
- Tidak bisa menambah atau mengedit: Jika tidak terlihat, tanyakan ke admin.
