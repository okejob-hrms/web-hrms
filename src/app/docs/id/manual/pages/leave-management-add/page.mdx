# Tambah Tipe Cuti

## Tujuan

Membuat tipe cuti baru: nama, deskripsi, siapa yang berhak (jenis kelamin), dan kuota (sama untuk semua level jabatan, per level jabatan, atau tidak terbatas). Simpan untuk menambah; Batal untuk membatalkan.

## Screenshot

![Tambah Tipe Cuti](/manual/pages/leave-management-add.png)

## Di halaman ini

1. **Nama Cuti** — Nama tipe cuti (wajib).
2. **Deskripsi** — Deskripsi opsional.
3. **Jenis Kelamin** — Semua, Laki-laki, atau Perempuan.
4. **Pengaturan Kuota** — Kuota sama untuk semua / Per level jabatan / Tidak terbatas; Kuota (hari); Carry Over; Potong Saldo Karyawan.
5. **Batal** — Kembali tanpa menyimpan.
6. **Simpan** — Buat tipe cuti.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Nama Cuti | Masukkan nama tipe cuti. | Wajib. |
| 2 | Deskripsi | Teks opsional. | |
| 3 | Jenis Kelamin | Siapa yang berhak. | Wajib. |
| 4 | Pengaturan Kuota | Atur kuota dan opsi. | |
| 5 | Batal | Batalkan dan kembali. | |
| 6 | Simpan | Membuat tipe cuti. | |

## Tugas umum

- **Tambah cuti tahunan** — Masukkan nama, atur Jenis Kelamin (mis. Semua), atur Kuota (mis. 12 hari), lalu **Simpan**.
- **Izinkan carry over** — Centang **Carry Over Diizinkan** di Pengaturan Kuota sebelum menyimpan.

## Pemecahan masalah

- **Simpan dinonaktifkan** — Isi kolom wajib (Nama Cuti, Jenis Kelamin).
- **Tidak bisa mengakses** — Jika tidak melihat halaman ini, tanyakan ke admin.
