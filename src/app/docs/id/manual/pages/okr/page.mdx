# Daftar OKR

## Tujuan

Melihat dan mengelola siklus Objective & Key Results (OKR): periode, tanggal, total OKR, pencapaian keseluruhan, dan status. Buat siklus baru atau buka baris untuk melihat detail siklus.

## Screenshot

![Daftar OKR](/manual/pages/okr.png)

## Di halaman ini

1. **Siklus OKR Baru** — Buka form untuk membuat siklus OKR baru.
2. **Tabel OKR** — Baris menampilkan Periode, Tanggal Mulai, Tanggal Akhir, Total OKR, Pencapaian Keseluruhan, Status, Pembaruan Terakhir.
3. **Menu baris** — Buka aksi untuk siklus tersebut (mis. lihat detail); URL berisi ID siklus.
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Siklus OKR Baru | Ke form siklus OKR baru. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel OKR | Daftar siklus OKR. | |
| 3 | Menu baris | Membuka detail atau aksi lain. | URL berisi ID siklus. |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Buat siklus** — Klik **+ Siklus OKR Baru**, atur periode dan tanggal, lalu simpan.
- **Lihat siklus** — Buka menu baris dan pilih aksi untuk membuka siklus (URL berisi ID).

## Pemecahan masalah

- **Daftar kosong** — Belum ada siklus OKR. Buat dengan **+ Siklus OKR Baru**. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa membuat atau membuka** — Mungkin dibatasi oleh peran. Jika tidak melihat tombol atau menu, tanyakan ke admin.
