# Penilaian per Periode/Karyawan

## Tujuan

Melihat penilaian diri satu karyawan untuk periode tertentu: informasi penilaian, skor hasil, dan jawaban rinci. Gunakan tab untuk beralih antara Penilaian Diri dan Validasi Penilaian.

## Screenshot

![Penilaian per Periode/Karyawan](/manual/pages/self-assessment-period.png)

## Di halaman ini

1. **Informasi Karyawan dan Penilaian** — Nama karyawan, ID, Posisi, Departemen, Level Jabatan, Dikirim Pada, Status Pengiriman, Supervisor, Divalidasi Pada.
2. **Tab Penilaian Diri** — Lihat hasil dan detail penilaian diri.
3. **Tab Validasi Penilaian** — Lihat validasi (jika ada).
4. **Hasil Penilaian Diri** — Tabel menampilkan Kategori dan Skor (dan total).
5. **Detail Penilaian Diri** — Pengelompokan dan jawaban form (mis. rating, teks).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Informasi Karyawan dan Penilaian | Menampilkan siapa dan kapan. | URL berisi ID periode dan karyawan. |
| 2 | Tab Penilaian Diri | Menampilkan konten penilaian diri. | |
| 3 | Tab Validasi Penilaian | Menampilkan konten validasi. | |
| 4 | Hasil Penilaian Diri | Menampilkan skor kategori. | |
| 5 | Detail Penilaian Diri | Menampilkan bagian form dan jawaban. | Hanya baca saat selesai. |

## Tugas umum

- **Lihat penilaian karyawan** — Buka dari daftar periode; URL berisi ID periode dan karyawan.
- **Cek skor** — Gunakan tabel Hasil Penilaian Diri dan Skor Total.
- **Beralih ke validasi** — Klik tab **Validasi Penilaian**.

## Pemecahan masalah

- **Halaman tidak ditemukan** — Pastikan ID periode dan karyawan di URL valid. Jika tidak punya akses, tanyakan ke admin.
- **Detail dinonaktifkan** — Penilaian yang selesai hanya baca. Untuk mengubah, gunakan Edit (jika tersedia untuk peran Anda).
