# Tambah Cabang

## Tujuan

Menambah cabang perusahaan: masukkan informasi perusahaan, lokasi kehadiran, dan detail payroll (bank). Atur **Utama** jika ini cabang utama.

## Screenshot

![Tambah Cabang](/manual/pages/company-branch-add.png)

## Di halaman ini

1. **Informasi Perusahaan** — Logo (opsional), Nama, Badan Hukum, Industri, Email, Telepon, BRN, Situs Web, Alamat, Pilih Lokasi, Radius Maksimum, Utama.
2. **Informasi Payroll** — Nama Rekening Bank, Nomor, Pemegang, Mata Uang.
3. **Batal** — Kembali tanpa menyimpan.
4. **Simpan** — Buat cabang.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Informasi Perusahaan | Masukkan detail cabang dan lokasi. | Kolom wajib ditandai *. |
| 2 | Informasi Payroll | Masukkan detail bank. | |
| 3 | Batal | Keluar tanpa menyimpan. | |
| 4 | Simpan | Membuat cabang. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Tambah cabang** — Isi kolom wajib, atur lokasi jika perlu, lalu **Simpan**.
- **Atur utama** — Nyalakan **Utama** ke Ya untuk cabang utama.

## Pemecahan masalah

- **Tidak bisa menyimpan** — Periksa kolom wajib. Jika tidak melihat **Simpan**, tanyakan ke admin.
