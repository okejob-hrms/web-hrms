# Detail OKR

## Tujuan

Melihat satu siklus OKR: periode, tanggal, pencapaian keseluruhan, dan jumlah key result. Tambah objective, beralih antara tab Objective Key Result, Key Result, dan Dasbor. URL berisi ID siklus.

## Screenshot

![Detail OKR](/manual/pages/okr-detail.png)

## Di halaman ini

1. **Judul dan status siklus** — Nama periode (mis. Q5 2026) dan status (Draf atau Aktif).
2. **Tanggal Mulai, Tanggal Akhir** — Rentang tanggal siklus.
3. **Pencapaian Keseluruhan** — Rata-rata progres (persentase).
4. **Total Key Result, Terbuka, Selesai** — Jumlah key result.
5. **Tab Objective Key Result** — Daftar dan kelola objective.
6. **Tab Key Result** — Lihat key result.
7. **Tab Dasbor** — Tampilan dasbor untuk siklus ini.
8. **Pencarian** — Filter objective atau key result.
9. **Tambah Objective Baru** — Tambah objective ke siklus ini.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Judul dan status siklus | Menampilkan periode dan status. | URL berisi ID siklus. |
| 2 | Tanggal Mulai, Tanggal Akhir | Menampilkan rentang tanggal. | |
| 3 | Pencapaian Keseluruhan | Menampilkan progres. | |
| 4 | Total / Terbuka / Selesai | Menampilkan jumlah key result. | |
| 5 | Tab Objective Key Result | Menampilkan objective. | |
| 6 | Tab Key Result | Menampilkan key result. | |
| 7 | Tab Dasbor | Menampilkan dasbor. | |
| 8 | Pencarian | Memfilter daftar. | |
| 9 | Tambah Objective Baru | Menambah objective. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Tambah objective** — Klik **Tambah Objective Baru**, isi form, simpan.
- **Lihat key result** — Buka tab **Key Result** atau **Dasbor**.
- **Cek progres** — Gunakan Pencapaian Keseluruhan dan jumlah key result.

## Pemecahan masalah

- **Halaman tidak ditemukan** — ID siklus di URL harus ada. Buka dari daftar OKR terlebih dahulu. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menambah objective** — Mungkin dibatasi oleh peran. Jika tidak melihat **Tambah Objective Baru**, tanyakan ke admin.
