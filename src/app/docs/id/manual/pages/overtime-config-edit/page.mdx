# Edit Pengaturan Lembur

## Tujuan

Mengubah aturan lembur: pembagi jam kerja, aturan bertingkat, batas, dan tarif libur. Simpan untuk menerapkan; Batal untuk keluar tanpa menyimpan.

## Screenshot

![Edit Pengaturan Lembur](/manual/pages/overtime-config-edit.png)

## Di halaman ini

1. **Pembagi Jam Kerja** — Rumus (160 / 173 / 180 Jam per bulan).
2. **Tambah Aturan Bertingkat** — Tambah tingkatan baru (rentang jam waktu dan tarif).
3. **Tabel bertingkat** — Baris dengan Jam Waktu, Tarif, dan hapus.
4. **Batas & Ambang** — Jam Harian/Mingguan/Bulanan Maks, Tolak Otomatis, Proporsi per Menit.
5. **Tarif Akhir Pekan/Libur Nasional** — Input angka untuk pengali.
6. **Tambah Pengecualian** — Tambah tarif hari khusus.
7. **Batal** — Keluar tanpa menyimpan.
8. **Simpan** — Terapkan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Pembagi Jam Kerja | Pilih rumus untuk tarif per jam. | Wajib. |
| 2 | Tambah Aturan Bertingkat | Menambah baris ke tabel bertingkat. | |
| 3 | Tabel bertingkat | Edit atau hapus tingkatan. | |
| 4 | Batas & Ambang | Atur jam maks dan opsi. | |
| 5 | Tarif Akhir Pekan/Libur Nasional | Atur pengali (mis. 3x, 4x). | |
| 6 | Tambah Pengecualian | Tambah hari khusus dan tarif. | |
| 7 | Batal | Batalkan perubahan. | |
| 8 | Simpan | Menyimpan pengaturan. | |

## Tugas umum

- **Ubah pembagi** — Pilih 160, 173, atau 180 Jam/Bulan dan **Simpan**.
- **Tambah tingkatan** — Klik **Tambah Aturan Bertingkat**, isi rentang dan tarif, lalu **Simpan**.
- **Atur tarif libur** — Masukkan pengali Akhir Pekan dan Libur Nasional dan **Simpan**.

## Pemecahan masalah

- **Simpan dinonaktifkan** — Periksa kolom wajib (mis. pembagi, tarif).
- **Tidak bisa mengakses** — Jika tidak melihat halaman ini, tanyakan ke admin.
