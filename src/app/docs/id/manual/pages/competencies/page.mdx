# Daftar Kompetensi

## Tujuan

Melihat dan mengelola kompetensi kinerja (kode, nama, deskripsi). Gunakan Kompetensi Kinerja Baru untuk menambah; gunakan aksi baris untuk membuka detail atau edit.

## Screenshot

![Daftar Kompetensi](/manual/pages/competencies.png)

## Di halaman ini

1. **Kompetensi Kinerja Baru** — Buka form untuk menambah kompetensi.
2. **Tabel kompetensi** — Kode, Kompetensi, Deskripsi.
3. **Aksi baris** — Menu pada setiap baris untuk Lihat detail atau Edit.
4. **Paginasi** — Sebelumnya, Berikutnya dan nomor halaman.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Kompetensi Kinerja Baru | Membuka form tambah. | |
| 2 | Tabel kompetensi | Daftar kode, nama, deskripsi. | |
| 3 | Aksi baris | Buka detail atau edit. | |
| 4 | Paginasi | Pindah antar halaman. | |

## Tugas umum

- **Tambah kompetensi** — Klik Kompetensi Kinerja Baru, masukkan kode, nama, deskripsi, lalu simpan.
- **Lihat detail** — Buka aksi baris dan pilih opsi yang membuka halaman detail.
- **Edit kompetensi** — Buka dari aksi baris atau dari tombol Edit di halaman detail.

## Pemecahan masalah

- **Daftar kosong** — Tambah kompetensi atau periksa akses. Jika tidak melihat daftar, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Jika tidak terlihat, tanyakan ke admin.
