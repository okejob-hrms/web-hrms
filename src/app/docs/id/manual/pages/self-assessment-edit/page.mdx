# Edit Penilaian Diri

## Tujuan

Mengedit periode penilaian diri yang ada: ubah periode, tahun, tanggal, pengingat, peserta, atau form. URL berisi ID periode.

## Screenshot

![Edit Penilaian Diri](/manual/pages/self-assessment-edit.png)

## Di halaman ini

1. **Periode Penilaian** — Ubah tipe periode (mis. Q2).
2. **Tahun** — Ubah tahun (wajib).
3. **Tanggal Mulai** — Ubah tanggal mulai.
4. **Tanggal Akhir** — Ubah tanggal akhir.
5. **Kirim Pengingat** — Ubah opsi pengingat.
6. **Peserta** — Bagian menampilkan jumlah yang ditetapkan (mis. 2/49).
7. **Form Penilaian** — Ubah form untuk penilaian ini.
8. **Edit Peserta** — Ubah siapa yang ditetapkan.
9. **Hapus** — Hapus peserta atau form (tergantung konteks).
10. **Tambah Peserta** — Tambah peserta lain.
11. **Batal** — Kembali tanpa menyimpan.
12. **Perbarui Penilaian** — Simpan perubahan.

## Tugas umum

- **Ubah tanggal** — Perbarui Tanggal Mulai dan Tanggal Akhir, lalu **Perbarui Penilaian**.
- **Ubah peserta** — Klik **Edit Peserta** atau **Tambah Peserta**, lalu **Perbarui Penilaian**.

## Pemecahan masalah

- **Tidak bisa mengedit** — Anda mungkin butuh izin. Jika tidak melihat **Perbarui Penilaian** atau **Edit Peserta**, tanyakan ke admin.
- **URL tidak ditemukan** — ID periode di URL harus ada. Buka penilaian dari daftar terlebih dahulu.
