# Detail Akses

## Tujuan

Melihat atau mengedit peran: ubah nama dan deskripsi, lalu atur izin berdasarkan fungsionalitas (Lihat, Buat, Edit, dll.). Anda dapat menyimpan sebagai peran baru atau mengatur ulang ke template. URL berisi ID peran.

## Screenshot

![Detail Akses](/manual/pages/access-control-detail.png)

## Di halaman ini

1. **Informasi Peran** — Nama dan Deskripsi.
2. **Simpan sebagai peran baru** — Simpan izin saat ini sebagai peran baru.
3. **Atur ulang ke template** — Atur ulang izin ke template default.
4. **Tabel izin** — Fungsionalitas dan kotak centang aksi (Lihat, Buat, Edit, Tetapkan, Unduh, Hapus, Ekspor, Persetujuan, Override Status).
5. **Batal** — Kembali tanpa menyimpan.
6. **Simpan** — Simpan perubahan ke peran ini.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Informasi Peran | Edit nama dan deskripsi peran. | URL berisi ID peran. |
| 2 | Simpan sebagai peran baru | Membuat peran baru dari pengaturan saat ini. | Jika tidak terlihat, tanyakan ke admin. |
| 3 | Atur ulang ke template | Mengembalikan izin default. | |
| 4 | Tabel izin | Atur izin per fungsionalitas. | |
| 5 | Batal | Keluar tanpa menyimpan. | |
| 6 | Simpan | Menyimpan perubahan. | |

## Tugas umum

- **Edit izin** — Aktifkan/nonaktifkan kotak centang di tabel Izin, lalu klik **Simpan**.
- **Salin sebagai peran baru** — Sesuaikan jika perlu, lalu klik **Simpan sebagai peran baru**.
- **Atur ulang** — Klik **Atur ulang ke template** untuk mengembalikan default, lalu **Simpan** jika perlu.

## Pemecahan masalah

- **Halaman tidak ditemukan** — ID peran di URL harus ada. Buka dari daftar Kontrol Akses. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menyimpan** — Anda mungkin butuh izin. Jika tidak melihat **Simpan** atau **Simpan sebagai peran baru**, tanyakan ke admin.
