# Profil Perusahaan

## Tujuan

Melihat informasi perusahaan dan detail payroll (bank). Gunakan **Edit Informasi Perusahaan** untuk mengubahnya.

## Screenshot

![Profil Perusahaan](/manual/pages/company-profile.png)

## Di halaman ini

1. **Informasi Perusahaan** — Logo, nama, Badan Hukum, Industri, Email, Telepon, Nomor Registrasi Bisnis, Situs Web, Alamat.
2. **Informasi Payroll** — Nama Rekening Bank, Nomor, Pemegang, Mata Uang.
3. **Edit Informasi Perusahaan** — Buka form edit.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Informasi Perusahaan | Menampilkan detail perusahaan. | |
| 2 | Informasi Payroll | Menampilkan detail bank. | |
| 3 | Edit Informasi Perusahaan | Ke form edit. | Jika tidak terlihat, tanyakan ke admin. |

## Tugas umum

- **Lihat profil** — Periksa bagian perusahaan dan payroll.
- **Perbarui detail** — Klik **Edit Informasi Perusahaan**, ubah kolom, lalu simpan.

## Pemecahan masalah

- **Tidak bisa mengedit** — Anda mungkin butuh izin. Jika tidak melihat tombol, tanyakan ke admin.
