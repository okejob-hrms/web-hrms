# Daftar Karyawan

## Tujuan

Gunakan Daftar Karyawan untuk melihat dan mencari semua karyawan. Anda dapat memfilter berdasarkan posisi dan departemen, membuka catatan untuk melihat detail, atau menambah karyawan baru.

## Tangkapan layar

![Daftar Karyawan](/manual/pages/employee-management.png)

## Di halaman ini

1. **Cari berdasarkan Nama atau ID Karyawan** — Ketik untuk menemukan karyawan berdasarkan nama atau ID.
2. **Filter posisi** — Persempit daftar berdasarkan satu atau lebih posisi.
3. **Filter departemen** — Persempit daftar berdasarkan satu atau lebih departemen.
4. **Pencarian Lanjutan** — Buka opsi filter tambahan.
5. **Karyawan Baru** — Buka halaman Tambah Karyawan.
6. **Tabel karyawan** — Baris menampilkan Nama, Posisi, Departemen, Email, Nomor Telepon, Status, Tanggal Bergabung.
7. **Tindakan baris** — Gunakan menu pada setiap baris untuk membuka atau mengelola karyawan tersebut.
8. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Cari berdasarkan Nama atau ID Karyawan | Memfilter daftar saat Anda mengetik. | |
| 2 | Filter posisi | Pilih banyak untuk memfilter berdasarkan posisi. | |
| 3 | Filter departemen | Pilih banyak untuk memfilter berdasarkan departemen. | |
| 4 | Pencarian Lanjutan | Membuka filter pencarian tambahan. | |
| 5 | Karyawan Baru | Ke formulir Tambah Karyawan. | |
| 6 | Tabel karyawan | Daftar karyawan; klik baris atau gunakan menu baris untuk membuka detail. | |
| 7 | Tindakan baris | Menu untuk setiap baris (mis. buka detail). | |
| 8 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Temukan karyawan** — Gunakan kotak pencarian atau filter, lalu klik baris atau menu baris untuk membuka detail karyawan.
- **Tambah karyawan** — Klik **+ Karyawan Baru**, isi formulir, dan kirim.
- **Buka detail karyawan** — Klik nama karyawan atau menu tindakan baris dan pilih untuk melihat catatan. URL akan berisi ID karyawan (mis. `/employee/employee-management/12`).

## Pemecahan masalah

- **Daftar kosong** — Periksa filter dan pencarian; kosongkan atau ubah rentang tanggal. Jika Anda tidak memiliki akses, tanyakan kepada admin.
- **Tidak melihat Karyawan Baru** — Ini mungkin dibatasi oleh peran. Jika Anda tidak melihatnya, tanyakan kepada admin.
- **Menu baris tidak bereaksi** — Pastikan Anda memiliki izin untuk melihat karyawan tersebut. Coba segarkan halaman.
