# Daftar Payrun

## Tujuan

Melihat dan mengelola payrun. Anda dapat mencari berdasarkan nama, memfilter berdasarkan tanggal, membuat payrun baru, atau membuka baris untuk melihat detail payrun dan mengeditnya.

## Screenshot

![Daftar Payrun](/manual/pages/payroll-list.png)

## Di halaman ini

1. **Cari berdasarkan nama payrun** — Ketik untuk menemukan payrun.
2. **Pilih tanggal** — Filter payrun berdasarkan tanggal.
3. **Payrun Baru** — Buka form untuk membuat payrun baru.
4. **Tabel payrun** — Baris menampilkan Payrun (nama/periode), Total Slip Gaji, Total Gaji, Status Slip Gaji, Status Generasi.
5. **Menu baris** — Buka aksi untuk payrun (mis. lihat detail, edit).
6. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Cari berdasarkan nama payrun | Memfilter daftar saat Anda mengetik. | |
| 2 | Pilih tanggal | Memfilter payrun berdasarkan tanggal yang dipilih. | |
| 3 | Payrun Baru | Ke form payrun baru. | Jika tidak terlihat, tanyakan ke admin. |
| 4 | Tabel payrun | Daftar payrun dengan total, status, pembaruan terakhir. | |
| 5 | Menu baris | Membuka aksi untuk payrun tersebut (mis. detail, edit). | |
| 6 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Lihat payrun** — Gunakan tabel untuk melihat periode, total, dan status. Klik nama payrun untuk membuka detail.
- **Buat payrun** — Klik **+ Payrun Baru**, isi form, dan simpan.
- **Filter berdasarkan tanggal** — Gunakan **Pilih tanggal** untuk mempersempit daftar.

## Pemecahan masalah

- **Daftar kosong** — Periksa pencarian dan filter tanggal; hapus jika perlu. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa membuat payrun** — Mungkin dibatasi oleh peran. Jika tidak melihat **+ Payrun Baru**, tanyakan ke admin.
