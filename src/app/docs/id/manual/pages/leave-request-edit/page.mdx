# Edit Pengajuan Cuti

## Tujuan

Mengubah pengajuan cuti yang ada. Form menampilkan kolom yang sama dengan Ajukan Cuti; gunakan **Perbarui Pengajuan Cuti** untuk menyimpan. URL berisi ID pengajuan (mis. .../leave-request/edit/1).

## Screenshot

![Edit Pengajuan Cuti](/manual/pages/leave-request-edit.png)

## Di halaman ini

1. **Nama Karyawan** — Karyawan terpilih (dapat diedit).
2. **Persetujuan yang Ditugaskan** — Persetujuan (dapat diedit).
3. **Tipe Cuti** — Tipe cuti (dapat diedit).
4. **Tanggal Mulai** — Tanggal mulai (dapat diedit).
5. **Tanggal Akhir** — Tanggal akhir (dapat diedit).
6. **Alasan** — Alasan (dapat diedit).
7. **Pilih Lampiran** — Lampiran (dapat diedit).
8. **Batal** — Batalkan perubahan dan kembali.
9. **Perbarui Pengajuan Cuti** — Simpan perubahan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Nama Karyawan | Ubah karyawan jika perlu. | |
| 2 | Persetujuan yang Ditugaskan | Ubah persetujuan. | |
| 3 | Tipe Cuti | Ubah tipe cuti. | |
| 4 | Tanggal Mulai | Ubah tanggal mulai. | |
| 5 | Tanggal Akhir | Ubah tanggal akhir. | |
| 6 | Alasan | Edit alasan. | |
| 7 | Pilih Lampiran | Tambah atau hapus lampiran. | |
| 8 | Batal | Batalkan dan kembali. | |
| 9 | Perbarui Pengajuan Cuti | Menyimpan perubahan. | |

## Tugas umum

- **Edit pengajuan** — Dari daftar, buka aksi baris dan pilih Edit. Ubah kolom dan klik **Perbarui Pengajuan Cuti**.
- **Kembali tanpa menyimpan** — Klik **Batal**.

## Pemecahan masalah

- **Halaman tidak dimuat** — Pengajuan mungkin tidak ada atau ID tidak valid. Kembali ke daftar dan buka pengajuan lain.
- **Tidak bisa memperbarui** — Periksa izin. Jika tidak melihat Perbarui atau gagal, tanyakan ke admin.
