# Edit Payrun

## Tujuan

Mengedit payrun: atur atau tinjau gaji kotor untuk setiap karyawan, lalu lanjut ke langkah berikutnya untuk meninjau payrun. Anda dapat meregenerasi payrun ketika data referensi (kehadiran, cuti, lembur, gaji) berubah.

![Edit Payrun](/manual/pages/payroll-edit.png)

## Di halaman ini

1. **Riwayat Payrun** — Lihat riwayat payrun ini.
2. **Regenerasi Payrun** — Hitung ulang payroll dari data referensi (mengatur ulang edit manual).
3. **Periode Pembayaran** — Menampilkan periode payrun.
4. **Status Slip Gaji** — Menampilkan status draf atau final.
5. **Langkah penyelesaian** — Langkah: 1 Gaji Kotor, 2 Tinjau Payrun.
6. **Atur Gaji Kotor** — Bagian dengan instruksi; periksa tarif bayar dan keselarasan gaji.
7. **Daftar Gaji Kotor Karyawan** — Judul dan jumlah karyawan.
8. **Cari berdasarkan Nama, ID, atau Departemen Karyawan** — Filter daftar karyawan.
9. **Tabel gaji kotor karyawan** — Baris menampilkan Nama, Jam Kerja, Tunjangan, Lembur, Penghasilan Tambahan, Potongan Penalti, Gaji Kotor, Gaji Bersih.
10. **Paginasi** — Pindah antar halaman karyawan.
11. **Batal** — Kembali tanpa menyimpan.
12. **Berikutnya** — Ke langkah berikutnya (Tinjau Payrun).

## Tugas umum

- **Atur gaji kotor** — Periksa tabel, sesuaikan jika perlu, lalu klik **Berikutnya** untuk melanjutkan.
- **Regenerasi** — Gunakan **Regenerasi Payrun** hanya ketika data referensi berubah; akan menghitung ulang dan mengatur ulang nilai manual.
- **Batal** — Klik **Batal** untuk kembali tanpa menyimpan.

## Pemecahan masalah

- **Tabel kosong** — Data mungkin masih dimuat, atau payrun belum punya karyawan. Regenerasi jika mengharapkan data. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa edit atau regenerasi** — Mungkin dibatasi oleh peran. Jika tidak melihat tombol, tanyakan ke admin.
