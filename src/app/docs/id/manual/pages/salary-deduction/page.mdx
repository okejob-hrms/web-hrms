# Potongan

## Tujuan

Melihat dan mengelola potongan gaji (mis. wajib, pajak, kebijakan perusahaan). Gunakan Atur Potongan Gaji untuk menambah; gunakan aksi baris untuk edit atau hapus.

## Screenshot

![Potongan](/manual/pages/salary-deduction.png)

## Di halaman ini

1. **Atur Potongan Gaji** — Buka form untuk menambah potongan.
2. **Tabel potongan** — Nama Potongan, Tipe, Kontribusi Pemberi Kerja dan Karyawan, Tanggal Berlaku, Berlaku Sampai, Pembaruan Terakhir.
3. **Aksi baris** — Menu pada setiap baris untuk Edit atau Hapus.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Atur Potongan Gaji | Membuka form tambah atau atur. | |
| 2 | Tabel potongan | Daftar nama, tipe, kontribusi, rentang tanggal. | |
| 3 | Aksi baris | Edit atau hapus potongan tersebut. | |

## Tugas umum

- **Tambah potongan** — Klik Atur Potongan Gaji, masukkan nama, tipe, kontribusi pemberi kerja dan karyawan, dan rentang tanggal, lalu simpan.
- **Edit potongan** — Buka aksi baris dan pilih Edit.
- **Cek periode berlaku** — Gunakan kolom Tanggal Berlaku dan Berlaku Sampai.

## Pemecahan masalah

- **Daftar kosong** — Tambah potongan atau periksa filter. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Jika tidak terlihat, tanyakan ke admin.
