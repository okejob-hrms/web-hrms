# Daftar Cabang

## Tujuan

Melihat dan mengelola cabang perusahaan: nama, pembaruan terakhir, dan apakah cabang utama. Tambah cabang atau buka menu baris untuk mengedit.

## Screenshot

![Daftar Cabang](/manual/pages/company-branch.png)

## Di halaman ini

1. **Cabang Baru** — Buka form untuk menambah cabang.
2. **Tabel cabang** — Baris menampilkan Nama Perusahaan, Pembaruan Terakhir, Utama.
3. **Menu baris** — Edit cabang (URL berisi ID cabang).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Cabang Baru | Ke form Tambah Cabang. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel cabang | Daftar cabang. | |
| 3 | Menu baris | Membuka edit. | URL berisi ID cabang. |

## Tugas umum

- **Tambah cabang** — Klik **+ Cabang Baru**, isi form, simpan.
- **Edit cabang** — Buka menu baris dan pilih edit (URL berisi ID).

## Pemecahan masalah

- **Daftar kosong** — Belum ada cabang. Tambah dengan **+ Cabang Baru**. Jika tidak punya akses, tanyakan ke admin.
