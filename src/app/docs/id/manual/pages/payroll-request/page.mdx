# Permintaan Akses

## Tujuan

Meminta akses ke payroll: gunakan **Permintaan Cetak** untuk melihat dan mengelola permintaan cetak, atau **Permintaan Lihat Slip Gaji** untuk melihat permintaan tampilan slip gaji. Cari dan filter berdasarkan karyawan atau tanggal.

## Screenshot

![Permintaan Akses](/manual/pages/payroll-request.png)

## Di halaman ini

1. **Tab Permintaan Cetak** — Lihat dan kelola permintaan cetak payroll.
2. **Tab Permintaan Lihat Slip Gaji** — Lihat dan kelola permintaan lihat slip gaji.
3. **Cari berdasarkan nama karyawan** — Filter permintaan berdasarkan karyawan.
4. **Pilih tanggal** — Filter berdasarkan tanggal.
5. **Permintaan Cetak Payroll** — Judul bagian (saat tab Permintaan Cetak aktif).
6. **Tabel permintaan** — Baris menampilkan Diajukan Oleh, Permintaan Payrun, Tanggal Permintaan, Status Permintaan, Pembaruan Terakhir.
7. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Tab Permintaan Cetak | Menampilkan daftar permintaan cetak. | |
| 2 | Tab Permintaan Lihat Slip Gaji | Menampilkan daftar permintaan lihat slip gaji. | |
| 3 | Cari berdasarkan nama karyawan | Memfilter daftar saat Anda mengetik. | |
| 4 | Pilih tanggal | Memfilter permintaan berdasarkan tanggal yang dipilih. | |
| 5 | Permintaan Cetak Payroll | Judul bagian untuk tab aktif. | |
| 6 | Tabel permintaan | Daftar permintaan dan status. | |
| 7 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Lihat permintaan cetak** — Buka tab **Permintaan Cetak** dan gunakan tabel; gunakan pencarian atau tanggal untuk memfilter.
- **Lihat permintaan slip gaji** — Buka tab **Permintaan Lihat Slip Gaji**.
- **Cari permintaan** — Gunakan **Cari berdasarkan nama karyawan** atau **Pilih tanggal** untuk mempersempit daftar.

## Pemecahan masalah

- **Daftar kosong** — Periksa pencarian dan filter tanggal; hapus jika perlu. Jika tidak punya akses ke halaman ini, tanyakan ke admin.
- **Tidak bisa meminta akses** — Permintaan mungkin dibatasi oleh peran. Jika tidak melihat opsi yang dibutuhkan, tanyakan ke admin.
