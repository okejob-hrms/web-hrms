# Tunjangan

## Tujuan

Melihat dan mengelola tunjangan berdasarkan tipe dan level jabatan. Gunakan Atur Tunjangan untuk menambah; gunakan aksi baris untuk edit atau hapus.

## Screenshot

![Tunjangan](/manual/pages/salary-allowance.png)

## Di halaman ini

1. Atur Tunjangan — Buka form untuk menambah tunjangan.
2. Tabel tunjangan — Tipe Tunjangan, Level Jabatan, Tanggal Berlaku, Pembaruan Terakhir.
3. Aksi baris — Menu pada setiap baris untuk Edit atau Hapus.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Atur Tunjangan | Membuka form tambah atau atur. | |
| 2 | Tabel tunjangan | Daftar tipe, level, tanggal. | |
| 3 | Aksi baris | Edit atau hapus tunjangan tersebut. | |

## Tugas umum

- Tambah tunjangan: Klik Atur Tunjangan, pilih tipe dan level jabatan, atur jumlah dan tanggal berlaku, lalu simpan.
- Edit tunjangan: Buka aksi baris dan pilih Edit.
- Cek tanggal berlaku: Gunakan kolom Tanggal Berlaku dan Pembaruan Terakhir.

## Pemecahan masalah

- Daftar kosong: Tambah tunjangan atau periksa filter. Jika tidak punya akses, tanyakan ke admin.
- Tidak bisa menambah atau mengedit: Jika tidak terlihat, tanyakan ke admin.
