# Catatan Offboarding Karyawan

## Tujuan

Melihat dan mengelola catatan offboarding. Anda dapat mencari dan memfilter daftar, memulai proses offboarding baru, atau membuka catatan untuk melihat detail atau menyesuaikan gaji.

## Screenshot

![Catatan Offboarding Karyawan](/manual/pages/offboarding.png)

## Di halaman ini

1. **Cari berdasarkan Nama atau ID Karyawan** — Ketik untuk menemukan catatan offboarding.
2. **Filter posisi** — Mempersempit daftar berdasarkan posisi.
3. **Filter departemen** — Mempersempit daftar berdasarkan departemen.
4. **Pencarian lanjutan** — Buka opsi filter tambahan.
5. **Proses Offboarding Baru** — Mulai proses offboarding baru.
6. **Tabel offboarding** — Baris menampilkan Nama, Posisi, Departemen, Tanggal Bergabung, Status.
7. **Tautan pratinjau** — Buka detail offboarding untuk catatan tersebut (URL berisi ID catatan).
8. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Cari berdasarkan Nama atau ID Karyawan | Memfilter daftar saat Anda mengetik. | |
| 2 | Filter posisi | Pilih banyak untuk memfilter berdasarkan posisi. | |
| 3 | Filter departemen | Pilih banyak untuk memfilter berdasarkan departemen. | |
| 4 | Pencarian lanjutan | Membuka filter pencarian tambahan. | |
| 5 | Proses Offboarding Baru | Memulai proses offboarding baru. | Jika tidak terlihat, tanyakan ke admin. |
| 6 | Tabel offboarding | Daftar catatan; gunakan Pratinjau untuk membuka detail. | |
| 7 | Tautan pratinjau | Membuka halaman detail; URL adalah `.../off-boarding/{id}`. | |
| 8 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Lihat daftar offboarding** — Gunakan pencarian dan filter, lalu klik **Pratinjau** pada baris untuk membuka detail.
- **Mulai offboarding** — Klik **Proses Offboarding Baru** dan ikuti langkahnya.
- **Buka detail** — Klik **Pratinjau** pada baris. URL detail berisi ID catatan (mis. .../off-boarding/16).

## Pemecahan masalah

- **Daftar kosong** — Periksa filter dan pencarian; hapus jika perlu. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa memulai proses baru** — Mungkin dibatasi oleh peran. Jika tidak terlihat, tanyakan ke admin.
