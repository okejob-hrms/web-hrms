# Template Penilaian Supervisor

## Tujuan

Mengonfigurasi template form penilaian supervisor. Gunakan Tambah Pertanyaan untuk membangun form; Simpan untuk menyimpan; Batal untuk membatalkan.

## Screenshot

![Template Penilaian Supervisor](/manual/pages/form-template-supervisor.png)

## Di halaman ini

1. Detail Form — Nama Form dan Penggunaan Form.
2. Tambah Pertanyaan — Tambah pertanyaan ke template.
3. Batal — Kembali tanpa menyimpan.
4. Simpan — Simpan template penilaian supervisor.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Detail Form | Nama dan penggunaan form. | |
| 2 | Tambah Pertanyaan | Tambah blok pertanyaan. | |
| 3 | Batal | Batalkan dan kembali. | |
| 4 | Simpan | Menyimpan template. | |

## Tugas umum

- Siapkan template: Atur nama dan penggunaan, tambah pertanyaan dengan Tambah Pertanyaan, lalu Simpan.
- Tambah pertanyaan: Klik Tambah Pertanyaan untuk setiap item; atur tipe dan opsi sesuai kebutuhan.

## Pemecahan masalah

- Simpan dinonaktifkan: Pastikan nama form, penggunaan dan setidaknya satu pertanyaan diatur jika wajib.
- Tidak bisa mengakses: Jika tidak melihat halaman ini, tanyakan ke admin.
