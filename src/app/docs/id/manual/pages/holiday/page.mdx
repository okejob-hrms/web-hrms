# Kehadiran Libur

## Tujuan

Melihat dan mengelola daftar libur (acara dan tanggal). Gunakan **Tambah Libur** untuk membuat; gunakan aksi baris untuk edit atau hapus.

## Screenshot

![Kehadiran Libur](/manual/pages/holiday.png)

## Di halaman ini

1. **Tambah Libur** — Buka form untuk menambah libur baru.
2. **Tabel libur** — Kolom Acara dan Tanggal.
3. **Aksi baris** — Menu pada setiap baris (mis. Edit, Hapus).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Tambah Libur | Membuka form Tambah Libur. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel libur | Daftar libur; Acara dan Tanggal. | |
| 3 | Aksi baris | Edit atau hapus libur tersebut. | |

## Tugas umum

- **Tambah libur** — Klik **Tambah Libur**, masukkan nama acara dan tanggal, lalu simpan.
- **Edit libur** — Buka aksi baris dan pilih Edit.
- **Hapus libur** — Buka aksi baris dan pilih Hapus (jika tersedia).

## Pemecahan masalah

- **Daftar kosong** — Tambah libur atau periksa filter. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Mungkin dibatasi. Jika tidak terlihat, tanyakan ke admin.
