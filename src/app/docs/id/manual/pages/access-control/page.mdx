# Daftar Kontrol Akses

## Tujuan

Melihat dan mengelola peran (kontrol akses). Anda dapat membuat peran baru atau membuka baris untuk melihat atau mengedit detail dan izin peran.

## Screenshot

![Daftar Kontrol Akses](/manual/pages/access-control.png)

## Di halaman ini

1. **Peran Baru** — Buka form untuk membuat peran baru.
2. **Tabel peran** — Baris menampilkan Nama Peran dan Pembaruan Terakhir.
3. **Menu baris** — Buka detail atau edit peran (URL berisi ID peran).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Peran Baru | Ke form Tambah Akses. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel peran | Daftar peran. | |
| 3 | Menu baris | Membuka detail peran. | URL berisi ID peran. |

## Tugas umum

- **Buat peran** — Klik **+ Peran Baru**, atur nama dan izin, lalu simpan.
- **Lihat atau edit peran** — Buka menu baris dan pilih aksi (URL berisi ID).

## Pemecahan masalah

- **Daftar kosong** — Belum ada peran. Buat satu atau periksa izin. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa membuat atau membuka** — Mungkin dibatasi. Jika tidak melihat tombol atau menu, tanyakan ke admin.
