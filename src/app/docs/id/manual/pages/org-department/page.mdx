# Daftar Departemen

## Tujuan

Lihat dan kelola departemen (mis. IT, HR, Keuangan). Anda dapat menambah departemen baru dan menggunakan tindakan baris untuk mengedit atau mengelola masing-masing.

## Tangkapan layar

![Daftar Departemen](/manual/pages/org-department.png)

## Di halaman ini

1. **Departemen Baru** — Buka formulir untuk membuat departemen baru.
2. **Tabel departemen** — Daftar nama departemen, deskripsi, dan pembaruan terakhir.
3. **Tindakan baris** — Menu pada setiap baris untuk mengedit atau mengelola departemen tersebut.
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Departemen Baru | Membuka formulir untuk menambah departemen. | Jika Anda tidak melihat ini, tanyakan kepada admin. |
| 2 | Tabel departemen | Menampilkan semua departemen. | |
| 3 | Tindakan baris | Edit atau tindakan lain per departemen. | |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Tambah departemen** — Klik **+ Departemen Baru**, masukkan nama dan deskripsi, dan simpan.
- **Edit departemen** — Buka tindakan baris pada baris tersebut dan pilih edit.
- **Lihat semua departemen** — Gunakan tabel dan paginasi untuk menelusuri.

## Pemecahan masalah

- **Daftar kosong** — Departemen mungkin belum diatur, atau akses mungkin dibatasi. Tanyakan kepada admin.
- **Tidak dapat menambah atau edit** — Tindakan ini mungkin dibatasi. Jika Anda tidak melihatnya, tanyakan kepada admin.
