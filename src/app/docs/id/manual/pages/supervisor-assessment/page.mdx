# Daftar Penilaian Supervisor

## Tujuan

Melihat dan mengelola penilaian supervisor: nama karyawan, posisi sebelumnya dan target, skor akhir, tanggal wawancara, dan hasil. Buat penilaian baru atau buka baris untuk melihat detail.

## Screenshot

![Daftar Penilaian Supervisor](/manual/pages/supervisor-assessment.png)

## Di halaman ini

1. **Penilaian Baru** — Buka form untuk membuat penilaian supervisor baru.
2. **Tabel penilaian** — Baris menampilkan Nama Karyawan, Posisi Sebelumnya, Posisi Target, Skor Akhir, Tanggal Wawancara, Hasil Penilaian.
3. **Menu baris** — Buka aksi untuk baris tersebut (mis. lihat detail); URL berisi ID penilaian.
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Penilaian Baru | Ke form penilaian baru. | Jika tidak terlihat, tanyakan ke admin. |
| 2 | Tabel penilaian | Daftar penilaian. | |
| 3 | Menu baris | Membuka detail atau aksi lain. | URL berisi ID penilaian. |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Buat penilaian** — Klik **+ Penilaian Baru**, isi form, dan simpan.
- **Lihat detail** — Buka menu baris dan pilih aksi untuk membuka penilaian (URL berisi ID).

## Pemecahan masalah

- **Daftar kosong** — Belum ada penilaian supervisor. Buat satu atau periksa filter. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa membuat atau membuka** — Mungkin dibatasi oleh peran. Jika tidak melihat tombol atau menu, tanyakan ke admin.
