# Pengaturan Cuti

## Tujuan

Melihat dan mengelola tipe cuti dan (opsional) saldo cuti. Gunakan tab **Tipe Cuti** untuk menambah atau mengedit tipe cuti; gunakan **Saldo Cuti** untuk pengaturan saldo.

## Screenshot

![Pengaturan Cuti](/manual/pages/leave-management.png)

## Di halaman ini

1. **Tab Tipe Cuti** — Menampilkan daftar tipe cuti.
2. **Tab Saldo Cuti** — Beralih ke tampilan saldo cuti.
3. **Tipe Cuti Baru** — Buka form untuk menambah tipe cuti.
4. **Tabel Tipe Cuti** — Nama Cuti, Pembaruan Terakhir.
5. **Aksi baris** — Menu pada setiap baris (mis. Edit).

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Tab Tipe Cuti | Menampilkan daftar tipe cuti. | |
| 2 | Tab Saldo Cuti | Menampilkan pengaturan saldo cuti. | |
| 3 | Tipe Cuti Baru | Membuka form Tambah Tipe Cuti. | Jika tidak terlihat, tanyakan ke admin. |
| 4 | Tabel Tipe Cuti | Daftar tipe cuti. | |
| 5 | Aksi baris | Edit (atau aksi lain) untuk tipe tersebut. | |

## Tugas umum

- **Tambah tipe cuti** — Klik **Tipe Cuti Baru**, isi nama, hak, kuota, lalu **Simpan**.
- **Edit tipe cuti** — Buka aksi baris dan pilih Edit (membuka halaman edit untuk ID tersebut).
- **Cek saldo cuti** — Beralih ke tab **Saldo Cuti**.

## Pemecahan masalah

- **Edit membuka 404** — Gunakan Edit dari menu baris untuk tipe cuti yang ada; URL menggunakan ID tipe tersebut.
- **Tidak bisa menambah atau mengedit** — Jika tidak melihat tombol atau menu baris, tanyakan ke admin.
