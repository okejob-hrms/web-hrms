# Ajukan Cuti

## Tujuan

Mengirim pengajuan cuti baru. Pilih karyawan, tetapkan persetujuan, tipe cuti, tanggal mulai dan akhir, alasan, dan lampiran opsional.

## Screenshot

![Ajukan Cuti](/manual/pages/leave-request-add.png)

## Di halaman ini

1. **Nama Karyawan** — Pilih karyawan.
2. **Persetujuan yang Ditugaskan** — Pilih satu atau lebih persetujuan.
3. **Tipe Cuti** — Pilih tipe cuti (mis. Sakit, Tahunan).
4. **Tanggal Mulai** — Pilih hari pertama cuti.
5. **Tanggal Akhir** — Pilih hari terakhir cuti.
6. **Alasan** — Masukkan alasan cuti.
7. **Pilih Lampiran** — Tambah file lampiran opsional.
8. **Batal** — Kembali tanpa menyimpan.
9. **Tambah Pengajuan Cuti** — Kirim pengajuan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Nama Karyawan | Pilih karyawan. | |
| 2 | Persetujuan yang Ditugaskan | Pilih siapa yang akan menyetujui. | |
| 3 | Tipe Cuti | Pilih tipe cuti. | |
| 4 | Tanggal Mulai | Hari pertama cuti. | |
| 5 | Tanggal Akhir | Hari terakhir cuti. | |
| 6 | Alasan | Alasan cuti. | |
| 7 | Pilih Lampiran | Tambah file jika perlu. | |
| 8 | Batal | Batalkan dan kembali. | |
| 9 | Tambah Pengajuan Cuti | Mengirim pengajuan. | |

## Tugas umum

- **Kirim pengajuan** — Pilih karyawan dan persetujuan, pilih tipe cuti dan tanggal, masukkan alasan, lalu klik **Tambah Pengajuan Cuti**.
- **Batal** — Klik **Batal** untuk kembali tanpa mengirim.

## Pemecahan masalah

- **Tidak bisa menyimpan** — Periksa kolom wajib (karyawan, persetujuan, tipe cuti, tanggal). Jika tidak punya izin, tanyakan ke admin.
