# Penilaian ESS

## Tujuan

Halaman ini mendaftar periode penilaian diri Anda. Anda dapat melihat nama periode, tanggal akhir, dan status (mis. Belum Dimulai). Gunakan ikon lihat (mata) untuk membuka penilaian dan melengkapinya.

## Tangkapan layar

![Penilaian ESS](/manual/pages/ess-assessment.png)

## Di halaman ini

1. **Tabel penilaian** — Daftar periode penilaian dengan Periode, Tanggal Akhir, dan Status.
2. **Lihat detail** — Ikon mata pada setiap baris untuk membuka penilaian tersebut.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Tabel penilaian | Daftar periode penilaian Anda. | Kolom: Periode, Tanggal Akhir, Status. |
| 2 | Lihat detail | Membuka penilaian untuk periode tersebut. | Gunakan untuk memulai atau melanjutkan. |

## Tugas umum

- **Lengkapi penilaian** — Klik ikon mata untuk periode yang Anda butuhkan; lalu isi dan kirim formulir.
- **Lihat periode mana yang terbuka** — Periksa kolom Status (mis. Belum Dimulai, Sedang Berjalan, Dikirim).
- **Periksa tanggal akhir** — Gunakan kolom Tanggal Akhir untuk melihat batas waktu.

## Pemecahan masalah

- **Tidak ada baris di tabel** — Belum ada periode penilaian yang diatur untuk Anda. Tanyakan kepada admin atau HR.
- **Ikon lihat tidak bereaksi** — Periode mungkin ditutup atau Anda tidak memiliki akses. Segarkan dan coba lagi, atau tanyakan kepada admin.
- **Status tidak diperbarui** — Setelah mengirim, segarkan halaman untuk melihat status baru.
