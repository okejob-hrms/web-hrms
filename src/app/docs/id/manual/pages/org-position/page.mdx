# Posisi Jabatan

## Tujuan

Lihat dan kelola posisi jabatan (mis. CEO, Manager, Junior Staff). Anda dapat menambah posisi baru dan menggunakan tindakan baris untuk mengedit atau mengelola masing-masing.

## Tangkapan layar

![Posisi Jabatan](/manual/pages/org-position.png)

## Di halaman ini

1. **Posisi Jabatan Baru** — Buka formulir untuk membuat posisi baru.
2. **Tabel posisi** — Daftar nama posisi dan pembaruan terakhir.
3. **Tindakan baris** — Menu pada setiap baris untuk mengedit atau mengelola posisi tersebut.
4. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Posisi Jabatan Baru | Membuka formulir untuk menambah posisi jabatan. | Jika Anda tidak melihat ini, tanyakan kepada admin. |
| 2 | Tabel posisi | Menampilkan semua posisi jabatan. | |
| 3 | Tindakan baris | Edit atau tindakan lain per posisi. | |
| 4 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Tambah posisi** — Klik **+ Posisi Jabatan Baru**, masukkan nama, dan simpan.
- **Edit posisi** — Buka tindakan baris pada baris tersebut dan pilih edit.
- **Lihat yang ada** — Gunakan tabel dan paginasi untuk menelusuri.

## Pemecahan masalah

- **Daftar kosong** — Posisi mungkin belum diatur, atau akses mungkin dibatasi. Tanyakan kepada admin.
- **Tidak dapat menambah atau edit** — Tindakan ini mungkin dibatasi. Jika Anda tidak melihatnya, tanyakan kepada admin.
