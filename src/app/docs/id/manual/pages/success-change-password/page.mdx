# Kata Sandi Berhasil Diubah

## Tujuan

Halaman ini mengonfirmasi bahwa kata sandi Anda berhasil diubah. Gunakan **Lanjutkan** untuk membuka halaman login dan masuk dengan kata sandi baru Anda.

## Tangkapan layar

![Kata Sandi Berhasil Diubah](/manual/pages/success-change-password.png)

## Di halaman ini

1. **Kembali** — Tautan untuk kembali ke halaman sebelumnya.
2. **Lanjutkan** — Tombol untuk membuka halaman login.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Kembali | Kembali ke halaman sebelumnya. | Jarang diperlukan setelah berhasil. |
| 2 | Lanjutkan | Membuka halaman login. | Gunakan untuk masuk dengan kata sandi baru Anda. |

## Tugas umum

- **Masuk dengan kata sandi baru** — Klik **Lanjutkan** untuk ke halaman login, lalu masukkan email dan kata sandi baru Anda.

## Pemecahan masalah

- **Lanjutkan tidak berfungsi** — Segarkan halaman dan coba lagi. Anda juga dapat membuka halaman login dari aplikasi atau bookmark.
- **Lupa kata sandi baru** — Gunakan alur atur ulang kata sandi lagi dari halaman login untuk mengatur kata sandi baru lainnya.
