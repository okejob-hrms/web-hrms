# Detail Offboarding

> **Ditandai:** Bagian ini adalah dokumentasi draf. Fitur offboarding belum sepenuhnya diperbaiki. Screenshot dan langkah akan diperbarui setelah fitur selesai.

## Tujuan

Melihat detail satu catatan offboarding. Halaman menampilkan informasi karyawan dan offboarding untuk catatan yang dipilih. URL berisi ID catatan (mis. .../off-boarding/16).

## Screenshot

![Detail Offboarding](/manual/pages/offboarding-detail.png)

## Di halaman ini

1. **Breadcrumb** — Menampilkan Off Boarding dan ID catatan; gunakan untuk melihat posisi Anda.
2. **Kembali ke daftar** — Klik "Off Boarding" di breadcrumb untuk kembali ke daftar.
3. **Konten detail atau pesan** — Area utama menampilkan detail offboarding, atau pesan jika catatan tidak ditemukan.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Breadcrumb | Jalur navigasi (Off Boarding / id). | |
| 2 | Kembali ke daftar | Tautan untuk kembali ke daftar offboarding. | |
| 3 | Konten detail atau pesan | Data offboarding atau "Data karyawan tidak ditemukan". | |

## Tugas umum

- **Buka detail** — Dari daftar offboarding, klik **Pratinjau** pada baris. URL akan menjadi `.../off-boarding/{id}`.
- **Ke penyesuaian gaji** — Dari halaman ini Anda mungkin punya tautan atau aksi untuk membuka halaman penyesuaian gaji untuk catatan ini (`.../off-boarding/{id}/salary-adjustment`).
- **Kembali ke daftar** — Klik **Off Boarding** di breadcrumb.

## Pemecahan masalah

- **"Data karyawan tidak ditemukan"** — Catatan mungkin telah dihapus atau ID tidak valid. Kembali ke daftar dan buka catatan lain, atau tanyakan ke admin.
- **Tidak bisa melihat detail** — Anda mungkin tidak punya izin untuk catatan ini. Jika tidak terlihat, tanyakan ke admin.
