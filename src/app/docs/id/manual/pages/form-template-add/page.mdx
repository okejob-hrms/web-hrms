# Tambah Template Form

## Tujuan

Membuat template form baru. Atur nama form dan penggunaan, lalu tambah pertanyaan. Simpan untuk membuat; Batal untuk membatalkan.

## Screenshot

![Tambah Template Form](/manual/pages/form-template-add.png)

## Di halaman ini

1. Edit — Beralih ke mode edit untuk nama dan penggunaan jika ditampilkan.
2. Nama Form, Penggunaan Form — Tampilan atau edit.
3. Tambah Pertanyaan — Tambah blok pertanyaan.
4. Batal — Kembali tanpa menyimpan.
5. Simpan — Buat form.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Edit | Edit nama dan penggunaan form. | |
| 2 | Nama Form, Penggunaan Form | Nama dan penggunaan form. | |
| 3 | Tambah Pertanyaan | Tambah pertanyaan ke form. | |
| 4 | Batal | Batalkan dan kembali. | |
| 5 | Simpan | Membuat form. | |

## Tugas umum

- Buat form: Atur Nama Form dan Penggunaan Form, klik Tambah Pertanyaan untuk menambah pertanyaan, lalu Simpan.
- Tambah beberapa pertanyaan: Klik Tambah Pertanyaan untuk masing-masing; atur tipe dan opsi sesuai kebutuhan.

## Pemecahan masalah

- Simpan dinonaktifkan: Atur nama form dan tambah setidaknya satu pertanyaan jika wajib.
- Tidak bisa mengakses: Jika tidak melihat halaman ini, tanyakan ke admin.
