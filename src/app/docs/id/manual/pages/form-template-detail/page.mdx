# Detail Template Form

## Tujuan

Melihat template form dalam bentuk hanya baca: nama, penggunaan, dan semua pertanyaan. Gunakan Edit Form untuk mengubah atau Hapus Form untuk menghapus jika tersedia.

## Screenshot

![Detail Template Form](/manual/pages/form-template-detail.png)

## Di halaman ini

1. **Nama Form, Penggunaan Form** — Tampilan di atas.
2. **Pengelompokan** — Pertanyaan dan opsi jawaban hanya baca.
3. **Edit Form** — Buka layar edit untuk form ini.
4. **Hapus Form** — Hapus form jika Anda punya izin.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Nama Form, Penggunaan Form | Menampilkan nama dan penggunaan. | |
| 2 | Pengelompokan | Daftar pertanyaan hanya baca. | |
| 3 | Edit Form | Membuka edit untuk form ini. | |
| 4 | Hapus Form | Menghapus form. | |

## Tugas umum

- **Tinjau form** — Buka dari daftar Template Form; URL berisi ID form.
- **Ubah form** — Klik Edit Form, lakukan perubahan, lalu Perbarui.

## Pemecahan masalah

- **Halaman tidak ditemukan** — Gunakan ID form dari daftar; buka detail dari menu baris.
- **Tidak bisa edit atau hapus** — Jika tidak melihat tombol tersebut, tanyakan ke admin.
