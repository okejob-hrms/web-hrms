# Lembur

## Tujuan

Melihat ringkasan pengajuan lembur dan daftar pengajuan lembur. Anda dapat beralih tab berdasarkan status, mencari berdasarkan karyawan, memfilter berdasarkan tanggal, dan menggunakan tabel untuk melihat atau mengelola pengajuan.

## Screenshot

![Lembur](/manual/pages/overtime.png)

## Di halaman ini

1. **Bagian ringkasan** — Kartu untuk pengajuan lembur Baru, Menunggu, Disetujui, dan Ditolak.
2. **Tab** — Beralih antara Menunggu persetujuan, Disetujui, Ditolak.
3. **Cari berdasarkan Nama atau Email Karyawan** — Ketik untuk menemukan pengajuan.
4. **Filter tanggal** — Filter berdasarkan tanggal.
5. **Tabel lembur** — Baris menampilkan Nama, Tanggal Lembur, Tanggal Pengajuan, Durasi, Catatan, Status (dan aksi baris bila ada data).
6. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Bagian ringkasan | Menampilkan jumlah berdasarkan status. | |
| 2 | Tab | Memfilter daftar berdasarkan status. | |
| 3 | Cari berdasarkan Nama atau Email Karyawan | Memfilter daftar. | |
| 4 | Filter tanggal | Filter berdasarkan tanggal. | |
| 5 | Tabel lembur | Daftar pengajuan; gunakan menu baris bila tersedia. | |
| 6 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Lihat berdasarkan status** — Gunakan tab untuk melihat pengajuan lembur menunggu, disetujui, atau ditolak.
- **Cari pengajuan** — Gunakan pencarian atau filter tanggal, lalu buka menu aksi baris untuk melihat atau mengedit.
- **Tambah lembur** — Jika tersedia, gunakan tombol atau aksi untuk membuat pengajuan baru. Jika tidak terlihat, tanyakan ke admin.

## Pemecahan masalah

- **Tabel tidak menampilkan data** — Periksa tab dan filter; mungkin belum ada pengajuan. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Mungkin dibatasi oleh peran. Jika tidak terlihat, tanyakan ke admin.
