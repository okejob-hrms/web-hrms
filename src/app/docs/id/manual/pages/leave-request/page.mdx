# Daftar Pengajuan Cuti

## Tujuan

Melihat ringkasan pengajuan cuti dan daftar pengajuan cuti. Anda dapat beralih tab (Menunggu persetujuan, Disetujui, Ditolak), mencari, memfilter berdasarkan tanggal, menambah pengajuan baru, atau menggunakan aksi baris untuk melihat detail, menyetujui, menolak, mengedit, atau menghapus.

## Di halaman ini

1. **Bagian ringkasan** — Kartu untuk Pengajuan Cuti Baru, Karyawan Cuti Hari Ini, Menunggu Persetujuan, Disetujui, Ditolak.
2. **Tab** — Beralih antara Menunggu persetujuan, Disetujui, Ditolak.
3. **Cari berdasarkan Nama atau Email Karyawan** — Ketik untuk menemukan pengajuan cuti.
4. **Filter tanggal** — Filter berdasarkan tanggal.
5. **Pengajuan Cuti Baru** — Buka form Ajukan Cuti.
6. **Tabel cuti** — Baris menampilkan Nama, Tipe cuti, Durasi, Alasan, Catatan, Status, Pembaruan Terakhir.
7. **Aksi baris** — Menu pada setiap baris (Detail, Setujui, Tolak, Edit, Hapus).
8. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Bagian ringkasan | Menampilkan jumlah untuk setiap status. | |
| 2 | Tab | Memfilter daftar berdasarkan status. | |
| 3 | Cari berdasarkan Nama atau Email Karyawan | Memfilter daftar. | |
| 4 | Filter tanggal | Filter berdasarkan tanggal. | |
| 5 | Pengajuan Cuti Baru | Ke form Ajukan Cuti. | Jika tidak terlihat, tanyakan ke admin. |
| 6 | Tabel cuti | Daftar pengajuan; gunakan menu baris untuk aksi. | |
| 7 | Aksi baris | Lihat detail, setujui, tolak, edit, atau hapus. | |
| 8 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Lihat berdasarkan status** — Gunakan tab untuk melihat pengajuan menunggu, disetujui, atau ditolak.
- **Ajukan cuti** — Klik **Pengajuan Cuti Baru**, isi form, dan kirim.
- **Edit pengajuan** — Buka aksi baris dan pilih Edit. URL berisi ID pengajuan (mis. .../leave-request/edit/1).

## Pemecahan masalah

- **Daftar kosong** — Periksa tab dan filter; hapus pencarian atau tanggal. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa menambah atau mengedit** — Mungkin dibatasi oleh peran. Jika tidak terlihat, tanyakan ke admin.
