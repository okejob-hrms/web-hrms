# Detail Karyawan

## Tujuan

Gunakan halaman Detail Karyawan untuk melihat catatan lengkap satu karyawan. URL berisi ID karyawan (mis. `/employee/employee-management/12`). Anda dapat beralih antar Informasi Pribadi, Dokumen, Payroll, Kehadiran, dan Penalty, serta membuka Edit dari sini.

## Tangkapan layar

![Detail Karyawan](/manual/pages/employee-management-detail.png)

## Di halaman ini

1. **Nama dan ID karyawan** — Menampilkan nama dan ID Karyawan di bagian atas.
2. **Edit Data Karyawan** — Membuka halaman Edit Karyawan untuk karyawan ini.
3. **Tab** — Informasi Pribadi, Dokumen, Payroll, Kehadiran, Penalty. Klik untuk beralih konten.
4. **Konten Informasi Pribadi** — Pengenalan Wajah, Peran Pengguna, Email, Telepon, Gender, Tempat Lahir, Tanggal Lahir, Status Pernikahan, Golongan Darah, Tinggi, Berat, Nomor ID, NPWP, BPJS, alamat, Hobi, Prestasi, Media Sosial.
5. **Informasi Karyawan** — Posisi, Departemen, Level Jabatan, Atasan Langsung Utama, Atasan Langsung Tambahan, Tim, Tanggal Mulai Karyawan, Tanggal Akhir Karyawan.
6. **Informasi Gaji dan Bank** — Gaji Pokok, Gaji (Bersih), Bank, Nomor Rekening, Nama Rekening.
7. **Tabel Informasi Keluarga** — Daftar anggota keluarga; **Tambah Informasi Keluarga** untuk menambah.
8. **Pendidikan Formal** — **Tambah Pendidikan Formal** untuk menambah catatan.
9. **Pengalaman Kerja, Pendidikan Non Formal, Referensi Kontak** — Bagian serupa dengan tombol Tambah.

## Tugas umum

- **Lihat karyawan** — Buka dari Daftar Karyawan (klik baris atau menu baris). URL detail berisi ID karyawan.
- **Edit karyawan ini** — Klik **Edit Data Karyawan**, ubah kolom, lalu **Perbarui** di halaman edit.
- **Tambah keluarga atau pendidikan** — Di bagian yang relevan, klik **Tambah Informasi Keluarga**, **Tambah Pendidikan Formal**, dan seterusnya.

## Pemecahan masalah

- **Halaman tidak ditemukan** — ID di URL mungkin salah atau karyawan mungkin telah dihapus. Kembali ke Daftar Karyawan dan buka catatan lagi.
- **Edit Data Karyawan tidak terlihat** — Anda mungkin tidak memiliki izin. Jika Anda tidak melihatnya, tanyakan kepada admin.
- **Tab tidak menampilkan data** — Beberapa tab memuat data saat dipilih. Tunggu sebentar atau segarkan.
