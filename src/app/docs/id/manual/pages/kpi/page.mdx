# KPI

## Tujuan

Melihat dan mengelola Key Performance Indicators (KPI): cari, buat KPI baru, dan lihat ID, nama, frekuensi, arah, dan target di daftar.

## Screenshot

![KPI](/manual/pages/kpi.png)

## Di halaman ini

1. **Cari KPI** — Ketik untuk memfilter daftar.
2. **KPI Baru** — Buka form untuk membuat KPI baru.
3. **Tabel KPI** — Baris menampilkan ID, Nama KPI, Frekuensi, Arah, Target.
4. **Menu baris** — Buka aksi untuk KPI tersebut (mis. edit, hapus).
5. **Paginasi** — Pindah antar halaman hasil.

## Kontrol

| Nomor | Nama | Fungsi | Catatan |
|--------|------|----------------|-------|
| 1 | Cari KPI | Memfilter daftar saat Anda mengetik. | |
| 2 | KPI Baru | Ke form KPI baru. | Jika tidak terlihat, tanyakan ke admin. |
| 3 | Tabel KPI | Daftar KPI. | |
| 4 | Menu baris | Edit atau hapus KPI tersebut. | |
| 5 | Paginasi | Sebelumnya / Berikutnya dan nomor halaman. | |

## Tugas umum

- **Buat KPI** — Klik **+ KPI Baru**, isi nama, frekuensi, arah, target, lalu simpan.
- **Cari KPI** — Gunakan **Cari KPI** untuk memfilter berdasarkan nama.
- **Edit atau hapus** — Buka menu baris dan pilih aksi.

## Pemecahan masalah

- **Daftar kosong** — Belum ada KPI, atau hapus pencarian. Jika tidak punya akses, tanyakan ke admin.
- **Tidak bisa membuat atau mengedit** — Mungkin dibatasi oleh peran. Jika tidak melihat tombol atau menu, tanyakan ke admin.
