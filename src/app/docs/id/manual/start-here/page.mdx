# Mulai di Sini

Selamat datang di panduan pengguna OkeJobHub HRMS. Gunakan panduan ini untuk mempelajari cara menggunakan aplikasi dan di mana menemukan setiap layar.

## Di mana menemukan panduan

Anda dapat membuka panduan ini dari aplikasi utama atau dengan masuk ke bagian dokumentasi HRMS. Panduan ini untuk semua pengguna sistem.

## Siapa melihat apa

| Peran | Yang Anda lihat setelah login |
|------|-------------------------------|
| **HR / Admin** | Dasbor, Karyawan, Kehadiran, Payroll, Kinerja, Pengaturan. Anda dapat mengelola staf, menyetujui permintaan, dan mengonfigurasi sistem. |
| **Karyawan** | Layanan Mandiri Karyawan (ESS). Anda dapat melihat info Anda, mengajukan cuti dan lembur, serta melengkapi penilaian. |

Jika Anda tidak melihat menu atau layar, tanyakan kepada admin Anda.
