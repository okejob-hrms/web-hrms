# Mobile ESS — Konsep Dasar

Istilah yang digunakan di aplikasi mobile **ESS CPS**. Untuk istilah HR di seluruh perusahaan, lihat juga [Konsep Dasar](/docs/manual/core-concepts) di panduan utama.

## Glosarium

- **ESS CPS** — Aplikasi HRMS mobile (Layanan Mandiri Karyawan di ponsel Anda). Berbeda dari halaman ESS web.
- **Tab Home** — Layar utama setelah login (clock in/out, pintasan). Di rute aplikasi ini `/dashboard`; di panduan web disebut **ESS**.
- **Web ESS** — Layanan Mandiri Karyawan di **browser** (`/ess`). Tata letak dan menu berbeda dari mobile.
- **Clock in / Clock out** — Mencatat awal dan akhir hari kerja Anda, sering dengan verifikasi lokasi dan wajah.
- **Inbox** — Daftar permintaan atau tugas yang memerlukan persetujuan atau tindakan Anda.
- **Primary direct report** — Manajer utama Anda di bagan organisasi (ditetapkan oleh HR).

## Peran (mobile)

- **Karyawan** — Menggunakan Home, Leave, Performance, Profile; mengajukan cuti dan kehadiran.
- **Supervisor / Manager** — Aplikasi yang sama; mungkin melihat persetujuan di kotak masuk serta penilaian manajer atau atasan untuk tim mereka.

Jika Anda tidak melihat tab atau item menu, peran Anda mungkin tidak mencakupnya. Tanyakan kepada admin Anda.

## Status

Sama seperti panduan utama: **Pending**, **Approved**, **Rejected** pada permintaan cuti, lembur, dan kehadiran.
