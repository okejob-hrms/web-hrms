# Mobile ESS — Mulai di Sini

Bagian ini mendokumentasikan aplikasi mobile native **ESS CPS** untuk karyawan. Ini terpisah dari halaman **Web ESS** di Panduan Pengguna utama (browser di `/ess`).

## Siapa yang menggunakan aplikasi mobile

Karyawan dan atasan menggunakan aplikasi mobile di Android (atau iOS) untuk clock in, mengajukan cuti, melihat slip gaji, melengkapi penilaian, dan menindaklanjuti item di kotak masuk.

## Navigasi bawah (5 tab)

| Tab | Fungsinya |
|-----|-----------|
| **Home** | Dashboard — kehadiran, tindakan cepat, aktivitas terbaru |
| **Performance** | OKR dan penilaian |
| **Leave Request** | Daftar cuti dan permintaan baru |
| **Inbox** | Item yang menunggu tindakan Anda |
| **Profile** | Akun dan detail karyawan Anda |

## Web ESS vs Mobile

| | Web ESS | Aplikasi mobile (panduan ini) |
|---|---------|-------------------------------|
| Akses | Browser, `/ess` | Instal **ESS CPS** di ponsel Anda |
| Layar beranda | Tindakan cepat Web ESS | Tab **Home** (`/dashboard`) |

Jika fitur tidak tersedia di mobile, perusahaan Anda mungkin hanya menyediakannya di web — tanyakan kepada admin Anda.
