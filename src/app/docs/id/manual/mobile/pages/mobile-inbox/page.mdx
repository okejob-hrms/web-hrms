# Mobile: Inbox

## Tujuan

Gunakan tab **Inbox** di aplikasi mobile ESS CPS. Ini bukan pengalaman Web ESS di browser.

## Tangkapan layar

![Mobile: Inbox](/manual/mobile/pages/mobile-inbox.png)

## Di halaman ini

1. **Inbox list** — Lihat tabel kontrol.
2. **Inbox item** — Lihat tabel kontrol.
3. **Bottom navigation** — Lihat tabel kontrol.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Inbox list | Kontrol utama di layar ini. | Item yang menunggu tindakan Anda. |
| 2 | Inbox item | Kontrol utama di layar ini. | Buka untuk menyetujui atau menolak. |
| 3 | Bottom navigation | Kontrol utama di layar ini. | Beralih antar tab. |

## Tugas umum

- **Gunakan layar ini** — Ikuti alur: masuk sebagai Supervisor → ketuk tab **Inbox**
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan kepada admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (slip gaji, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan akses lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.

**Prasyarat untuk capture/pengujian:** Akun Supervisor; item inbox tertunda jika memungkinkan
