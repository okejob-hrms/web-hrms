# Mobile: Payslip View Request

## Tujuan

Gunakan **Payslip View Request** di aplikasi mobile ESS CPS (memerlukan payload tambahan). Ini bukan pengalaman Web ESS di browser. Setelah HR menyetujui permintaan Anda, Anda dapat melihat slip gaji selama **3 hari**; ajukan ulang jika akses kedaluwarsa.

## Tugas umum

- **Gunakan layar ini** — Ikuti alur daftar Payslip → pilih periode → permintaan lihat
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan kepada admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (slip gaji, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan akses lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.

**Prasyarat untuk capture/pengujian:** Data slip gaji
