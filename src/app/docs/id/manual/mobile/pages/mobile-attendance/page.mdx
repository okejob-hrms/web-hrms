# Mobile: Attendance & Overtime

## Tujuan

**Attendance and Overtime** adalah pusat riwayat Anda: catatan kehadiran bulanan, statistik ringkasan, dan tab **Overtime** terpisah untuk permintaan lembur. Buka dari **Profile** untuk meninjau clock in sebelumnya atau meminta koreksi.

## Tangkapan layar

![Mobile: Attendance & Overtime](/manual/mobile/pages/mobile-attendance.png)

## Di halaman ini

1. **Back** — Kembali ke [Mobile: Profile](/docs/manual/mobile/pages/mobile-profile).
2. **Attendance tab** — Daftar catatan kehadiran harian (dipilih secara default).
3. **Overtime tab** — Daftar permintaan lembur untuk bulan yang sama.
4. **Month selector** — Mengubah bulan yang ditampilkan di statistik dan daftar.
5. **Summary stats** — Hari clock in terlambat, hari clock out lebih awal, jam lembur, hari absen, dan kuota hari libur.
6. **Attendance heading** — Judul bagian di atas daftar catatan.
7. **Filter** — Memfilter baris kehadiran berdasarkan status (All, Waiting, Approved, Rejected).
8. **Attendance record row** — Tanggal, waktu clock in/out, durasi, chip status, dan ikon edit.
9. **Edit icon** — Membuka [Mobile: Edit Attendance](/docs/manual/mobile/pages/mobile-attendance-edit) untuk hari tersebut.

## Tugas umum

- **Tinjau kehadiran bulan ini** — Buka **Profile** → **Attendance and Overtime**, konfirmasi bulan, gulir daftar.
- **Minta koreksi waktu** — Ketuk ikon **edit** pada baris → sesuaikan waktu di [Mobile: Edit Attendance](/docs/manual/mobile/pages/mobile-attendance-edit).
- **Filter berdasarkan status persetujuan** — Ketuk **Filter**, pilih Waiting, Approved, atau Rejected.

## Pemecahan masalah

- **Tidak ada data kehadiran untuk periode ini** — Anda mungkin belum clock in bulan itu, atau HR belum mempublikasikan catatan.
- **Tidak dapat mengedit baris** — Beberapa status mungkin terkunci setelah disetujui; tanyakan HR.
- **Layar tidak tersedia** — Tanyakan admin Anda jika Anda tidak melihat **Attendance and Overtime** di Profile.

**Alur terkait:** Setelah Anda [Clock in di mobile](/docs/workflows/mobile-clock-in), catatan baru muncul di sini untuk bulan berjalan.
