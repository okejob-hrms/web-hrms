# Mobile: Profile

## Tujuan

Gunakan tab **Profile** di aplikasi mobile ESS CPS. Ini bukan pengalaman Web ESS di browser.

## Tangkapan layar

![Mobile: Profile](/manual/mobile/pages/mobile-profile.png)

## Di halaman ini

1. **Profile header** — Lihat tabel kontrol.
2. **Employee details** — Lihat tabel kontrol.
3. **Payslip** — Lihat tabel kontrol.
4. **Log Out** — Lihat tabel kontrol.
5. **Bottom navigation** — Lihat tabel kontrol.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Profile header | Kontrol utama di layar ini. | Foto dan ringkasan. |
| 2 | Employee details | Kontrol utama di layar ini. | Lihat info pribadi dan pekerjaan. |
| 3 | Payslip | Kontrol utama di layar ini. | Buka daftar slip gaji jika tersedia. |
| 4 | Log Out | Kontrol utama di layar ini. | Keluar dari aplikasi mobile. |
| 5 | Bottom navigation | Kontrol utama di layar ini. | Beralih antar tab utama. |

## Tugas umum

- **Gunakan layar ini** — Ikuti alur: masuk sebagai Employee A → ketuk tab **Profile**
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan kepada admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (slip gaji, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan akses lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.

**Prasyarat untuk capture/pengujian:** Akun Employee A
