# Mobile: Leave Request

## Tujuan

Gunakan tab **Leave Request** di aplikasi mobile ESS CPS. Ini bukan pengalaman Web ESS di browser.

## Tangkapan layar

![Mobile: Leave Request](/manual/mobile/pages/mobile-leave-request.png)

## Di halaman ini

1. **Leave list** — Lihat tabel kontrol.
2. **Add / New leave** — Lihat tabel kontrol.
3. **Bottom navigation** — Lihat tabel kontrol.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Leave list | Kontrol utama di layar ini. | Permintaan cuti Anda. |
| 2 | Add / New leave | Kontrol utama di layar ini. | Membuat permintaan baru. |
| 3 | Bottom navigation | Kontrol utama di layar ini. | Beralih antar tab. |

## Tugas umum

- **Gunakan layar ini** — Ikuti alur: masuk sebagai Employee A → ketuk tab **Leave Request**
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan kepada admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (slip gaji, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan akses lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.

**Prasyarat untuk capture/pengujian:** Akun Employee A
