# Mobile: Performance

## Tujuan

Gunakan tab **Performance** di aplikasi mobile ESS CPS. Ini bukan pengalaman Web ESS di browser.

## Tangkapan layar

![Mobile: Performance](/manual/mobile/pages/mobile-performance.png)

## Di halaman ini

1. **OKR** — Lihat tabel kontrol.
2. **Self Assessment** — Lihat tabel kontrol.
3. **Manager Assessment** — Lihat tabel kontrol.
4. **Supervisor Assessment** — Lihat tabel kontrol.
5. **Bottom navigation** — Lihat tabel kontrol.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | OKR | Kontrol utama di layar ini. | Objectives and key results. |
| 2 | Self Assessment | Kontrol utama di layar ini. | Formulir penilaian Anda. |
| 3 | Manager Assessment | Kontrol utama di layar ini. | Jika Anda mengelola bawahan langsung. |
| 4 | Supervisor Assessment | Kontrol utama di layar ini. | Alur tinjauan supervisor. |
| 5 | Bottom navigation | Kontrol utama di layar ini. | Beralih antar tab. |

## Tugas umum

- **Gunakan layar ini** — Ikuti alur: masuk sebagai Employee A → ketuk tab **Performance**
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan kepada admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (slip gaji, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan akses lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.

**Prasyarat untuk capture/pengujian:** Akun Employee A
