# Mobile: Home (Dashboard)

## Tujuan

Tab **Home** adalah dasbor mobile Anda setelah masuk: konteks perusahaan, **Clock In** / **Clock Out** cepat, pintasan ke lembur dan cuti, serta aktivitas terbaru. Ini menggantikan beranda Web ESS di browser — tugas karyawan yang sama, tata letak berbeda.

## Tangkapan layar

![Mobile: Home (Dashboard)](/manual/mobile/pages/mobile-dashboard.png)

## Di halaman ini

1. **Company / branch** — Label cabang yang ditetapkan kepada Anda.
2. **Employee name** — Nama tampilan Anda.
3. **Job title** — Jabatan Anda.
4. **Today's date** — Tanggal hari ini di **Home**.
5. **Clock In** — Memulai kehadiran hari ini (verifikasi lokasi dan wajah mungkin diperlukan).
6. **Clock Out** — Mengakhiri shift hari ini setelah Anda clock in.
7. **Overtime Request** — Pintasan untuk mengajukan lembur.
8. **New Leave Request** — Pintasan untuk membuat permintaan cuti.
9. **Recent Activity** — Kehadiran atau cuti terbaru (mungkin kosong).
10. **Home tab** — Anda berada di **Home** (terpilih di bottom navigation).
11. **Performance tab** — Membuka area kinerja dan OKR.
12. **Leave Request tab** — Membuka daftar cuti Anda.
13. **Inbox tab** — Membuka item yang menunggu tindakan Anda.
14. **Profile tab** — Membuka profil dan keluar.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Company / branch | Menampilkan nama cabang. | Hanya tampilan. |
| 2 | Employee name | Menampilkan nama Anda. | Hanya tampilan. |
| 3 | Job title | Menampilkan jabatan. | Hanya tampilan. |
| 4 | Today's date | Menampilkan tanggal hari ini. | Hanya tampilan. |
| 5 | Clock In | Memulai alur clock in. | Mungkin memerlukan GPS dan pencocokan wajah. |
| 6 | Clock Out | Mengakhiri shift. | Nonaktif sampai Anda clock in. |
| 7 | Overtime Request | Membuka permintaan lembur. | Sama seperti jalur Performance/Leave. |
| 8 | New Leave Request | Membuka formulir cuti baru. | Lihat [Mobile: New Leave Request](/docs/manual/mobile/pages/mobile-leave-request-form). |
| 9 | Recent Activity | Mencantumkan aktivitas terbaru. | Kosong sampai Anda memiliki aktivitas. |
| 10–14 | Bottom tabs | Beralih antar bagian utama. | Lima tab: **Home**, **Performance**, **Leave Request**, **Inbox**, **Profile**. |

## Tugas umum

- **Clock in** — Ikuti [Clock in di mobile](/docs/workflows/mobile-clock-in): **Clock In** → lokasi → wajah (jika diperlukan) → formulir kehadiran.
- **Clock out** — Ikuti [Clock out di mobile](/docs/workflows/mobile-clock-out) setelah Anda clock in.
- **Ajukan cuti dengan cepat** — Ketuk **New Leave Request**.
- **Ajukan lembur** — Ketuk **Overtime Request**.

## Pemecahan masalah

- **Clock Out nonaktif** — Anda harus **Clock In** terlebih dahulu untuk hari itu.
- **Lokasi atau wajah gagal** — Izinkan akses lokasi; berdiri dalam jangkauan lokasi kerja; daftar ulang wajah jika ketidakcocokan berlanjut. Tanyakan HR jika masalah berlanjut.
- **Tidak ada aktivitas terbaru** — Normal untuk akun baru sampai Anda clock in atau mengajukan cuti.
- **Fitur Web ESS tidak ada** — Beberapa fitur admin hanya tersedia di browser; tanyakan admin Anda.
