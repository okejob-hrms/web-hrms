# Mobile: Splash

## Tujuan

Gunakan layar **Splash** di aplikasi mobile ESS CPS (mungkin muncul sebentar saat sudah masuk). Ini bukan pengalaman Web ESS di browser.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Konten layar | Kontrol utama di layar ini. | Area utama layar ini. |
| 2 | Back | Kontrol utama di layar ini. | Kembali ke layar sebelumnya jika ditampilkan. |
| 3 | Primary action | Kontrol utama di layar ini. | Tombol utama untuk tugas ini. |
| 4 | Bottom navigation | Kontrol utama di layar ini. | Hanya terlihat di tab utama. |

## Tugas umum

- **Gunakan layar ini** — Ikuti alur: cold start aplikasi → splash terlihat sebentar sebelum dialihkan ke login atau dasbor
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan kepada admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (slip gaji, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan akses lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.
