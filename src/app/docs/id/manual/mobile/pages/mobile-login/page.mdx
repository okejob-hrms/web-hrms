# Mobile: Login

## Tujuan

Gunakan layar **Login** di aplikasi mobile ESS CPS untuk masuk dengan email kerja dan kata sandi Anda. Setelah masuk, Anda akan berada di tab **Home**. Ini bukan login Web HRMS di browser.

## Tangkapan layar

![Mobile: Login](/manual/mobile/pages/mobile-login.png)

## Di halaman ini

1. **Logo** — Branding aplikasi di bagian atas formulir.
2. **Email** — Kolom untuk alamat email kerja Anda.
3. **Password** — Kolom untuk kata sandi Anda.
4. **Show/hide password** — Alihkan untuk menampilkan atau menyembunyikan yang Anda ketik.
5. **Reset Password** — Membuka alur atur ulang kata sandi di mobile.
6. **Sign In** — Mengirim kredensial Anda dan membuka aplikasi.

## Kontrol

| No | Nama | Fungsi | Catatan |
|----|------|--------|---------|
| 1 | Logo | Menampilkan branding aplikasi. | Hanya tampilan. |
| 2 | Email | Masukkan email kerja terdaftar Anda. | Harus format email yang valid. |
| 3 | Password | Masukkan kata sandi Anda. | Panjang minimum ditetapkan server. |
| 4 | Show/hide password | Mengalihkan visibilitas kata sandi. | Gunakan untuk memverifikasi pengetikan. |
| 5 | Reset Password | Menavigasi ke layar atur ulang kata sandi. | Gunakan jika Anda lupa kata sandi. |
| 6 | Sign In | Memasukkan Anda dan membuka **Home**. | Nonaktif saat permintaan sedang diproses. |

## Tugas umum

- **Masuk** — Masukkan email dan kata sandi, lalu ketuk **Sign In**. Anda akan diarahkan ke tab [Mobile: Home](/docs/manual/mobile/pages/mobile-dashboard).
- **Atur ulang kata sandi** — Ketuk **Reset Password**, masukkan email Anda, dan ikuti instruksi di kotak masuk Anda.
- **Login pertama** — Anda mungkin diminta [membuat kata sandi baru](/docs/manual/mobile/pages/mobile-create-password) sebelum menggunakan aplikasi.

## Pemecahan masalah

- **Email atau kata sandi tidak valid** — Periksa caps lock dan pastikan Anda menggunakan email yang terdaftar di HRMS. Coba **Reset Password** atau hubungi admin Anda.
- **Sign In tidak bereaksi** — Periksa data seluler atau Wi‑Fi. Pastikan aplikasi dapat menjangkau API perusahaan Anda.
- **Kolom Password wajib diisi** — Masukkan kata sandi lagi sebelum mengetuk **Sign In**.
- **Anda mengharapkan Web ESS** — Instal dan gunakan aplikasi mobile untuk alur kerja di ponsel; buka `/ess` di browser untuk Web ESS.
