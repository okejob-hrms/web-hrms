## Tugas umum

- **Gunakan layar ini** — Ikuti tab Leave Request → ketuk tambah/permintaan cuti baru
- **Terkait** — Lihat [Referensi Halaman Mobile](/docs/manual/mobile/pages).

## Pemecahan masalah

- **Layar tidak tersedia** — Peran atau pengaturan perusahaan Anda mungkin menyembunyikan fitur ini. Tanyakan admin Anda.
- **Daftar kosong** — Anda mungkin memerlukan permintaan sebelumnya atau HR untuk mempublikasikan data (payslip, OKR, offboarding).
- **Error lokasi atau wajah** — Izinkan izin lokasi; untuk ketidakcocokan wajah, daftar ulang atau hubungi HR.
