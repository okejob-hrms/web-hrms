# Mobile ESS — Core Concepts

Terms used in the **ESS CPS** mobile app. For company-wide HR terms, see also [Core Concepts](/docs/en/manual/core-concepts) in the main manual.

## Glossary

- **ESS CPS** — The mobile HRMS app (Employee Self-Service on your phone). Not the same as the web ESS page.
- **Home tab** — The main screen after login (clock in/out, shortcuts). In the app route this is `/dashboard`; in the web manual it is called **ESS**.
- **Web ESS** — Employee Self-Service in the **browser** (`/ess`). Layout and menus differ from mobile.
- **Clock in / Clock out** — Record start and end of your work day, often with location and face verification.
- **Inbox** — List of requests or tasks that need your approval or action.
- **Primary direct report** — Your main manager in the org chart (set by HR).

## Roles (mobile)

- **Employee** — Uses Home, Leave, Performance, Profile; submits leave and attendance.
- **Supervisor / Manager** — Same app; may see inbox approvals and manager or supervisor assessments for their team.

If you do not see a tab or menu item, your role may not include it. Ask your admin.

## Statuses

Same as the main manual: **Pending**, **Approved**, **Rejected** on leave, overtime, and attendance requests.
