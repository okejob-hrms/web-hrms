# Mobile: Inbox

## Purpose

Use **Inbox** in the ESS CPS mobile app. This is not the Web ESS browser experience.

## Screenshot

![Mobile: Inbox](/manual/mobile/pages/mobile-inbox.png)

## On this page

1. **Inbox list** — See controls table.
2. **Inbox item** — See controls table.
3. **Bottom navigation** — See controls table.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Inbox list | Primary control on this screen. | Items awaiting your action. |
| 2 | Inbox item | Primary control on this screen. | Open to approve or reject. |
| 3 | Bottom navigation | Primary control on this screen. | Switch tabs. |

## Common tasks

- **Use this screen** — Follow Login as Supervisor → tap Inbox tab
- **Related** — See [Mobile Page Reference](/docs/en/manual/mobile/pages).

## Troubleshooting

- **Screen not available** — Your role or company setup may hide this feature. Ask your admin.
- **Empty list** — You may need prior requests or HR to publish data (payslip, OKR, offboarding).
- **Location or face errors** — Allow location permission; for face mismatch, re-register or contact HR.

**Prerequisites for capture/testing:** Supervisor account; Pending inbox item if possible
