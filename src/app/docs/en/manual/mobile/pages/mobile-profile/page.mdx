# Mobile: Profile

## Purpose

Use **Profile** in the ESS CPS mobile app. This is not the Web ESS browser experience.

![Mobile: Profile](/manual/mobile/pages/mobile-profile.png)

## On this page

1. **Profile header** — See controls table.
2. **Employee details** — See controls table.
3. **Payslip** — See controls table.
4. **Log Out** — See controls table.
5. **Bottom navigation** — See controls table.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Profile header | Primary control on this screen. | Photo and summary. |
| 2 | Employee details | Primary control on this screen. | View personal and job info. |
| 3 | Payslip | Primary control on this screen. | Open payslip list if available. |
| 4 | Log Out | Primary control on this screen. | Sign out of the mobile app. |
| 5 | Bottom navigation | Primary control on this screen. | Switch between main tabs. |

## Common tasks

- **Use this screen** — Follow Login as Employee A → tap Profile tab
- **Related** — See [Mobile Page Reference](/docs/en/manual/mobile/pages).

## Troubleshooting

- **Screen not available** — Your role or company setup may hide this feature. Ask your admin.
- **Empty list** — You may need prior requests or HR to publish data (payslip, OKR, offboarding).
- **Location or face errors** — Allow location permission; for face mismatch, re-register or contact HR.

**Prerequisites for capture/testing:** Employee A account
