# Mobile: Payslip View

## Purpose

Use **Payslip View** in the ESS CPS mobile app. This is not the Web ESS browser experience. Access stays valid for **3 days** from approval; after that you must request view access again.

## Troubleshooting

- **Screen not available** — Your role or company setup may hide this feature. Ask your admin.
- **Empty list** — You may need prior requests or HR to publish data (payslip, OKR, offboarding).
- **Location or face errors** — Allow location permission; for face mismatch, re-register or contact HR.

**Prerequisites for capture/testing:** Payslip data
