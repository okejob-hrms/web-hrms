# Mobile: Leave Request

## Purpose

Use **Leave Request** in the ESS CPS mobile app. This is not the Web ESS browser experience.

## Screenshot

![Mobile: Leave Request](/manual/mobile/pages/mobile-leave-request.png)

## On this page

1. **Leave list** — See controls table.
2. **Add / New leave** — See controls table.
3. **Bottom navigation** — See controls table.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Leave list | Primary control on this screen. | Your leave requests. |
| 2 | Add / New leave | Primary control on this screen. | Create a new request. |
| 3 | Bottom navigation | Primary control on this screen. | Switch tabs. |

## Common tasks

- **Use this screen** — Follow Login as Employee A → tap Leave Request tab
- **Related** — See [Mobile Page Reference](/docs/en/manual/mobile/pages).

## Troubleshooting

- **Screen not available** — Your role or company setup may hide this feature. Ask your admin.
- **Empty list** — You may need prior requests or HR to publish data (payslip, OKR, offboarding).
- **Location or face errors** — Allow location permission; for face mismatch, re-register or contact HR.

**Prerequisites for capture/testing:** Employee A account
