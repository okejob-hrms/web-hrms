# Mobile ESS — Start Here

This section documents the **ESS CPS** native mobile app for employees. It is separate from the **Web ESS** pages in the main User Manual (browser at `/ess`).

## Who uses the mobile app

Employees and supervisors use the mobile app on Android (or iOS) to clock in, request leave, view payslips, complete assessments, and act on inbox items.

## Bottom navigation (5 tabs)

| Tab | What it is for |
|-----|----------------|
| **Home** | Dashboard — attendance, quick actions, recent activity |
| **Performance** | OKR and assessments |
| **Leave Request** | Leave list and new requests |
| **Inbox** | Items waiting for your action |
| **Profile** | Your account and employee details |

## Web ESS vs Mobile

| | Web ESS | Mobile app (this guide) |
|---|---------|-------------------------|
| Access | Browser, `/ess` | Install **ESS CPS** on your phone |
| Home screen | Web ESS quick actions | **Home** tab (`/dashboard`) |

If a feature is missing on mobile, your company may only offer it on the web — ask your admin.

## Daily attendance (clock in / out)

Most employees start here:

1. [Clock in on mobile](/docs/en/workflows/mobile-clock-in) — Home → location → face (if required) → attendance form
2. [Clock out on mobile](/docs/en/workflows/mobile-clock-out) — Same verification steps at end of day
3. [Mobile: Attendance & Overtime](/docs/en/manual/mobile/pages/mobile-attendance) — Review history or request a correction
