# Edit Company Profile

## Purpose

Edit company information and payroll (bank) details: name, legal entity, contact, address, and bank account. Change the logo with **Select Image**.

## Screenshot

![Edit Company Profile](/manual/pages/company-profile-edit.png)

## On this page

1. **Company Logo** — **Select Image** to change the logo.
2. **Company Information fields** — Company Name, Legal Entity, Industry, Email, Phone, Business Registration Number, Website, Address.
3. **Payroll Information fields** — Bank Account Name, Number, Holder, Currency.
4. **Cancel** — Go back without saving.
5. **Save** — Save changes.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Company Logo | Change logo image. | |
| 2 | Company Information fields | Edit company details. | |
| 3 | Payroll Information fields | Edit bank details. | |
| 4 | Cancel | Leaves without saving. | |
| 5 | Save | Saves changes. | If you don't see this, ask your admin. |

## Common tasks

- **Update company details** — Edit the fields, then click **Save**.
- **Update bank details** — Edit Payroll Information, then **Save**.

## Troubleshooting

- **Cannot save** — You may need permission. If you don't see **Save**, ask your admin.
