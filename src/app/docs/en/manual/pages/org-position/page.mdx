# Job Positions

## Purpose

View and manage job positions (e.g. CEO, Manager, Junior Staff). You can add new positions and use row actions to edit or manage each one.

## Screenshot

![Job Positions](/manual/pages/org-position.png)

## On this page

1. **New Job Position** — Open the form to create a new position.
2. **Positions table** — Lists position name and last update.
3. **Row actions** — Menu on each row to edit or manage that position.
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Job Position | Opens form to add a job position. | If you don't see this, ask your admin. |
| 2 | Positions table | Shows all job positions. | |
| 3 | Row actions | Edit or other actions per position. | |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Add a position** — Click **+ New Job Position**, enter the name, and save.
- **Edit a position** — Open row actions on that row and choose edit.
- **See what exists** — Use the table and pagination to browse.

## Troubleshooting

- **List is empty** — Positions may not be set up yet, or access may be restricted. Ask your admin.
- **Cannot add or edit** — These actions may be restricted. If you don't see them, ask your admin.
