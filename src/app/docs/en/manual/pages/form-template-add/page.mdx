# Add Form Template

## Purpose

Create a new form template. Set form name and usage, then add questions. Save to create; Cancel to discard.

## Screenshot

![Add Form Template](/manual/pages/form-template-add.png)

## On this page

1. Edit — Switch to edit mode for name and usage if shown.
2. Form Name, Form Usage — Display or edit.
3. Add Question — Add a question block.
4. Cancel — Return without saving.
5. Save — Create the form.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Edit | Edit form name and usage. | |
| 2 | Form Name, Form Usage | Name and usage of the form. | |
| 3 | Add Question | Add a question to the form. | |
| 4 | Cancel | Discard and go back. | |
| 5 | Save | Create form. | |

## Common tasks

- Create a form: Set Form Name and Form Usage, click Add Question to add questions, then Save.
- Add multiple questions: Click Add Question for each; set type and options as needed.

## Troubleshooting

- Save disabled: Set form name and add at least one question if required.
- Cannot access: If you do not see this page, ask your admin.
