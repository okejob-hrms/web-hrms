# Competency Detail

## Purpose

View a competency’s code, name, description, and levels. Use **Edit** to change the competency; use **+ Add Level** to add levels (dimensions, level name, description).

## Screenshot

![Competency Detail](/manual/pages/competencies-detail.png)

## On this page

1. **Edit** — Open edit for this competency.
2. **Competency Code, Name, Description** — Display at top.
3. **Add Level** — Add a level row to the Level table.
4. **Level table** — Dimensions, Level, Level Name, Description (and row actions).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Edit | Opens edit for this competency. | If you don't see this, ask your admin. |
| 2 | Competency Code, Name, Description | Shows competency details. | |
| 3 | Add Level | Adds a level. | |
| 4 | Level table | Lists levels; edit/delete per row. | |

## Common tasks

- **View competency** — Open from Competencies list; URL includes competency ID (e.g. .../1).
- **Add levels** — Click **+ Add Level**, fill dimensions and level name/description, then save.
- **Change competency** — Click **Edit**, update code/name/description, then save.

## Troubleshooting

- **Shows “-” or no data** — The ID in the URL may not exist; open detail from the list for a valid competency.
- **Cannot edit or add level** — If you don't see those options, ask your admin.
