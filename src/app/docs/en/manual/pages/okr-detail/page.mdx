# OKR Detail

## Purpose

View one OKR cycle: period, dates, overall achievement, and key result counts. Add objectives, switch between Objective Key Result, Key Result, and Dashboard tabs. The URL includes the cycle ID.

## Screenshot

![OKR Detail](/manual/pages/okr-detail.png)

## On this page

1. **Cycle title and status** — Period name (e.g. Q5 2026) and status (Draft or Active).
2. **Start Date, End Date** — Cycle date range.
3. **Overall Achievement** — Average progress (percentage).
4. **Total Key Result, Open, Completed** — Counts for key results.
5. **Objective Key Result tab** — List and manage objectives.
6. **Key Result tab** — View key results.
7. **Dashboard tab** — Dashboard view for this cycle.
8. **Search** — Filter objectives or key results.
9. **Add New Objective** — Add an objective to this cycle.

| Number | Name | What it does | Notes |

## Common tasks

- **Add an objective** — Click **Add New Objective**, fill the form, save.
- **View key results** — Open the **Key Result** or **Dashboard** tab.
- **Check progress** — Use Overall Achievement and the key result counts.

## Troubleshooting

- **Page not found** — The cycle ID in the URL must exist. Open from the OKR list first. If you don't have access, ask your admin.
- **Cannot add objective** — This may be restricted by role. If you don't see **Add New Objective**, ask your admin.
