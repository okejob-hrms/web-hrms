# Allowance

## Purpose

View and manage allowances by type and job level. Use Set Up Allowance to add one; use row actions to edit or delete.

## Screenshot

![Allowance](/manual/pages/salary-allowance.png)

## On this page

1. Set Up Allowance — Open the form to add an allowance.
2. Allowance table — Allowance Type, Job Level, Effective Date, Last Update.
3. Row actions — Menu on each row for Edit or Delete.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Set Up Allowance | Opens add or setup form. | |
| 2 | Allowance table | Lists type, level, dates. | |
| 3 | Row actions | Edit or delete that allowance. | |

## Common tasks

- Add an allowance: Click Set Up Allowance, choose type and job level, set amount and effective date, then save.
- Edit an allowance: Open row actions and choose Edit.
- Check effective date: Use Effective Date and Last Update columns.

## Troubleshooting

- List empty: Add allowances or check filters. If you do not have access, ask your admin.
- Cannot add or edit: If you do not see them, ask your admin.
