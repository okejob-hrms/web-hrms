# Edit Leave Request

## Purpose

Change an existing leave request. The form shows the same fields as Request Leave; use **Update Leave Request** to save. The URL contains the request ID (e.g. .../leave-request/edit/1).

## Screenshot

![Edit Leave Request](/manual/pages/leave-request-edit.png)

## On this page

1. **Employee Name** — Selected employee (editable).
2. **Assigned Approver** — Approvers (editable).
3. **Leave Type** — Leave type (editable).
4. **Start Date** — Start date (editable).
5. **End Date** — End date (editable).
6. **Reason** — Reason (editable).
7. **Select Attachments** — Attachments (editable).
8. **Cancel** — Discard changes and go back.
9. **Update Leave Request** — Save changes.

## Common tasks

- **Edit a request** — From the list, open row actions and choose Edit. Change fields and click **Update Leave Request**.
- **Return without saving** — Click **Cancel**.

## Troubleshooting

- **Page does not load** — The request may not exist or the ID may be invalid. Return to the list and open another request.
- **Cannot update** — Check permissions. If you don't see Update or it fails, ask your admin.
