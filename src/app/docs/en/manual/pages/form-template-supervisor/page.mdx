# Supervisor Assessment Template

## Purpose

Configure the supervisor assessment form template. Use Add Question to build the form; Save to store; Cancel to discard.

## Screenshot

![Supervisor Assessment Template](/manual/pages/form-template-supervisor.png)

## On this page

1. Form Details — Form Name and Form Usage.
2. Add Question — Add a question to the template.
3. Cancel — Return without saving.
4. Save — Save the supervisor assessment template.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Form Details | Form name and usage. | |
| 2 | Add Question | Add question blocks. | |
| 3 | Cancel | Discard and go back. | |
| 4 | Save | Save template. | |

## Common tasks

- Set up the template: Set name and usage, add questions with Add Question, then Save.
- Add questions: Click Add Question for each item; set type and options as needed.

## Troubleshooting

- Save disabled: Ensure form name, usage and at least one question are set if required.
- Cannot access: If you do not see this page, ask your admin.
