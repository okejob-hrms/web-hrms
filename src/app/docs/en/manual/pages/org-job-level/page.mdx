# Job Levels

## Purpose

View and manage job levels (e.g. Direktur, Manager, Junior Staff) and their numeric level. You can add new levels and use row actions to edit each one.

## Screenshot

![Job Levels](/manual/pages/org-job-level.png)

## On this page

1. **New Job Level** — Open the form to create a new job level.
2. **Job levels table** — Lists job level name, level number, and last update.
3. **Row actions** — Menu on each row to edit or manage that level.
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Job Level | Opens form to add a job level. | If you don’t see this, ask your admin. |
| 2 | Job levels table | Shows all job levels and their level value. | |
| 3 | Row actions | Edit or other actions per level. | |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Add a job level** — Click **+ New Job Level**, enter name and level, and save.
- **Edit a level** — Open row actions on that row and choose edit.
- **See hierarchy** — Use the table to see levels (e.g. 1 = Junior, 5 = Direktur).

## Troubleshooting

- **List is empty** — Job levels may not be set up yet, or access may be restricted. Ask your admin.
- **Cannot add or edit** — These actions may be restricted. If you don’t see them, ask your admin.
