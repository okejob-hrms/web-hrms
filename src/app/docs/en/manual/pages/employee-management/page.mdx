# Employee List

## Purpose

Use the Employee List to view and search all employees. You can filter by position and department, open a record to see details, or add a new employee.

## Screenshot

![Employee List](/manual/pages/employee-management.png)

## On this page

1. **Search by Employee Name or ID** — Type to find employees by name or ID.
2. **Position filter** — Narrow the list by one or more positions.
3. **Department filter** — Narrow the list by one or more departments.
4. **Advanced Search** — Open more filter options.
5. **New Employee** — Open the Add Employee page.
6. **Employee table** — Rows show Name, Position, Department, Email, Phone Number, Status, Join Date.
7. **Row actions** — Use the menu on each row to open or manage that employee.
8. **Pagination** — Move between pages of results.

## Common tasks

- **Find an employee** — Use the search box or filters, then click the row or row menu to open the employee detail.
- **Add an employee** — Click **+ New Employee**, fill the form, and submit.
- **Open employee detail** — Click the employee name or the row action menu and choose to view the record. The URL will include the employee ID (e.g. `/employee/employee-management/12`).

## Troubleshooting

- **List is empty** — Check filters and search; clear them or change the date range. If you don’t have access, ask your admin.
- **Cannot see New Employee** — This may be restricted by role. If you don’t see it, ask your admin.
- **Row menu does nothing** — Ensure you have permission to view that employee. Try refreshing the page.
