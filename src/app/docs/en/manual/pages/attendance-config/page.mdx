# Attendance Configuration

## Purpose

View and manage attendance rules (e.g. check-in/out times, late thresholds). Use **Edit** to change the configuration.

## Screenshot

![Attendance Configuration](/manual/pages/attendance-config.png)

## On this page

1. **Edit Attendance Configuration** — Open the edit form to change rules.
2. **Configuration display** — Shows current attendance rules or settings.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Edit Attendance Configuration | Opens the edit screen. | If you don't see this, ask your admin. |
| 2 | Configuration display | Shows current attendance settings. | |

## Common tasks

- **View rules** — Check the configuration display for current check-in/out and late rules.
- **Change rules** — Click **Edit**, update the fields, then save.

## Troubleshooting

- **Cannot edit** — This screen may be restricted. If you don't see the Edit button, ask your admin.
- **Changes not applied** — Save the form and refresh; confirm you have permission to update settings.
