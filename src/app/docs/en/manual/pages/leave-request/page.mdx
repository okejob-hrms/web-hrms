# Leave Request List

## Purpose

View leave request summary and the list of leave requests. You can switch tabs (Waiting for approval, Approved, Rejected), search, filter by date, add a new request, or use row actions to view details, approve, reject, edit, or delete.

## Screenshot

![Leave Request List](/manual/pages/leave-request.png)

## On this page

1. **Summary section** — Cards for New Leave Request, Employee On Leave Today, Waiting for Approval, Approved, Rejected.
2. **Tabs** — Switch between Waiting for approval, Approved, Rejected.
3. **Search by Employee Name or Email** — Type to find leave requests.
4. **Pick a date filter** — Filter by date.
5. **New Leave Request** — Open the Request Leave form.
6. **Leave table** — Rows show Name, Leave type, Duration, Reason, Notes, Status, Last Update.
7. **Row actions** — Menu on each row (Details, Approve, Reject, Edit, Delete).
8. **Pagination** — Move between pages of results.

## Common tasks

- **View by status** — Use the tabs to see waiting, approved, or rejected requests.
- **Request leave** — Click **New Leave Request**, fill the form, and submit.
- **Edit a request** — Open row actions and choose Edit. The URL includes the request ID (e.g. .../leave-request/edit/1).

## Troubleshooting

- **List is empty** — Check the tab and filters; clear search or date. If you don't have access, ask your admin.
- **Cannot add or edit** — These may be restricted by role. If you don't see them, ask your admin.
