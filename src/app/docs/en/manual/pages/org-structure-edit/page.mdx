# Edit Organization Structure

## Purpose

Change who reports to whom. You see an employee list grouped by position and an editable chart; drag or assign people to update the structure.

## Screenshot

![Edit Organization Structure](/manual/pages/org-structure-edit.png)

## On this page

1. **Back** — Return to the view-only organization structure page.
2. **Employee List search** — Find employees by name or position to assign to the chart.
3. **Position groups** — Lists of employees by position (e.g. Team Leader, Manager); expand to see names.
4. **Employee names** — Click to add or move people on the chart.
5. **Organization chart** — Editable chart where you assign or move nodes.
6. **Zoom controls** — Zoom in or out on the chart.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Back | Returns to Organization Structure (view). | |
| 2 | Employee List search | Search by name or position. | |
| 3 | Position groups | Expandable lists by job position. | |
| 4 | Employee names | Click to assign or move on chart. | |
| 5 | Organization chart | Editable reporting structure. | |
| 6 | Zoom controls | Adjust chart zoom. | |

## Common tasks

- **Assign someone to the chart** — Find them in the list (use search or position groups), then click or drag to the chart.
- **Change reporting line** — Move the person on the chart or reassign from the list.
- **Finish** — Use **Back** to save and return to the view.

## Troubleshooting

- **Cannot see edit page** — This may be restricted. If you don’t see it, ask your admin.
- **Changes don’t stick** — Ensure you go back via **Back**; if it still fails, refresh and try again or ask your admin.
