# Edit Leave Type

## Purpose

Change an existing leave type. You open this page by choosing **Edit** from the row menu on the Leave Configuration list; the URL includes the leave type ID. Save to apply; Cancel to discard.

## Screenshot

![Edit Leave Type](/manual/pages/leave-management-edit.png)

## On this page

1. **Leave form** — Same fields as Add (Leave Name, Description, Gender, Quota Configuration).
2. **Cancel** — Return without saving.
3. **Save** — Save changes.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Leave form | Edit name, entitlement, quota. | |
| 2 | Cancel | Discard changes. | |
| 3 | Save | Apply changes. | |

## Common tasks

- **Change quota** — Update Quota (days) or options, then **Save**.
- **Change who is entitled** — Update Gender and **Save**.

## Troubleshooting

- **Page not found (404)** — Open Edit from the row menu on Leave Configuration for a valid leave type; don’t use a random ID in the URL.
- **Cannot access** — If you don't see Edit in the row menu, ask your admin.
