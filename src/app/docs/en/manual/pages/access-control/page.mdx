# Access Control List

## Purpose

View and manage roles (access control). You can create a new role or open a row to view or edit role details and permissions.

## Screenshot

![Access Control List](/manual/pages/access-control.png)

## On this page

1. **New Role** — Open the form to create a new role.
2. **Role table** — Rows show Role Name and Last Update.
3. **Row menu** — Open the role detail or edit (URL includes role ID).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Role | Goes to Add Access form. | If you don't see this, ask your admin. |
| 2 | Role table | Lists roles. | |
| 3 | Row menu | Opens role detail. | URL includes role ID. |

## Common tasks

- **Create a role** — Click **+ New Role**, set name and permissions, then save.
- **View or edit a role** — Open the row menu and choose the action (URL includes ID).

## Troubleshooting

- **List is empty** — No roles exist yet. Create one or check permissions. If you don't have access, ask your admin.
- **Cannot create or open** — These may be restricted. If you don't see the button or menu, ask your admin.
