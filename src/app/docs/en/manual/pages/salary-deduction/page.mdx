# Deduction

## Purpose

View and manage salary deductions (e.g. statutory, tax, company policy). Use Set Up Salary Deduction to add one; use row actions to edit or delete.

## Screenshot

![Deduction](/manual/pages/salary-deduction.png)

## On this page

1. **Set Up Salary Deduction** — Open the form to add a deduction.
2. **Deduction table** — Deduction Name, Type, Employer and Employee Contribution, Effective Date, Effective To, Last Update.
3. **Row actions** — Menu on each row for Edit or Delete.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Set Up Salary Deduction | Opens add or setup form. | |
| 2 | Deduction table | Lists name, type, contributions, date range. | |
| 3 | Row actions | Edit or delete that deduction. | |

## Common tasks

- **Add a deduction** — Click Set Up Salary Deduction, enter name, type, employer and employee contribution, and date range, then save.
- **Edit a deduction** — Open row actions and choose Edit.
- **Check effective period** — Use Effective Date and Effective To columns.

## Troubleshooting

- **List empty** — Add deductions or check filters. If you do not have access, ask your admin.
- **Cannot add or edit** — If you do not see them, ask your admin.
