# Edit Form Template

## Purpose

Change an existing form template: name, usage, and questions (add, edit, reorder, or remove). The URL includes the form ID (e.g. .../edit/1). **Update** to save; **Cancel** to discard.

## Screenshot

![Edit Form Template](/manual/pages/form-template-edit.png)

## On this page

1. **Form Name, Form Usage** — Display at top.
2. **Questions** — Each block: Question text, Description, Answer Type, options (e.g. Checkbox, Range, Paragraph).
3. **Add Question** — Add another question.
4. **Cancel** — Return without saving.
5. **Update** — Save changes.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Form Name, Form Usage | Shows current name and usage. | |
| 2 | Questions | Edit text, type, options; delete with trash. | |
| 3 | Add Question | Adds a new question block. | |
| 4 | Cancel | Discard changes. | |
| 5 | Update | Save template. | |

## Common tasks

- **Change a question** — Edit the question text, answer type, or options, then **Update**.
- **Add a question** — Click **Add Question**, fill the block, then **Update**.
- **Remove a question** — Use the trash icon on that question, then **Update**.

## Troubleshooting

- **Page not found** — Open Edit from the Form Template list for a valid form (URL uses that form’s ID).
- **Cannot access** — If you don't see Edit, ask your admin.
