# Teams

## Purpose

View and manage teams (e.g. HR, Finance, IT). You can add new teams and use row actions to edit or manage each one.

## Screenshot

![Teams](/manual/pages/org-teams.png)

## On this page

1. **New Team** — Open the form to create a new team.
2. **Teams table** — Lists team name, description, and last update.
3. **Row actions** — Menu on each row to edit or manage that team.
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Team | Opens form to add a team. | If you don’t see this, ask your admin. |
| 2 | Teams table | Shows all teams. | |
| 3 | Row actions | Edit or other actions per team. | |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Add a team** — Click **+ New Team**, enter name and description, and save.
- **Edit a team** — Open row actions on that row and choose edit.
- **See all teams** — Use the table and pagination to browse.

## Troubleshooting

- **List is empty** — Teams may not be set up yet, or access may be restricted. Ask your admin.
- **Cannot add or edit** — These actions may be restricted. If you don’t see them, ask your admin.
