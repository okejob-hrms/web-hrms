# Edit Attendance Config

## Purpose

Change attendance rules such as check-in/out times and late thresholds. Save to apply; cancel to leave without saving.

## Screenshot

![Edit Attendance Config](/manual/pages/attendance-config-edit.png)

## On this page

1. **Configuration form** — Fields for attendance rules (e.g. times, thresholds).
2. **Save or Submit** — Saves your changes.
3. **Cancel or Back** — Returns without saving.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Configuration form | Enter or change attendance rules. | Fill required fields. |
| 2 | Save or Submit | Applies changes. | |
| 3 | Cancel or Back | Exits without saving. | |

## Common tasks

- **Update check-in/out rules** — Edit the relevant fields and click **Save**.
- **Discard changes** — Click **Cancel** or **Back**.

## Troubleshooting

- **Save disabled** — Check that required fields are filled and valid.
- **Cannot access this page** — If you don't see it, ask your admin.
