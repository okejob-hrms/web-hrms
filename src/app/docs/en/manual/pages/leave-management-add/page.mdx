# Add Leave Type

## Purpose

Create a new leave type: name, description, who is entitled (gender), and quota (same for all job levels, per job level, or unlimited). Save to add; Cancel to discard.

## Screenshot

![Add Leave Type](/manual/pages/leave-management-add.png)

## On this page

1. **Leave Name** — Name of the leave type (required).
2. **Description** — Optional description.
3. **Gender** — All, Male, or Female.
4. **Quota Configuration** — Same quota for all / Per job level / Unlimited; Quota (days); Carry Over; Deduct Employee Balance.
5. **Cancel** — Return without saving.
6. **Save** — Create the leave type.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Leave Name | Enter the leave type name. | Required. |
| 2 | Description | Optional text. | |
| 3 | Gender | Who is entitled. | Required. |
| 4 | Quota Configuration | Set quota and options. | |
| 5 | Cancel | Discard and go back. | |
| 6 | Save | Create leave type. | |

## Common tasks

- **Add annual leave** — Enter name, set Gender (e.g. All), set Quota (e.g. 12 days), then **Save**.
- **Allow carry over** — Check **Carry Over Allowed** in Quota Configuration before saving.

## Troubleshooting

- **Save disabled** — Fill required fields (Leave Name, Gender).
- **Cannot access** — If you don't see this page, ask your admin.
