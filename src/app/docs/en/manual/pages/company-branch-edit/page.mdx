# Edit Branch

## Purpose

Edit a company branch: change company information, location, and payroll details. The URL includes the branch ID.

## Screenshot

![Edit Branch](/manual/pages/company-branch-edit.png)

## On this page

1. **Company Information** — Logo, Name, Legal Entity, Industry, Email, Phone, BRN, Website, Address, Select Location, Maximum Radius, Is Primary.
2. **Payroll Information** — Bank Account Name, Number, Holder, Currency.
3. **Cancel** — Go back without saving.
4. **Save** — Save changes.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Company Information | Edit branch details. | URL includes branch ID. |
| 2 | Payroll Information | Edit bank details. | |
| 3 | Cancel | Leaves without saving. | |
| 4 | Save | Saves changes. | If you don't see this, ask your admin. |

## Common tasks

- **Update branch** — Change fields, then **Save**.
- **Set primary** — Use **Is Primary** toggle, then **Save**.

## Troubleshooting

- **Page not found** — The branch ID in the URL must exist. If you don't have access, ask your admin.
