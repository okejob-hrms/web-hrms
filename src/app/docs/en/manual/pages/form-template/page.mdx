# Form Template List

## Purpose

View and manage form templates (e.g. Exit Interview, Competency Assessment). Use **+ New Form** to add one; use row actions to open detail or edit.

## Screenshot

![Form Template List](/manual/pages/form-template.png)

## On this page

1. **New Form** — Open the Add Form screen.
2. **Form table** — Form Name, Form Usage, Last Update.
3. **Row actions** — Menu on each row (e.g. View, Edit).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Form | Goes to Add Form Template. | If you don't see this, ask your admin. |
| 2 | Form table | Lists templates. | |
| 3 | Row actions | Open detail or edit for that form. | |

## Common tasks

- **Add a form** — Click **+ New Form**, set name and usage, add questions, then **Save**.
- **View a form** — Open row actions and choose the option that opens the form detail (URL includes form ID).
- **Edit a form** — Open row actions and choose Edit (e.g. .../edit/1 for form ID 1).

## Troubleshooting

- **List empty** — Add forms or check access. If you don't see the list, ask your admin.
- **Cannot add or edit** — These may be restricted. If you don't see them, ask your admin.
