# ESS Overtime

## Purpose

This page shows your overtime requests. Use the status filters to see waiting, approved, or rejected requests. You can search by employee name (if applicable), pick a date, and create a new overtime request.

## Screenshot

![ESS Overtime](/manual/pages/ess-overtime.png)

## On this page

1. **Waiting for approval** — Filter to show requests pending approval.
2. **Approved** — Filter to show approved requests.
3. **Rejected** — Filter to show rejected requests.
4. **Search** — Search by employee name (if the list includes others).
5. **Pick a date** — Choose a date to filter the list.
6. **New Overtime Request** — Button to create a new overtime request.
7. **Overtime table** — Lists requests with overtime date, request date, duration, notes, and status.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Waiting for approval | Shows only pending requests. | Common filter. |
| 2 | Approved | Shows only approved requests. | Confirm approval. |
| 3 | Rejected | Shows only rejected requests. | Review and possibly re-request. |
| 4 | Search | Filters list by employee name. | If the list is multi-person. |
| 5 | Pick a date | Filters by date. | Depends on app behavior. |
| 6 | New Overtime Request | Opens the form to request overtime. | Enter date, duration, notes. |
| 7 | Overtime table | Lists overtime requests. | Columns: Overtime Date, Request Date, Duration, Notes, Status. |

## Common tasks

- **Request overtime** — Click **New Overtime Request**, enter date and duration, then submit.
- **See pending requests** — Click **Waiting for approval** and check the table.
- **Check approved or rejected** — Use **Approved** or **Rejected** filter.

## Troubleshooting

- **No data in table** — No requests match the current filter. Try another filter or create a new request.
- **New Overtime Request not available** — Your role or policy may not allow overtime requests. Ask your admin.
- **Status not updating** — Refresh the page after your manager approves or rejects.
