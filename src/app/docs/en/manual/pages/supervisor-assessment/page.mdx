# Supervisor Assessment List

## Purpose

View and manage supervisor assessments: employee name, previous and target position, final score, interview date, and result. Create new assessments or open a row to view details.

## Screenshot

![Supervisor Assessment List](/manual/pages/supervisor-assessment.png)

## On this page

1. **New Assessment** — Open the form to create a new supervisor assessment.
2. **Assessment table** — Rows show Employee Name, Previous Position, Target Position, Final Score, Interview Date, Assessment Result.
3. **Row menu** — Open actions for that row (e.g. view detail); URL includes assessment ID.
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Assessment | Goes to new assessment form. | If you don't see this, ask your admin. |
| 2 | Assessment table | Lists assessments. | |
| 3 | Row menu | Opens detail or other actions. | URL includes assessment ID. |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Create an assessment** — Click **+ New Assessment**, fill the form, and save.
- **View details** — Open the row menu and choose the action to open the assessment (URL includes ID).

## Troubleshooting

- **List is empty** — No supervisor assessments yet. Create one or check filters. If you don't have access, ask your admin.
- **Cannot create or open** — These may be restricted by role. If you don't see the button or menu, ask your admin.
