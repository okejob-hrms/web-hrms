# Organization Structure

## Purpose

View the company organization chart. You can filter by employee, download the chart, or switch to edit mode to change reporting lines.

## Screenshot

![Organization Structure](/manual/pages/org-structure.png)

## On this page

1. **Filter by employee** — Narrow the chart to show a specific person and their connections.
2. **Download** — Save the chart as an image or file.
3. **Edit Structure** — Open the edit page to change who reports to whom.
4. **Organization chart** — The chart showing roles and reporting relationships.
5. **Node actions (Phone, Mail, Profile)** — Quick actions on each person’s node.
6. **Zoom controls** — Zoom in or out on the chart.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Filter by employee | Filters the chart to focus on one employee. | |
| 2 | Download | Downloads the structure chart. | |
| 3 | Edit Structure | Goes to the edit view. | If you don’t see this, ask your admin. |
| 4 | Organization chart | Displays roles and reporting structure. | |
| 5 | Node actions | Phone, Mail, Profile shortcuts on each node. | |
| 6 | Zoom controls | Adjust chart zoom level. | |

## Common tasks

- **View reporting lines** — Use the chart; zoom or filter if needed.
- **Download the chart** — Click **Download**.
- **Change structure** — Click **Edit Structure**, then assign or move people on the chart.

## Troubleshooting

- **Chart is empty** — Check filter; clear “Filter by employee” or refresh. If you don’t have access, ask your admin.
- **Cannot edit** — Edit Structure may be restricted. If you don’t see it, ask your admin.
