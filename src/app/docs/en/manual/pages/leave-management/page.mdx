# Leave Configuration

## Purpose

View and manage leave types and (optionally) leave balance. Use the **Leave Type** tab to add or edit leave types; use **Leave Balance** for balance settings.

## Screenshot

![Leave Configuration](/manual/pages/leave-management.png)

## On this page

1. **Leave Type tab** — Shows the list of leave types.
2. **Leave Balance tab** — Switch to leave balance view.
3. **New Leave Type** — Open the form to add a leave type.
4. **Leave Type table** — Leave Name, Last Updated.
5. **Row actions** — Menu on each row (e.g. Edit).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Leave Type tab | Shows leave types list. | |
| 2 | Leave Balance tab | Shows leave balance settings. | |
| 3 | New Leave Type | Opens Add Leave Type form. | If you don't see this, ask your admin. |
| 4 | Leave Type table | Lists leave types. | |
| 5 | Row actions | Edit (or other actions) for that type. | |

## Common tasks

- **Add a leave type** — Click **New Leave Type**, fill name, entitlement, quota, then **Save**.
- **Edit a leave type** — Open row actions and choose Edit (opens edit page for that ID).
- **Check leave balance** — Switch to **Leave Balance** tab.

## Troubleshooting

- **Edit opens 404** — Use Edit from the row menu for an existing leave type; the URL uses that type’s ID.
- **Cannot add or edit** — If you don't see the button or row menu, ask your admin.
