# Attendance Detail

## Purpose

View and edit an existing attendance record. The page shows the same fields as Add Attendance; use **Update** to save changes. The URL contains the employee ID and attendance record ID (e.g. .../attendance-tracker/9/1).

## Screenshot

![Attendance Detail](/manual/pages/attendance-tracker-detail.png)

## On this page

1. **Back** — Return to the previous page.
2. **Breadcrumb** — Shows Attendance Tracker and the record IDs.
3. **Employee Name** — Selected employee (editable).
4. **Date** — Attendance date.
5. **Shift** — Shift type.
6. **Clock-In Time** — Clock-in time.
7. **Clock-Out Time** — Clock-out time.
8. **Select Location** — Location.
9. **Note** — Optional note.
10. **Cancel** — Discard changes and go back.
11. **Update** — Save changes.

## Common tasks

- **Edit a record** — From the list, open row actions and choose **Edit Attendance Record**. Change fields and click **Update**.
- **Return without saving** — Click **Cancel** or **Back**.

## Troubleshooting

- **Page does not load** — The record may not exist or the ID may be invalid. Return to the list and open another record.
- **Cannot update** — Check permissions. If you don't see Update or it fails, ask your admin.
