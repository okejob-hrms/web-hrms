# ESS OKR

## Purpose

This page shows your Objective & Key Results (OKR) cycles. You can see each period’s start and end date, total OKRs, overall achievement, and status. Use it to open a cycle or create a new one.

## Screenshot

![ESS OKR](/manual/pages/ess-okr.png)

## On this page

1. **New OKR Cycle** — Button to create a new OKR cycle.
2. **OKR table** — Lists OKR cycles with period, start date, end date, total OKR, overall achievement, status, and last update.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New OKR Cycle | Starts a new OKR period. | Use when a new cycle is open. |
| 2 | OKR table | Lists your OKR cycles. | Click a row to open that cycle (if supported). |

## Common tasks

- **View an OKR cycle** — Click the row (or the period) for that cycle to open details.
- **Create a new cycle** — Click **New OKR Cycle** when your admin has opened a new period.
- **Check achievement** — Use the Overall Achievement column to see progress.

## Troubleshooting

- **New OKR Cycle disabled or missing** — New cycles may be created by admins only. If you don’t see it, ask your admin.
- **Table empty** — No OKR cycles exist yet for your account. Ask when the next cycle will be opened.
- **Status stays Draft** — Draft means the cycle is open for editing; complete and submit when required.
