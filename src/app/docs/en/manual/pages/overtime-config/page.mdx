# Overtime Configuration

## Purpose

View overtime rules: working hour divisor, tiering rates, daily/weekly limits, and holiday rates. Use **Edit Overtime Configuration** to change them.

## Screenshot

![Overtime Configuration](/manual/pages/overtime-config.png)

## On this page

1. **Formula & Rate Coefficient** — Working Hour Divisor (e.g. 173 Hours/Month).
2. **Tiering Rules table** — Timing Hour and Rate (e.g. 0–3 Hour, 4 Hour).
3. **Limits & Thresholds** — Max Daily/Weekly Overtime, Auto Reject, Prorate by Minutes.
4. **Holiday & Special Day Overtime** — Weekend and Public Holiday rates; Special Exceptions table.
5. **Edit Overtime Configuration** — Opens the edit form.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Formula & Rate Coefficient | Shows divisor used for hourly rate. | |
| 2 | Tiering Rules table | Shows overtime rate by hour range. | |
| 3 | Limits & Thresholds | Shows max hours and options. | |
| 4 | Holiday & Special Day Overtime | Shows weekend/holiday rates and exceptions. | |
| 5 | Edit Overtime Configuration | Opens edit screen. | If you don't see this, ask your admin. |

## Common tasks

- **Check rates** — Review Formula, Tiering Rules, and Holiday sections.
- **Change rules** — Click **Edit Overtime Configuration**, update fields, then **Save**.

## Troubleshooting

- **Cannot edit** — This may be restricted. If you don't see the Edit button, ask your admin.
- **Values don’t match payroll** — Confirm the effective configuration and that changes were saved.
