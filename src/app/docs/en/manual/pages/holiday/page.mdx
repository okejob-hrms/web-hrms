# Holiday Attendance

## Purpose

View and manage the list of holidays (events and dates). Use **Add Holiday** to create one; use row actions to edit or delete.

## Screenshot

![Holiday Attendance](/manual/pages/holiday.png)

## On this page

1. **Add Holiday** — Open the form to add a new holiday.
2. **Holiday table** — Events and Date columns.
3. **Row actions** — Menu on each row (e.g. Edit, Delete).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Add Holiday | Opens Add Holiday form. | If you don't see this, ask your admin. |
| 2 | Holiday table | Lists holidays; Events and Date. | |
| 3 | Row actions | Edit or delete that holiday. | |

## Common tasks

- **Add a holiday** — Click **Add Holiday**, enter event name and date, then save.
- **Edit a holiday** — Open row actions and choose Edit.
- **Remove a holiday** — Open row actions and choose Delete (if available).

## Troubleshooting

- **List empty** — Add holidays or check filters. If you don't have access, ask your admin.
- **Cannot add or edit** — These may be restricted. If you don't see them, ask your admin.
