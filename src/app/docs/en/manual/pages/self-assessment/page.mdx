# Self Assessment List

## Purpose

View and manage self-assessment periods. You can create a new assessment, open a period to see progress by employee, or use the row menu for more actions.

## Screenshot

![Self Assessment List](/manual/pages/self-assessment.png)

## On this page

1. **New Assessment** — Open the form to create a new assessment period.
2. **Assessment table** — Rows show Assessment Period, Status, Start Date, End Date, Created At, Submitted (e.g. 0/2 Employees), Progress, Created By.
3. **Row menu** — Open actions for that period (e.g. view period details).
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Assessment | Goes to Add Self Assessment form. | If you don't see this, ask your admin. |
| 2 | Assessment table | Lists periods; click row or menu to open. | |
| 3 | Row menu | Opens period details or other actions. | URL includes period ID. |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Create an assessment** — Click **+ New Assessment**, set period and options, then save.
- **View a period** — Open the row menu and choose the action to open period details (URL includes period ID).
- **Check progress** — Use the Submitted and Progress columns to see completion.

## Troubleshooting

- **List is empty** — No assessment periods exist yet. Create one with **+ New Assessment**. If you don't have access, ask your admin.
- **Cannot create or open** — These may be restricted by role. If you don't see the button or menu, ask your admin.
