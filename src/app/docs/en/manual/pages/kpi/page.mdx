# KPI

## Purpose

View and manage Key Performance Indicators (KPIs): search, create new KPIs, and see ID, name, frequency, direction, and target in the list.

## Screenshot

![KPI](/manual/pages/kpi.png)

## On this page

1. **Search KPI** — Type to filter the list.
2. **New KPI** — Open the form to create a new KPI.
3. **KPI table** — Rows show ID, KPI Name, Frequency, Direction, Target.
4. **Row menu** — Open actions for that KPI (e.g. edit, delete).
5. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Search KPI | Filters the list as you type. | |
| 2 | New KPI | Goes to new KPI form. | If you don't see this, ask your admin. |
| 3 | KPI table | Lists KPIs. | |
| 4 | Row menu | Edit or delete that KPI. | |
| 5 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Create a KPI** — Click **+ New KPI**, fill name, frequency, direction, target, then save.
- **Find a KPI** — Use **Search KPI** to filter by name.
- **Edit or delete** — Open the row menu and choose the action.

## Troubleshooting

- **List is empty** — No KPIs yet, or clear the search. If you don't have access, ask your admin.
- **Cannot create or edit** — These may be restricted by role. If you don't see the button or menu, ask your admin.
