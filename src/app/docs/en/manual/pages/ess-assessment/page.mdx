# ESS Assessment

## Purpose

This page lists your self-assessment periods. You can see the period name, end date, and status (e.g. Not Started). Use the view (eye) icon to open an assessment and complete it.

## Screenshot

![ESS Assessment](/manual/pages/ess-assessment.png)

## On this page

1. **Assessment table** — Lists assessment periods with Period, End Date, and Status.
2. **View details** — Eye icon on each row to open that assessment.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Assessment table | Lists your assessment periods. | Columns: Period, End Date, Status. |
| 2 | View details | Opens the assessment for that period. | Use to start or continue. |

## Common tasks

- **Complete an assessment** — Click the eye icon for the period you need; then fill and submit the form.
- **See which periods are open** — Check the Status column (e.g. Not Started, In Progress, Submitted).
- **Check end date** — Use the End Date column to see the deadline.

## Troubleshooting

- **No rows in table** — No assessment periods have been set up for you yet. Ask your admin or HR.
- **View icon does nothing** — The period may be closed or you may not have access. Refresh and try again, or ask your admin.
- **Status not updating** — After submitting, refresh the page to see the new status.
