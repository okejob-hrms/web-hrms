# Add Branch

## Purpose

Add a company branch: enter company information, attendance location, and payroll (bank) details. Set **Is Primary** if this is the primary branch.

## Screenshot

![Add Branch](/manual/pages/company-branch-add.png)

## On this page

1. **Company Information** — Logo (optional), Name, Legal Entity, Industry, Email, Phone, BRN, Website, Address, Select Location, Maximum Radius, Is Primary.
2. **Payroll Information** — Bank Account Name, Number, Holder, Currency.
3. **Cancel** — Go back without saving.
4. **Save** — Create the branch.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Company Information | Enter branch details and location. | Required fields marked *. |
| 2 | Payroll Information | Enter bank details. | |
| 3 | Cancel | Leaves without saving. | |
| 4 | Save | Creates the branch. | If you don't see this, ask your admin. |

## Common tasks

- **Add a branch** — Fill required fields, set location if needed, then **Save**.
- **Set primary** — Turn **Is Primary** to Yes for the main branch.

## Troubleshooting

- **Cannot save** — Check required fields. If you don't see **Save**, ask your admin.
