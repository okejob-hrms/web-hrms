# Request overtime on mobile

## When to use

You worked or will work extra hours and need to submit an overtime request.

## Prerequisites

- Signed in on the mobile app.

## Steps

1. From [Mobile: Home](/docs/en/manual/mobile/pages/mobile-dashboard), tap **Overtime Request**, or use attendance shortcuts on [Mobile: Profile](/docs/en/manual/mobile/pages/mobile-profile).
2. On [Mobile: Overtime Request](/docs/en/manual/mobile/pages/mobile-overtime-request), fill date, hours, and reason.
3. Submit the form.

## Expected result

The overtime request is saved and visible in your attendance or overtime history.

## Common mistakes

- **Validation errors** — Required fields must be filled; check date is not in the past if restricted.
- **Cannot find the screen** — Use Home shortcut or Profile → Attendance and Overtime.
