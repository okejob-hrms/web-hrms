# Edit profile on mobile

## When to use

You need to update personal details allowed for self-service on mobile.

## Prerequisites

- Signed in; fields your company allows employees to edit.

## Steps

1. Open **Profile** ([Mobile: Profile](/docs/en/manual/mobile/pages/mobile-profile)).
2. Tap **My Profile** ([Mobile: Profile Detail](/docs/en/manual/mobile/pages/mobile-profile-detail)).
3. Tap **Edit** ([Mobile: Edit Profile](/docs/en/manual/mobile/pages/mobile-profile-edit)).
4. Change allowed fields and save.

## Expected result

Profile detail shows your updated information.

## Common mistakes

- **Edit not available** — Some fields are HR-only on web; ask your admin.
- **Save fails** — Check required fields and network connection.
