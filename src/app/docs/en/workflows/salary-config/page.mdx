# Configure salary components

## When to use

Use this workflow when you need to set up or change base salary, allowances, or deductions (e.g. by job position/level, statutory deductions).

## Prerequisites

- You are signed in as Admin (or a role with salary management permission).
- You have permission to manage base salary, allowance, or deduction settings.

## Steps

1. Go to Settings, Salary Management. You have three areas:
   - [Base Salary](/docs/manual/pages/salary-base) — Set base salary by job position and job level. Click **Add Base Salary** to add an entry; use row menu to edit or delete.
   - [Allowance](/docs/manual/pages/salary-allowance) — Set allowances by type and job level. Click **Set Up Allowance** to add; use row menu to edit or delete.
   - [Deduction](/docs/manual/pages/salary-deduction) — Set deductions (e.g. statutory, company policy). Click **Set Up Salary Deduction** to add; use row menu to edit or delete.
2. For each component, fill in the required fields (e.g. position, level, amount or percentage, effective date). Save.
3. Changes apply to payroll calculations for the relevant periods and employees.

## Expected result

Base salary, allowances, or deductions are added or updated. Payroll and payruns use the new configuration.

## Common mistakes

- **Cannot see Salary Management** — Your role may not have permission. Ask your admin.
- **Cannot add or edit** — Check required fields and effective dates. If you do not see the buttons, ask your admin.
