# Add or edit user access

## When to use

Use this workflow when you need to add a new user or role assignment or view or edit an existing access.

## Prerequisites

- You are signed in as Admin. You have permission to manage access control.

## Steps

1. Go to the [Access Control List](/docs/manual/pages/access-control).
2. To add: Click Add Access. You are on the [Add Access](/docs/manual/pages/access-control-add) page. Fill in the user, role, and any other required fields. Save.
3. To view or edit: Open an existing access from the list. You are on the [Access Detail](/docs/manual/pages/access-control-detail) page. View or edit the assignment and save.
4. After saving, the user has the new or updated access when they next sign in.

## Expected result

A new access is added or an existing one is updated. The list and detail pages reflect the change.

## Common mistakes

- **Cannot see Access Control** — This is usually an admin-only area. Ask your admin.
- **User still does not see new menu** — The user may need to sign out and sign in again.
