# Manage organization structure

## When to use

Use this workflow when you need to view the organization chart or change reporting lines (who reports to whom).

## Prerequisites

- You are signed in as HR or Admin.
- You have permission to view or edit the organization structure.

## Steps

1. Go to the [Organization Structure](/docs/manual/pages/org-structure) page (under Employee or Organization).
2. To **view** the structure, use the chart or list as shown. You can expand or filter if the app supports it.
3. To **change** reporting lines, click **Edit** (or open [Edit Organization Structure](/docs/manual/pages/org-structure-edit)). Move or assign employees to different managers as needed, then save.

## Expected result

You can see the org chart and, if you have permission, update reporting relationships. Changes are reflected in the structure.

## Common mistakes

- **Cannot edit** — The Edit option may be restricted. If you need to change the structure, ask your admin.
- **Changes not reflected** — Save your edits and refresh; if it still looks wrong, re-open the edit screen and confirm the correct manager is selected.
