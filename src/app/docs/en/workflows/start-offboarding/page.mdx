# Start offboarding

## When to use

Use this workflow when you need to start an offboarding process for an employee who is leaving.

## Prerequisites

- You are signed in as HR or Admin.
- You have permission to start offboarding.
- The employee exists in the system and offboarding is appropriate (e.g. resignation, end of contract).

## Steps

1. Go to the [Offboarding List](/docs/manual/pages/offboarding).
2. Click the button to start a new offboarding (e.g. **Start Offboarding** or **Add**). If the flow starts from elsewhere (e.g. employee detail), follow that path.
3. Select the employee and fill in the required details (e.g. offboarding type, date). Submit.
4. The new offboarding record appears in the list. Open it to go to [Offboarding Detail](/docs/manual/pages/offboarding-detail) (URL includes the offboarding ID).
5. Complete the offboarding steps as shown (e.g. handover, documents). Use [Offboarding Salary Adjustment](/docs/manual/pages/offboarding-salary-adjustment) when you need to adjust final pay.

## Expected result

An offboarding case is created and you can track and complete it from the list and detail pages.

## Common mistakes

- **Cannot start offboarding** — Your role may not have permission. Ask your admin.
- **Employee not found** — Ensure the employee is in the [Employee List](/docs/manual/pages/employee-management) and that you select the correct person.
