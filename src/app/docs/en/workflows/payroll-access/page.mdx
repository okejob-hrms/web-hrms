# Request payroll access

## When to use

Use this workflow when you need to request access to view or print payslips (e.g. employees requesting their payslip or HR processing requests).

## Prerequisites

- You are signed in. Employees may request their own payslip access; HR/Admin may have a separate flow to approve or process requests.
- You have permission to use the payroll request feature.

## Steps

1. Go to the [Request Access](/docs/manual/pages/payroll-request) page (under Payroll).
2. Follow the on-screen steps to request access or to view/print payslips (e.g. select pay period, submit request). If the app shows a list of requests, you can create a new one or open an existing one.
3. Submit the request. If your company requires approval, the request may show as Pending until an admin approves it. Once approved, you can view or print the payslip as allowed.

## Expected result

Your request is submitted. You can view or print the requested payslip once the process is complete (and you have access).

## Common mistakes

- **Cannot see Request Access** — Your role may not have access. Ask your admin how to request payslips.
- **No payslip for period** — The payrun for that period may not be completed yet. Check with HR or try again after the payrun is processed.
