# Request leave on mobile

## When to use

You need time off and want to submit a leave request from your phone.

## Prerequisites

- Signed in as an employee.
- Leave types configured by your company.

## Steps

1. Open the **Leave Request** tab ([Mobile: Leave Request](/docs/en/manual/mobile/pages/mobile-leave-request)) or tap **New Leave Request** on Home.
2. On [Mobile: New Leave Request](/docs/en/manual/mobile/pages/mobile-leave-request-form), choose leave type, dates, and reason.
3. Submit the form.
4. Track status in the leave list; open a row for [Mobile: Leave Detail](/docs/en/manual/mobile/pages/mobile-leave-detail).

## Expected result

A new leave request appears in your list with a pending or submitted status.

## Common mistakes

- **Empty leave list after submit** — Pull to refresh or reopen the tab; check for validation errors on the form.
- **Cannot select dates** — Some leave types restrict dates; ask HR if options are missing.
