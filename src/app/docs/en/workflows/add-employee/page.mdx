# Add employee

## When to use

Use this workflow when you need to add a new employee to the HRMS.

## Prerequisites

- You are signed in as HR or Admin.
- You have permission to add employees.
- You have the required information (name, email, position, department, etc.) as required by your company.

## Steps

1. Go to the [Employee List](/docs/manual/pages/employee-management).
2. Click **Add Employee** (or **+ New Employee**).
3. On the [Add Employee](/docs/manual/pages/employee-management-add) page, fill in the required fields (e.g. name, email, job position, department). Fill any optional fields as needed.
4. Click **Save** (or **Submit**). If validation fails, correct the errors and save again.
5. After success, you are typically taken to the employee list or to the [Employee Detail](/docs/manual/pages/employee-management-detail) page for the new employee.

## Expected result

The new employee is created and appears in the employee list. They can be assigned access and appear in org structure as configured.

## Common mistakes

- **Save disabled or validation errors** — Ensure all required fields are filled and formats (e.g. email) are valid. Check on-screen messages.
- **Cannot see Add Employee** — This may be restricted by role. Ask your admin if you need to add employees.
