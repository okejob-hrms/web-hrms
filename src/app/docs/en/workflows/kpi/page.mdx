# Manage KPI

## When to use

Use this workflow when you need to view or manage Key Performance Indicators in the HRMS.

## Prerequisites

- You are signed in as HR or Admin. You have permission to view or edit KPIs.

## Steps

1. Go to the [KPI](/docs/manual/pages/kpi) page.
2. View the list or dashboard of KPIs. To add or edit, use the button or row menu. Fill in or change the KPI name, target, period. Save.
3. The KPI list or dashboard updates.

## Expected result

You can see KPIs and, if you have permission, add or update them.

## Common mistakes

- **Cannot see KPI page** — Your role may not have access. Ask your admin.
- **Cannot save** — Check required fields and validation. Ensure you have edit permission.
