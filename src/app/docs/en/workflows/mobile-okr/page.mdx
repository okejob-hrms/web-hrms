# Review OKR on mobile

## When to use

You need to view or update objectives and key results on your phone.

## Prerequisites

- OKR data exists for your employee and period.

## Steps

1. Open **Performance** → OKR ([Mobile: OKR List](/docs/en/manual/mobile/pages/mobile-okr-list)).
2. Tap an objective ([Mobile: OKR Detail](/docs/en/manual/mobile/pages/mobile-okr)).
3. Open a key result ([Mobile: OKR Key Result](/docs/en/manual/mobile/pages/mobile-okr-key-result)) to update progress if allowed.

## Expected result

You can read OKR progress and save updates where editing is enabled.

## Common mistakes

- **Empty OKR list** — HR must assign OKRs for the period.
- **Read-only fields** — Some periods lock editing after deadline.
