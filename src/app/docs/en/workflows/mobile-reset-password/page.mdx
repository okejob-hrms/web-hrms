# Reset password on mobile

## When to use

You forgot your mobile app password and need a reset link by email.

## Prerequisites

- You know the email address registered in HRMS.

## Steps

1. On [Mobile: Login](/docs/en/manual/mobile/pages/mobile-login), tap **Reset Password**.
2. On [Mobile: Reset Password](/docs/en/manual/mobile/pages/mobile-reset-password), enter your email and submit.
3. Open [Mobile: Check Email](/docs/en/manual/mobile/pages/mobile-reset-password-check-email) and follow the link in your inbox.
4. Set a new password on [Mobile: Create Password](/docs/en/manual/mobile/pages/mobile-create-password) if prompted.
5. Confirm [Mobile: Password Reset Success](/docs/en/manual/mobile/pages/mobile-reset-password-success), then sign in with [Sign in to the mobile app](/docs/en/workflows/mobile-sign-in).

## Expected result

You can sign in with the new password on the mobile app.

## Common mistakes

- **No email received** — Check spam; confirm the email matches HR records; ask your admin.
- **Link expired** — Request reset again from the login screen.
