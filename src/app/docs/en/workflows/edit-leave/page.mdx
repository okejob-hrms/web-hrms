# Edit or cancel leave request

## When to use

Use this workflow when you need to change or cancel an existing leave request that is still editable (e.g. pending).

## Prerequisites

- You are signed in and have permission to edit leave requests (your own or as HR/Admin).
- The leave request exists and is in a status that allows edits (e.g. Pending).

## Steps

1. Go to the [Leave Request List](/docs/manual/pages/leave-request) (or [ESS Leave](/docs/manual/pages/ess-leave) for employees).
2. Find the leave request. Open the row menu and choose **Edit** (or the equivalent). You are taken to the [Edit Leave Request](/docs/manual/pages/leave-request-edit) page (URL includes the request ID).
3. Change the fields as needed (e.g. dates, reason). To cancel, use **Cancel** or the cancel/withdraw action if the app offers it.
4. Click **Update Leave Request** (or **Save**) to save changes. If you cancelled the request, confirm as prompted.

## Expected result

The leave request is updated or cancelled. The list reflects the new status or the request is removed from the pending list.

## Common mistakes

- **Edit not available** — The request may already be approved or rejected. Only pending (or similar) requests can usually be edited. If you need to change an approved request, ask your admin.
- **Page not found** — Open Edit from the list so the URL contains a valid request ID. Do not type the ID manually.
