# Request leave

## When to use

Use this workflow when you need to submit a new leave request (as an employee from ESS or as HR/Admin on behalf of someone).

## Prerequisites

- You are signed in. Employees use [ESS](/docs/manual/pages/ess) or the leave section; HR/Admin use the attendance area.
- You have permission to request leave.
- You know the leave type, dates, and reason (and approver if the app requires it).

## Steps

1. **Employees:** Go to [ESS](/docs/manual/pages/ess) then open the leave section (e.g. [ESS Leave](/docs/manual/pages/ess-leave)) and start a new request. **HR/Admin:** Go to the [Leave Request List](/docs/manual/pages/leave-request) and click the button to add a request (e.g. Add Leave Request).
2. You are on the request form (e.g. [Request Leave](/docs/manual/pages/leave-request-add) for HR). Select Leave Type, Start Date, End Date, and enter Reason. Select Employee and Assigned Approver when adding on behalf of someone else.
3. Add attachments if required. Click Add Leave Request (or Submit).
4. The request appears in the list with status Pending until an approver acts on it.

## Expected result

A leave request is submitted and appears in the leave list. It waits for approval unless your company rules say otherwise.

## Common mistakes

- **Wrong dates** — Ensure end date is on or after start date and within your leave balance. Check the leave type rules.
- **Cannot submit** — Fill all required fields (leave type, dates, reason). If you do not see the form, check that you are in the correct area (ESS vs Attendance) and ask your admin if needed.
