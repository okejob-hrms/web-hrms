# View employee profile

## When to use

Use this workflow when you need to view one employee's profile and details.

## Prerequisites

- You are signed in (HR, Admin, or a user with access to employee data).
- You have permission to view employee details.

## Steps

1. Go to the [Employee List](/docs/manual/pages/employee-management).
2. Search or scroll to find the employee.
3. Open the row menu and choose **View** (or the option that opens the profile), or click the employee name if it is a link. You are taken to the [Employee Detail](/docs/manual/pages/employee-management-detail) page (URL includes the employee ID).
4. On the detail page you can see the employee's information. From here you can also **Edit** if you have permission.

## Expected result

You see the employee's profile with the information configured for your role (e.g. contact, position, department, leave balance).

## Common mistakes

- **Page not found** — The ID in the URL may be invalid. Open the employee from the list instead of typing the URL.
- **Missing information** — Some fields may be hidden by role or not yet filled. If you need more data, ask your admin or the employee to update their profile where allowed.
