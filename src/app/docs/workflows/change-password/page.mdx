# Change password (first login)

## When to use

Use this workflow when the system asks you to change your password (e.g. first login) or after you opened the link from the password-reset email.

## Prerequisites

- You have just signed in and were redirected to change password, or you opened the link from the reset email.

## Steps

1. You land on the [Change Password](/docs/manual/pages/change-password) page.
2. Enter your new password in the required field(s). Follow any rules shown (e.g. minimum length).
3. If there is a Confirm password field, enter the same password again.
4. Click Submit (or the button label shown).
5. You are taken to the [Password Changed](/docs/manual/pages/success-change-password) page. From there you can sign in with your new password.

## Expected result

Your password is updated. You see the success page and can use your new password to [log in](/docs/manual/pages/login).

## Common mistakes

- **Passwords do not match** — Ensure the new password and confirm password are identical.
- **Password too weak** — Follow the rules shown on the page and try again.
