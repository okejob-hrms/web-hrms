# Create or update OKR

## When to use

Use this workflow when you need to create a new OKR cycle or update an existing one.

## Prerequisites

- You are signed in. You have permission to create or edit OKRs.

## Steps

1. Go to the [OKR List](/docs/manual/pages/okr).
2. To create: Click the button to add a new OKR. Fill in the cycle name, period, and objectives or key results. Save.
3. To update: Open an existing OKR from the list. You are taken to the [OKR Detail](/docs/manual/pages/okr-detail) page. Edit the objectives or key results. Save.

## Expected result

A new OKR cycle is created or an existing one is updated. The list and detail pages show the latest data.

## Common mistakes

- **Cannot add or edit** — Your role may not have OKR permission. Ask your admin.
- **Detail page not found** — Open the OKR from the list so the URL contains a valid OKR ID.
