# Configure leave types

## When to use

Use this workflow when you need to add a new leave type or change existing leave types and their rules.

## Prerequisites

- You are signed in as Admin. You have permission to manage leave configuration.

## Steps

1. Go to the [Leave Configuration](/docs/manual/pages/leave-management) page under Settings. Use the Leave Type tab.
2. To add a leave type: Click New Leave Type. You are on the [Add Leave Type](/docs/manual/pages/leave-management-add) page. Fill in Leave Name, Description, Gender entitlement, and Quota Configuration. Save.
3. To edit a leave type: Open the row menu and choose Edit. Change the fields and save.
4. The new or updated leave type appears in the list and can be used when requesting leave.

## Expected result

Leave types are added or updated. Employees and HR can select these types when requesting leave.

## Common mistakes

- **Cannot add or edit** — Your role may not have permission. Ask your admin.
- **Edit page not found** — Use Edit from the row menu on the Leave Configuration list so the URL has a valid leave type ID.
