# View payrun list and details

## When to use

Use this workflow when you need to see the list of payruns (payroll runs) or open a specific payrun to view its details.

## Prerequisites

- You are signed in as HR or Admin (or a role with payroll access).
- You have permission to view payruns.

## Steps

1. Go to the [Payrun List](/docs/manual/pages/payroll-list) (under Payroll).
2. Use the search or date filter if you need to find a specific payrun. The table shows Payruns name, Total Payslip, Total Pay, Payslip Status, Generation Status, Last Updated.
3. To view one payrun in detail, open it from the row menu (e.g. **View** or **Detail**). You are taken to the [Payrun Detail](/docs/manual/pages/payroll-detail) page (URL includes the payrun ID).
4. On the detail page you can see the payrun information. To edit or process the payrun, use the link or button to [Edit Payrun](/docs/manual/pages/payroll-edit) (process payrun workflow).

## Expected result

You see the payrun list and can open a payrun to view its details (and from there proceed to process it if needed).

## Common mistakes

- **Cannot see Payrun List** — Your role may not have payroll access. Ask your admin.
- **Detail page not found** — Open the payrun from the list so the URL contains a valid payrun ID.
