# Configure attendance settings

## When to use

Use this workflow when you need to view or change attendance rules such as check-in/out times and late thresholds.

## Prerequisites

- You are signed in as Admin. You have permission to edit attendance configuration.

## Steps

1. Go to the [Attendance Configuration](/docs/manual/pages/attendance-config) page under Settings, Time and Attendance.
2. Review the current configuration. To change it, click Edit. You are on the [Edit Attendance Config](/docs/manual/pages/attendance-config-edit) page.
3. Update the fields. Save.
4. Return to the Attendance Configuration page. The new rules apply.

## Expected result

Attendance rules are updated. The system uses the new configuration for attendance validation and reporting.

## Common mistakes

- **Cannot edit** — Your role may not have permission. Ask your admin.
- **Save disabled** — Fill all required fields and check validation messages.
