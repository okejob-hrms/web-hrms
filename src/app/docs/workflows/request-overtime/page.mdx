# Request overtime

## When to use

Use this workflow when you need to submit an overtime request (as an employee or as HR/Admin on behalf of someone).

## Prerequisites

- You are signed in. Employees may use [ESS Overtime](/docs/manual/pages/ess-overtime) or the overtime section; HR/Admin use the attendance area.
- You have permission to request overtime.
- You know the date, hours, and reason (and any other required fields).

## Steps

1. Go to the [Overtime](/docs/manual/pages/overtime) page (from the menu under Attendance or from ESS).
2. Click the button to add a new overtime request (e.g. **Add Overtime** or **New Request**).
3. Fill in the required fields (e.g. date, hours, reason). Select employee if you are submitting on behalf of someone else.
4. Submit the request. It appears in the overtime list with status Pending (or similar) until an approver acts on it.

## Expected result

An overtime request is submitted and appears in the list. It waits for approval according to your company rules.

## Common mistakes

- **Cannot submit** — Check that required fields are filled and that hours are within the limits set in [Overtime Configuration](/docs/manual/pages/overtime-config) (if applicable). Ask your admin if you do not see the add button.
- **Request rejected** — Review the rejection reason. Ensure your request fits company policy (e.g. max hours per day/week). You can submit a new request if allowed.
