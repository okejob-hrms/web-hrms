# Edit employee

## When to use

Use this workflow when you need to change an employee's information (e.g. name, position, department, contact details).

## Prerequisites

- You are signed in as HR or Admin.
- You have permission to edit employees.
- You know which employee to edit (e.g. from the [Employee List](/docs/manual/pages/employee-management)).

## Steps

1. Go to the [Employee List](/docs/manual/pages/employee-management) and find the employee, or open their [Employee Detail](/docs/manual/pages/employee-management-detail) page.
2. From the list, open the row menu and choose **Edit**, or on the detail page click **Edit**. You are taken to the [Edit Employee](/docs/manual/pages/employee-management-edit) page (URL includes the employee ID).
3. Change the fields as needed (e.g. name, position, department).
4. Click **Save** (or **Update**). Correct any validation errors if shown.
5. After success, you are typically returned to the detail page or the list.

## Expected result

The employee's information is updated and the changes are visible on the detail page and list.

## Common mistakes

- **Cannot find Edit** — Use the row menu on the employee list or the Edit button on the employee detail page. If you do not see either, ask your admin.
- **Changes not saved** — Check for validation messages; ensure required fields are still valid and save again.
