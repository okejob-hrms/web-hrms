# Start Here

Welcome to the OkeJobHub HRMS user manual. Use this guide to learn how to use the application and where to find each screen.

## Where to find the manual

You can open this manual from the main app or by going to the docs section of the HRMS. The manual is for everyone who uses the system.

## Who sees what

| Role | What you see after login |
|------|---------------------------|
| **HR / Admin** | Dashboard, Employee, Attendance, Payroll, Performance, Settings. You can manage staff, approve requests, and configure the system. |
| **Employee** | Employee Self-Service (ESS). You can view your info, request leave and overtime, and complete assessments. |

If you don’t see a menu or screen, ask your admin.
