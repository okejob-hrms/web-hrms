# OKR List

## Purpose

View and manage Objective & Key Results (OKR) cycles: period, dates, total OKRs, overall achievement, and status. Create a new cycle or open a row to view cycle details.

## Screenshot

![OKR List](/manual/pages/okr.png)

## On this page

1. **New OKR Cycle** — Open the form to create a new OKR cycle.
2. **OKR table** — Rows show Period, Start Date, End Date, Total OKR, Overall Achievement, Status, Last Update.
3. **Row menu** — Open actions for that cycle (e.g. view detail); URL includes cycle ID.
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New OKR Cycle | Goes to new OKR cycle form. | If you don't see this, ask your admin. |
| 2 | OKR table | Lists OKR cycles. | |
| 3 | Row menu | Opens detail or other actions. | URL includes cycle ID. |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Create a cycle** — Click **+ New OKR Cycle**, set period and dates, then save.
- **View a cycle** — Open the row menu and choose the action to open the cycle (URL includes ID).

## Troubleshooting

- **List is empty** — No OKR cycles yet. Create one with **+ New OKR Cycle**. If you don't have access, ask your admin.
- **Cannot create or open** — These may be restricted by role. If you don't see the button or menu, ask your admin.
