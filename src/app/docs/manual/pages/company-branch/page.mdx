# Branch List

## Purpose

View and manage company branches: name, last update, and whether the branch is primary. Add a branch or open the row menu to edit.

## Screenshot

![Branch List](/manual/pages/company-branch.png)

## On this page

1. **New Branch** — Open the form to add a branch.
2. **Branch table** — Rows show Company Name, Last Update, Is Primary.
3. **Row menu** — Edit the branch (URL includes branch ID).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Branch | Goes to Add Branch form. | If you don't see this, ask your admin. |
| 2 | Branch table | Lists branches. | |
| 3 | Row menu | Opens edit. | URL includes branch ID. |

## Common tasks

- **Add a branch** — Click **+ New Branch**, fill the form, save.
- **Edit a branch** — Open the row menu and choose edit (URL includes ID).

## Troubleshooting

- **List is empty** — No branches yet. Add one with **+ New Branch**. If you don't have access, ask your admin.
