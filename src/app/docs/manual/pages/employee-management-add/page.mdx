# Add Employee

## Purpose

Use this page to add a new employee. You enter personal, employment, salary, bank, and attachment details. Required fields are marked with an asterisk (*).

## Screenshot

![Add Employee](/manual/pages/employee-management-add.png)

## On this page

1. **Personal Information section** — Photo (optional), Name, Email, Phone, Gender, Place of Birth, Born Date, Marital Status, Blood Type, Height, Weight, ID Number, NPWP, BPJS, addresses, Hobby, Achievement, Social Media.
2. **Employment Information section** — Company, Position, Department, Job Level, Primary Direct Report, Additional Direct Report, Team, Employment Start Date, Employment End Date, Status.
3. **Salary Information section** — Allowance (optional), Base Salary, Salary (Nett). You may need to select Job Level first to see allowance options.
4. **Bank Information section** — Bank, Account Number, Account Name.
5. **Attachments section** — Upload required documents (e.g. CV, Graduation Certificate, Personal ID Card, Family Card, NPWP, BPJS, Bank Account Book, Driver License) and optional Others.
6. **Cancel** — Leave without saving.
7. **Add Employee** — Save the new employee.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Personal Information | Enter name, contact, and personal details. | Fields marked * are required. |
| 2 | Employment Information | Enter company, position, department, job level, reports, team, dates, status. | |
| 3 | Salary Information | Enter base salary and nett salary. | Select Job Level to see allowance suggestions. |
| 4 | Bank Information | Enter bank and account details. | |
| 5 | Attachments | Upload required and optional files. | Each type may be required (*). |
| 6 | Cancel | Discard and go back. | |
| 7 | Add Employee | Submit and create the employee. | |

## Common tasks

- **Add a new employee** — Fill all required fields in each section, upload required attachments, then click **Add Employee**.
- **Leave without saving** — Click **Cancel**.
- **Add allowance manually** — If Job Level does not show allowances, use **Add Allowance Manually** in the Salary section.

## Troubleshooting

- **Add Employee is disabled** — Check that all required fields are filled and required attachments are uploaded.
- **Cannot select Position or Department** — Ensure Company (or parent data) is set first. If options are empty, ask your admin.
- **Upload fails** — Check file size and type. Try again or use a different file.
