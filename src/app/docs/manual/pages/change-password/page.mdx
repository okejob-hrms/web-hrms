# Change Password

## Purpose

Use this page to create a new password. You may see it after requesting a reset (from the link in your email) or when the system requires you to change your password (e.g. first login).

## Screenshot

![Change Password](/manual/pages/change-password.png)

## On this page

1. **Back** — Link to return to the previous page.
2. **Email** — Field showing or entering your email address.
3. **Password** — Field to enter your new password.
4. **Show/hide password** — Toggle to show or hide the password.
5. **Password Confirmation** — Field to enter the new password again.
6. **Show/hide password confirmation** — Toggle to show or hide the confirmation.
7. **Continue** — Button to save the new password.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Back | Returns to the previous page. | Use to cancel. |
| 2 | Email | Your email address. | May be pre-filled or read-only. |
| 3 | Password | Enter your new password. | Must meet the required rules (e.g. minimum length). |
| 4 | Show/hide password | Toggles password visibility. | Use to check what you typed. |
| 5 | Password Confirmation | Enter the new password again. | Must match the Password field. |
| 6 | Show/hide password confirmation | Toggles confirmation visibility. | Use to check what you typed. |
| 7 | Continue | Saves the new password. | You can then sign in with the new password. |

## Common tasks

- **Set new password** — Enter the new password in both fields and click **Continue**. Then sign in with the new password.
- **Check what you typed** — Use the eye icons to show the password and confirmation.
- **Cancel** — Click **Back** to return without changing the password.

## Troubleshooting

- **Passwords do not match** — Make sure Password and Password Confirmation are exactly the same.
- **Password too weak** — Follow the rules shown on the page (e.g. minimum length, required characters).
- **Continue does nothing** — Check that both password fields are filled and match. Fix any error messages shown.
- **Page redirects to login** — The reset link may have expired. Request a new reset link from the reset password page.
