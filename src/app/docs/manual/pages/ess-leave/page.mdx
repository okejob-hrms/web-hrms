# ESS Leave

## Purpose

This page shows your leave requests. Use the status filters to see waiting, approved, or rejected requests. You can pick a date and create a new leave request from here.

## Screenshot

![ESS Leave](/manual/pages/ess-leave.png)

## On this page

1. **Waiting for approval** — Filter to show requests that are pending approval.
2. **Approved** — Filter to show approved requests.
3. **Rejected** — Filter to show rejected requests.
4. **Pick a date** — Choose a date to filter or focus the list.
5. **New Leave Request** — Button to create a new leave request.
6. **Leave Request table** — Lists your requests with duration, reason, notes, status, and last update.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Waiting for approval | Shows only pending requests. | Default or common filter. |
| 2 | Approved | Shows only approved requests. | Use to confirm approval. |
| 3 | Rejected | Shows only rejected requests. | Use to see why and possibly re-request. |
| 4 | Pick a date | Filters or focuses by date. | Depends on app behavior. |
| 5 | New Leave Request | Opens the form to request leave. | Fill dates, reason, notes. |
| 6 | Leave Request table | Lists your leave requests. | Columns: Duration, Reason, Notes, Status, Last Update. |

## Common tasks

- **Request leave** — Click **New Leave Request**, enter dates and reason, then submit.
- **See pending requests** — Click **Waiting for approval** (or leave default) and check the table.
- **Check approved or rejected** — Click **Approved** or **Rejected** and review the list.

## Troubleshooting

- **No data in table** — No requests match the current filter or date. Try another filter or create a new request.
- **New Leave Request not working** — Check that you have leave balance and valid dates. If you don’t see the button, ask your admin.
- **Status not updating** — Refresh the page; approval may take a moment to appear.
