# Offboarding Salary Adjustment

> **Flagged:** This section is draft documentation. The offboarding feature is not fully fixed yet. Screenshots and steps will be updated once the feature is complete.

## Purpose

Adjust salary for an employee in an offboarding process. You reach this page from the offboarding detail; the URL is .../off-boarding/{id}/salary-adjustment where {id} is the offboarding record ID.

## Screenshot

![Offboarding Salary Adjustment](/manual/pages/offboarding-salary-adjustment.png)

## On this page

1. **Breadcrumb / Back** — Navigate back to the offboarding detail or list.
2. **Salary adjustment form** — Fields to enter or change salary-related values for the offboarding.
3. **Submit or Save** — Apply the salary adjustment.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Breadcrumb / Back | Return to detail or list. | |
| 2 | Salary adjustment form | Enter salary adjustment data. | |
| 3 | Submit or Save | Saves the adjustment. | If you don't see this, ask your admin. |

## Common tasks

- **Open salary adjustment** — From the offboarding detail page, use the link or button to go to salary adjustment for that record.
- **Apply adjustment** — Fill the form and click Submit or Save.
- **Go back** — Use the breadcrumb or back control to return without saving.

## Troubleshooting

- **Page shows an error** — The offboarding record may be missing or invalid. Go back to the offboarding list and open a valid record first.
- **Cannot save** — Check required fields and permissions. If you don't have access, ask your admin.
