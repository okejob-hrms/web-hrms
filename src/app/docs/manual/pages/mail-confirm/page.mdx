# Check Your Email

## Purpose

This page confirms that a password reset link was sent to your registered email. Use it to know what to do next or to resend the email.

## Screenshot

![Check Your Email](/manual/pages/mail-confirm.png)

## On this page

1. **Back** — Link to return to the previous page.
2. **Resend Email** — Link to send the reset email again if you did not receive it.
3. **Continue** — Button to go to the login page.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Back | Returns to the previous page. | Use to change the email address. |
| 2 | Resend Email | Sends the reset link again. | Use if you did not receive the first email. |
| 3 | Continue | Opens the login page. | Use after you have set your new password. |

## Common tasks

- **Wait for the email** — Check your inbox (and spam) for the reset link, then open it and set a new password.
- **Resend the link** — If you did not receive the email, click **Resend Email**.
- **Go to login** — Click **Continue** to open the login page (e.g. after resetting your password).

## Troubleshooting

- **Email not received** — Check spam or junk. Click **Resend Email**. Ensure the address is the one you use to log in.
- **Link expired** — Reset links are valid for a limited time. Request a new one from the reset password page.
- **Continue not working** — Refresh the page or try again. Contact your admin if it still fails.
