# Request Leave

## Purpose

Submit a new leave request. Choose the employee, assign approvers, leave type, start and end dates, reason, and optional attachments.

## Screenshot

![Request Leave](/manual/pages/leave-request-add.png)

## On this page

1. **Employee Name** — Select the employee.
2. **Assigned Approver** — Select one or more approvers.
3. **Leave Type** — Select the type of leave (e.g. Sick, Annual).
4. **Start Date** — Pick the first day of leave.
5. **End Date** — Pick the last day of leave.
6. **Reason** — Enter the reason for leave.
7. **Select Attachments** — Add optional attachment files.
8. **Cancel** — Return without saving.
9. **Add Leave Request** — Submit the request.

## Common tasks

- **Submit a request** — Select employee and approvers, choose leave type and dates, enter reason, then click **Add Leave Request**.
- **Cancel** — Click **Cancel** to return without submitting.

## Troubleshooting

- **Cannot save** — Check required fields (employee, approver, leave type, dates). If you don't have permission, ask your admin.
