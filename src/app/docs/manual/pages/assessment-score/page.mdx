# Assessment Score Threshold

## Purpose

View and manage assessment score thresholds: label (e.g. A, B) and score range. Use **Add Score** to add one; use row actions to edit or delete.

## Screenshot

![Assessment Score Threshold](/manual/pages/assessment-score.png)

## On this page

1. **Add Score** — Open the form to add a score threshold.
2. **Score table** — Score Label, Score Range.
3. **Row actions** — Menu on each row (e.g. Edit, Delete).
4. **Pagination** — Previous / Next and page numbers.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Add Score | Opens add form. | If you don't see this, ask your admin. |
| 2 | Score table | Lists label and range (e.g. 0–20, 21–40). | |
| 3 | Row actions | Edit or delete that threshold. | |
| 4 | Pagination | Move between pages. | |

## Common tasks

- **Add a threshold** — Click **Add Score**, enter label and score range, then save.
- **Edit a threshold** — Open row actions and choose Edit.
- **Check ranges** — Ensure ranges don’t overlap and cover the full scale used in assessments.

## Troubleshooting

- **List empty** — Add score thresholds or check access. If you don't see the list, ask your admin.
- **Cannot add or edit** — These may be restricted. If you don't see them, ask your admin.
