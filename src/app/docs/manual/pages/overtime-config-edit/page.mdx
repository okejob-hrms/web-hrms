# Edit Overtime Config

## Purpose

Change overtime rules: working hour divisor, tiering rules, limits, and holiday rates. Save to apply; Cancel to leave without saving.

## Screenshot

![Edit Overtime Config](/manual/pages/overtime-config-edit.png)

## On this page

1. **Working Hours Divisor** — Formula (160 / 173 / 180 Hours per month).
2. **Add Tiering Rules** — Add a new tier (timing hour range and rate).
3. **Tiering table** — Rows with Timing Hour, Rate, and delete.
4. **Limits & Thresholds** — Max Daily/Weekly/Monthly hours, Auto Reject, Prorate by Minutes.
5. **Weekend/Public Holiday rates** — Number inputs for multiplier.
6. **Add Exception** — Add a special-day rate.
7. **Cancel** — Exit without saving.
8. **Save** — Apply changes.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Working Hours Divisor | Choose formula for hourly rate. | Required. |
| 2 | Add Tiering Rules | Adds a row to the tiering table. | |
| 3 | Tiering table | Edit or remove tiers. | |
| 4 | Limits & Thresholds | Set max hours and options. | |
| 5 | Weekend/Public Holiday rates | Set multiplier (e.g. 3x, 4x). | |
| 6 | Add Exception | Add special day and rate. | |
| 7 | Cancel | Discard changes. | |
| 8 | Save | Save configuration. | |

## Common tasks

- **Change divisor** — Select 160, 173, or 180 Hours/Month and **Save**.
- **Add a tier** — Click **Add Tiering Rules**, fill range and rate, then **Save**.
- **Set holiday rate** — Enter Weekend and Public Holiday multipliers and **Save**.

## Troubleshooting

- **Save disabled** — Check required fields (e.g. divisor, rates).
- **Cannot access** — If you don't see this page, ask your admin.
