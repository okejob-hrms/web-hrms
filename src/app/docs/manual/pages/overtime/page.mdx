# Overtime

## Purpose

View overtime request summary and the list of overtime requests. You can switch tabs by status, search by employee, filter by date, and use the table to see or manage requests.

## Screenshot

![Overtime](/manual/pages/overtime.png)

## On this page

1. **Summary section** — Cards for New, Pending, Approved, and Rejected overtime requests.
2. **Tabs** — Switch between Waiting for approval, Approved, Rejected.
3. **Search by Employee Name or Email** — Type to find requests.
4. **Pick a date filter** — Filter by date.
5. **Overtime table** — Rows show Name, Overtime Date, Request Date, Duration, Notes, Status (and row actions when data exists).
6. **Pagination** — Move between pages of results.

## Common tasks

- **View by status** — Use the tabs to see waiting, approved, or rejected overtime requests.
- **Find a request** — Use search or date filter, then open the row action menu to view or edit.
- **Add overtime** — If available, use the button or action to create a new request. If you don't see it, ask your admin.

## Troubleshooting

- **Table shows no data** — Check the tab and filters; there may be no requests yet. If you don't have access, ask your admin.
- **Cannot add or edit** — These may be restricted by role. If you don't see them, ask your admin.
