# Add Attendance

## Purpose

Record a new attendance entry for an employee. Choose the employee, date, shift, clock-in and clock-out times, location, and optional note.

## Screenshot

![Add Attendance](/manual/pages/attendance-tracker-add.png)

## On this page

1. **Back** — Return to the Attendance List.
2. **Employee Name** — Select the employee.
3. **Date** — Pick the attendance date.
4. **Shift** — Select the shift.
5. **Clock-In Time** — Enter clock-in time.
6. **Clock-Out Time** — Enter clock-out time.
7. **Select Location** — Choose or set location.
8. **Note** — Optional note.
9. **Cancel** — Return without saving.
10. **Save** — Save the new record.

## Common tasks

- **Record attendance** — Select employee and date, enter times and location, add a note if needed, then click **Save**.
- **Cancel** — Click **Cancel** or **Back** to return without saving.

## Troubleshooting

- **Cannot save** — Check required fields (employee, date, times). If you don't have permission, ask your admin.
