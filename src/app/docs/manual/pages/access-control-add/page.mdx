# Add Access

## Purpose

Create a new role: enter name and description, set permissions by functionality, then save. You can assign the role to employees from here or later.

## Screenshot

![Add Access](/manual/pages/access-control-add.png)

## On this page

1. **Role Information** — Name and Description.
2. **Assign Role/Permission** — Apply or copy role/permission template.
3. **Assign Employee** — Open dialog to assign this role to employees.
4. **Permissions table** — Functionality and action checkboxes (View, Create, Edit, etc.).
5. **Cancel** — Go back without saving.
6. **Save** — Create the role.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Role Information | Enter role name and description. | |
| 2 | Assign Role/Permission | Apply template or bulk set permissions. | If you don't see this, ask your admin. |
| 3 | Assign Employee | Assign this role to employees. | |
| 4 | Permissions table | Set permissions per functionality. | |
| 5 | Cancel | Leaves without saving. | |
| 6 | Save | Creates the new role. | |

## Common tasks

- **Create a role** — Fill Role Information, set permissions in the table, then click **Save**.
- **Use a template** — Click **Assign Role/Permission** to copy from another role or template, then adjust and **Save**.

## Troubleshooting

- **Cannot save** — Check that Name is filled. If you don't see **Save** or **Assign Role/Permission**, ask your admin.
- **Permissions not applied** — Ensure checkboxes are set as needed before **Save**.
