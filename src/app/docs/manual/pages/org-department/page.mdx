# Department List

## Purpose

View and manage departments (e.g. IT, HR, Finance). You can add new departments and use row actions to edit or manage each one.

## Screenshot

![Department List](/manual/pages/org-department.png)

## On this page

1. **New Department** — Open the form to create a new department.
2. **Departments table** — Lists department name, description, and last update.
3. **Row actions** — Menu on each row to edit or manage that department.
4. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Department | Opens form to add a department. | If you don’t see this, ask your admin. |
| 2 | Departments table | Shows all departments. | |
| 3 | Row actions | Edit or other actions per department. | |
| 4 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **Add a department** — Click **+ New Department**, enter name and description, and save.
- **Edit a department** — Open row actions on that row and choose edit.
- **See all departments** — Use the table and pagination to browse.

## Troubleshooting

- **List is empty** — Departments may not be set up yet, or access may be restricted. Ask your admin.
- **Cannot add or edit** — These actions may be restricted. If you don’t see them, ask your admin.
