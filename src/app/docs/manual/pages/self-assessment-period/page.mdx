# Assessment by Period/Employee

## Purpose

View one employee's self-assessment for a given period: assessment information, result scores, and detailed responses. Use the tabs to switch between Self Assessment and Assessment Validation.

## Screenshot

![Assessment by Period/Employee](/manual/pages/self-assessment-period.png)

## On this page

1. **Employee and Assessment Information** — Employee name, ID, Position, Department, Job Level, Submitted On, Submission Status, Supervisor, Validated On.
2. **Self Assessment tab** — View the self-assessment result and details.
3. **Assessment Validation tab** — View validation (if any).
4. **Self Assessment Result** — Table showing Category and Score (and total).
5. **Self Assessment Details** — Groupings and form answers (e.g. ratings, text).

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Employee and Assessment Information | Shows who and when. | URL includes period and employee ID. |
| 2 | Self Assessment tab | Shows self-assessment content. | |
| 3 | Assessment Validation tab | Shows validation content. | |
| 4 | Self Assessment Result | Displays category scores. | |
| 5 | Self Assessment Details | Displays form sections and answers. | Read-only when completed. |

## Common tasks

- **View an employee's assessment** — Open from the period list; URL includes period and employee ID.
- **Check scores** — Use the Self Assessment Result table and Total Score.
- **Switch to validation** — Click the **Assessment Validation** tab.

## Troubleshooting

- **Page not found** — Check that the period and employee IDs in the URL are valid. If you don't have access, ask your admin.
- **Details are disabled** — Completed assessments are read-only. To change them, use Edit (if available for your role).
