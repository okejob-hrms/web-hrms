# Payrun List

## Purpose

View and manage payruns. You can search by name, filter by date, create a new payrun, or open a row to see payrun details and edit it.

## Screenshot

![Payrun List](/manual/pages/payroll-list.png)

## On this page

1. **Search by payruns name** — Type to find payruns.
2. **Pick a date** — Filter payruns by date.
3. **New Payruns** — Open the form to create a new payrun.
4. **Payruns table** — Rows show Payruns (name/period), Total Payslip, Total Pay, Payslip Status, Generation Status.
5. **Row menu** — Open actions for a payrun (e.g. view detail, edit).
6. **Pagination** — Move between pages of results.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Search by payruns name | Filters the list as you type. | |
| 2 | Pick a date | Filters payruns by the chosen date. | |
| 3 | New Payruns | Goes to the new payrun form. | If you don't see this, ask your admin. |
| 4 | Payruns table | Lists payruns with totals, status, last updated. | |
| 5 | Row menu | Opens actions for that payrun (e.g. detail, edit). | |
| 6 | Pagination | Previous / Next and page numbers. | |

## Common tasks

- **View payruns** — Use the table to see periods, totals, and status. Click a payrun name to open details.
- **Create a payrun** — Click **+ New Payruns**, fill the form, and save.
- **Filter by date** — Use **Pick a date** to narrow the list.

## Troubleshooting

- **List is empty** — Check search and date filter; clear them if needed. If you don't have access, ask your admin.
- **Cannot create payruns** — This may be restricted by role. If you don't see **+ New Payruns**, ask your admin.
