# Password Changed

## Purpose

This page confirms that your password was changed successfully. Use **Continue** to go to the login page and sign in with your new password.

## Screenshot

![Password Changed](/manual/pages/success-change-password.png)

## On this page

1. **Back** — Link to return to the previous page.
2. **Continue** — Button to open the login page.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Back | Returns to the previous page. | Rarely needed after success. |
| 2 | Continue | Opens the login page. | Use to sign in with your new password. |

## Common tasks

- **Sign in with new password** — Click **Continue** to go to the login page, then enter your email and new password.

## Troubleshooting

- **Continue not working** — Refresh the page and try again. You can also open the login page from the app or bookmark.
- **Forgot new password** — Use the reset password flow again from the login page to set another new password.
