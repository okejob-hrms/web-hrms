# Form Template Detail

## Purpose

View a form template in read-only form: name, usage, and all questions. Use Edit Form to change it or Delete Form to remove it if available.

## Screenshot

![Form Template Detail](/manual/pages/form-template-detail.png)

## On this page

1. **Form Name, Form Usage** — Display at top.
2. **Groupings** — Questions and answer options read-only.
3. **Edit Form** — Open the edit screen for this form.
4. **Delete Form** — Delete the form if you have permission.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Form Name, Form Usage | Shows name and usage. | |
| 2 | Groupings | Read-only list of questions. | |
| 3 | Edit Form | Opens edit for this form. | |
| 4 | Delete Form | Deletes the form. | |

## Common tasks

- **Review a form** — Open from the Form Template list; the URL includes the form ID.
- **Change the form** — Click Edit Form, make changes, then Update.

## Troubleshooting

- **Page not found** — Use a form ID from the list; open detail from the row menu.
- **Cannot edit or delete** — If you do not see those buttons, ask your admin.
