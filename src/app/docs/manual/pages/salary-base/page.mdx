# Base Salary

## Purpose

View and manage base salary by job position and job level. Use Add Base Salary to create an entry; use row actions to edit or delete.

## Screenshot

![Base Salary](/manual/pages/salary-base.png)

## On this page

1. Add Base Salary — Open the form to add a base salary entry.
2. Base salary table — Job Position, Job Level, Base Salary Amount, Effective Date, Last Update.
3. Row actions — Menu on each row for Edit or Delete.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Add Base Salary | Opens add form. | |
| 2 | Base salary table | Lists position, level, amount, dates. | |
| 3 | Row actions | Edit or delete that entry. | |

## Common tasks

- Add base salary: Click Add Base Salary, choose position and level, enter amount and effective date, then save.
- Edit an entry: Open row actions and choose Edit.
- Check effective date: Use Effective Date and Last Update columns.

## Troubleshooting

- List empty: Add entries or check filters. If you do not have access, ask your admin.
- Cannot add or edit: If you do not see them, ask your admin.
