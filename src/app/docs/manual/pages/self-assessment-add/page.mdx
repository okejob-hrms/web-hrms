# Add Self Assessment

## Purpose

Create a new self-assessment period: set the assessment period, year, dates, reminder option, then assign participants and an assessment form.

## Screenshot

![Add Self Assessment](/manual/pages/self-assessment-add.png)

## On this page

1. **Assessment Period** — Choose the period type (e.g. quarter).
2. **Year** — Enter the year (required).
3. **Start Date** — Pick the period start date.
4. **End Date** — Pick the period end date.
5. **Send Reminder** — Choose whether to send reminders.
6. **Participants** — Section showing how many employees are assigned (e.g. 0/49).
7. **Assessment Form** — Choose the form used for this assessment.
8. **Assign Participant** — Open the dialog to assign employees.
9. **Add Participant** — Add another participant.
10. **Cancel** — Go back without saving.
11. **Create Assessment** — Save and create the assessment.

## Common tasks

- **Create an assessment** — Fill Assessment Details, assign participants, choose form, then click **Create Assessment**.
- **Assign employees** — Click **Assign Participant**, select employees, confirm.

## Troubleshooting

- **Cannot create** — Check required fields (e.g. Year). If you don't see **Create Assessment** or **Assign Participant**, ask your admin.
- **No forms in dropdown** — Assessment forms must exist first. Ask your admin.
