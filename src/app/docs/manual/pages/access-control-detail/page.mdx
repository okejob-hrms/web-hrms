# Access Detail

## Purpose

View or edit a role: change name and description, then set permissions by functionality (View, Create, Edit, etc.). You can save as a new role or reset to a template. The URL includes the role ID.

## Screenshot

![Access Detail](/manual/pages/access-control-detail.png)

## On this page

1. **Role Information** — Name and Description.
2. **Save as new role** — Save current permissions as a new role.
3. **Reset to template** — Reset permissions to the default template.
4. **Permissions table** — Functionality and action checkboxes (View, Create, Edit, Assign, Download, Delete, Export, Approval, Override Status).
5. **Cancel** — Go back without saving.
6. **Save** — Save changes to this role.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Role Information | Edit role name and description. | URL includes role ID. |
| 2 | Save as new role | Creates a new role from current settings. | If you don't see this, ask your admin. |
| 3 | Reset to template | Restores default permissions. | |
| 4 | Permissions table | Set permissions per functionality. | |
| 5 | Cancel | Leaves without saving. | |
| 6 | Save | Saves changes. | |

## Common tasks

- **Edit permissions** — Toggle checkboxes in the Permissions table, then click **Save**.
- **Copy as new role** — Adjust as needed, then click **Save as new role**.
- **Reset** — Click **Reset to template** to restore defaults, then **Save** if needed.

## Troubleshooting

- **Page not found** — The role ID in the URL must exist. Open from the Access Control list. If you don't have access, ask your admin.
- **Cannot save** — You may need permission. If you don't see **Save** or **Save as new role**, ask your admin.
