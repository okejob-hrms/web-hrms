# Edit Employee

## Purpose

Use this page to update an existing employee’s data. The URL contains the employee ID (e.g. `/employee/employee-management/edit/12`). You can change personal, employment, salary, bank, and attachment information, or archive the employee.

## Screenshot

![Edit Employee](/manual/pages/employee-management-edit.png)

## On this page

1. **Personal Information form** — Photo, Name, Email, Phone, Gender, Place of Birth, Born Date, Marital Status, Blood Type, Height, Weight, ID Number, NPWP, BPJS, addresses, Hobby, Achievement, Social Media.
2. **Employment Information form** — Company, Position, Department, Job Level, Primary Direct Report, Additional Direct Report, Team, Employment Start Date, Employment End Date, Status.
3. **Salary Information** — Allowance, Base Salary, Salary (Nett).
4. **Bank Information** — Bank, Account Number, Account Name.
5. **Attachments** — View or change uploaded files (CV, Graduation Certificate, Personal ID Card, etc.); use **Upload File** or **Change File**.
6. **Cancel** — Leave without saving changes.
7. **Update** — Save changes.
8. **Archieve Employee** — Archive this employee (typically makes them inactive or removes them from the active list).

## Common tasks

- **Update employee data** — Change the fields you need, then click **Update**.
- **Change a document** — In Attachments, click **Change File** for that document and choose a new file.
- **Cancel changes** — Click **Cancel** to leave without saving.
- **Archive the employee** — Click **Archieve Employee** and confirm if prompted. If you don’t see it, ask your admin.

## Troubleshooting

- **Update does nothing** — Check for validation errors (e.g. required fields). Fix them and try again.
- **Archieve Employee not visible** — This may be restricted by role. If you don’t see it, ask your admin.
- **Page not found** — The employee ID in the URL may be invalid. Return to the Employee List and open the employee again.
