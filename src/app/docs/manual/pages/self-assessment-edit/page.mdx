# Edit Self Assessment

## Purpose

Edit an existing self-assessment period: change period, year, dates, reminder, participants, or form. The URL includes the period ID.

## Screenshot

![Edit Self Assessment](/manual/pages/self-assessment-edit.png)

## On this page

1. **Assessment Period** — Change the period type (e.g. Q2).
2. **Year** — Change the year (required).
3. **Start Date** — Change the start date.
4. **End Date** — Change the end date.
5. **Send Reminder** — Change reminder option.
6. **Participants** — Section showing assigned count (e.g. 2/49).
7. **Assessment Form** — Change the form for this assessment.
8. **Edit Participant** — Change who is assigned.
9. **Delete** — Remove participant or form (depending on context).
10. **Add Participant** — Add more participants.
11. **Cancel** — Go back without saving.
12. **Update Assessment** — Save changes.

## Common tasks

- **Change dates** — Update Start Date and End Date, then **Update Assessment**.
- **Change participants** — Click **Edit Participant** or **Add Participant**, then **Update Assessment**.

## Troubleshooting

- **Cannot edit** — You may need permission. If you don't see **Update Assessment** or **Edit Participant**, ask your admin.
- **URL not found** — The period ID in the URL must exist. Open the assessment from the list first.
