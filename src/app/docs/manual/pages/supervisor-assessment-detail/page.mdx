# Supervisor Assessment Detail

## Purpose

View one supervisor assessment: employee details, target position and level, assigned assessors, and interview schedule. Edit the schedule, complete the assessment, or cancel it. The URL includes the assessment ID.

## Screenshot

![Supervisor Assessment Detail](/manual/pages/supervisor-assessment-detail.png)

## On this page

1. **Employee Details** — Name, ID, Email, Current Position, Department, Job Level, Direct Reports, Start Date, Target Position, Target Job Level, Assigned Assessor.
2. **Assessment Schedule tab** — View or edit the interview schedule.
3. **Performance Assessment tab** — View performance assessment content.
4. **Interview Schedule** — Date, Time, Participant(s), Notes.
5. **Edit Interview Schedule** — Change date, time, or participants.
6. **Complete Assessment Proses** — Mark the assessment as complete.
7. **Cancel Supervisor Assessment** — Cancel this assessment.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | Employee Details | Shows employee and target info. | URL includes assessment ID. |
| 2 | Assessment Schedule tab | Shows schedule section. | |
| 3 | Performance Assessment tab | Shows performance section. | |
| 4 | Interview Schedule | Displays date, time, participants, notes. | |
| 5 | Edit Interview Schedule | Opens edit for schedule. | If you don't see this, ask your admin. |
| 6 | Complete Assessment Proses | Completes the process. | |
| 7 | Cancel Supervisor Assessment | Cancels the assessment. | Use with care. |

## Common tasks

- **Edit the schedule** — Click **Edit Interview Schedule**, change date/time/participants, save.
- **Complete the assessment** — When done, click **Complete Assessment Proses**.
- **Cancel** — Click **Cancel Supervisor Assessment** if the assessment should not proceed.

## Troubleshooting

- **Page not found** — The ID in the URL must be valid. Open from the list first. If you don't have access, ask your admin.
- **Cannot edit or complete** — These actions may be restricted by role. If you don't see the buttons, ask your admin.
