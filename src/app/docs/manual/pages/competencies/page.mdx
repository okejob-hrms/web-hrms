# Competencies List

## Purpose

View and manage performance competencies (code, name, description). Use New Performance Competency to add one; use row actions to open detail or edit.

## Screenshot

![Competencies List](/manual/pages/competencies.png)

## On this page

1. **New Performance Competency** — Open the form to add a competency.
2. **Competencies table** — Code, Competencies, Description.
3. **Row actions** — Menu on each row for View detail or Edit.
4. **Pagination** — Previous, Next and page numbers.

## Controls

| Number | Name | What it does | Notes |
|--------|------|----------------|-------|
| 1 | New Performance Competency | Opens add form. | |
| 2 | Competencies table | Lists code, name, description. | |
| 3 | Row actions | Open detail or edit. | |
| 4 | Pagination | Move between pages. | |

## Common tasks

- **Add a competency** — Click New Performance Competency, enter code, name, description, then save.
- **View detail** — Open row actions and choose the option that opens the detail page.
- **Edit a competency** — Open from row actions or from the detail page Edit button.

## Troubleshooting

- **List empty** — Add competencies or check access. If you do not see the list, ask your admin.
- **Cannot add or edit** — If you do not see them, ask your admin.
