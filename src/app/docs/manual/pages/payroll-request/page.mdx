# Request Access

## Purpose

Request access to payroll: use **Print Request** to see and manage print requests, or **View Payslip Request** to see payslip view requests. Search and filter by employee or date.

## Screenshot

![Request Access](/manual/pages/payroll-request.png)

## On this page

1. **Print Request tab** — View and manage print payroll requests.
2. **View Payslip Request tab** — View and manage payslip view requests.
3. **Search by employee name** — Filter requests by employee.
4. **Pick a date** — Filter by date.
5. **Print Payroll Request** — Section heading (when Print Request tab is active).
6. **Requests table** — Rows show Request By, Payrun Request, Request On, Request Status, Last Updated.
7. **Pagination** — Move between pages of results.

## Common tasks

- **View print requests** — Open the **Print Request** tab and use the table; use search or date to filter.
- **View payslip requests** — Open the **View Payslip Request** tab.
- **Find a request** — Use **Search by employee name** or **Pick a date** to narrow the list.

## Troubleshooting

- **List is empty** — Check search and date filter; clear them if needed. If you don't have access to this page, ask your admin.
- **Cannot request access** — Requesting may be restricted by role. If you don't see the options you need, ask your admin.
